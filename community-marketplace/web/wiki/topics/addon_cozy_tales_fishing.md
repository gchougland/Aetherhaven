# Cozy Tales: Fishing

**Cozy Tales: Fishing** is a relaxed fishing pack (rods, bobbers, aquariums, fishing journal). It works alone. With **Aetherhaven** installed alongside it, you get extra town content.

## What you get with both mods

- **Reed Castwell**, a castaway fisherman with dialogue and tips
- A **fishing shop** you help establish (blueprint → plot crafting bench → shop prefab)
- Shop stock and prices for fishing gear
- Extra rewards from sunken treasure (gold coins and the occasional jewelry)

Aetherhaven is not required for fishing. Install both only if you want the integration.

## How to unlock Reed

1. Install **Cozy Tales: Fishing** and **Aetherhaven**.
2. Finish **Vex's market stall** so Reed can appear in the inn visitor pool.
3. Talk to Reed at the inn, accept the fishing shop quest, learn the blueprint at the plot crafting bench, and build the shop.
4. Optionally build Reed a house the same way as other residents.

Full quest steps, schedule, and gift tastes: **[Reed Castwell](?topic=villager_fisherman)**.
