# Addons

Aetherhaven works on its own. Some Hexvane (and partner) mods can optionally plug in when both are installed: extra villagers, shops, quest board jobs, gift tastes, and journal pages.

Nothing here is required to run Aetherhaven. Install an addon only if you want that pack’s town content.

## Known integrations

| Mod | What you get with Aetherhaven |
|-----|-------------------------------|
| [Machinaria](?topic=addon_machinaria) | Mechanic villager **Rivet Cogsworth**, mechanics shop, rescue quest, shop stock |
| [Cozy Tales: Fishing](?topic=addon_cozy_tales_fishing) | Fisherman **Reed Castwell**, fishing shop, gear/fish shop spots, treasure extras |

Each overview page explains how to unlock that content. Villager detail pages cover quests, friendship, schedules, and gifts—same style as the Town Journal.
