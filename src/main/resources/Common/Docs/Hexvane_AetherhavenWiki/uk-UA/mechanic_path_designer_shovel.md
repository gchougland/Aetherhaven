# Лопата для конструктора шляхів

**Лопата для конструктора шляхів** дозволяє малювати вигнуті шляхи через місто, переглядати їх та розміщувати блоки на землі. Панель стану з ключовими підказками з'являється, поки ви тримаєте інструмент.

Створіть її на **містобудівному столі**.

## Режими

Натискайте **Q**, щоб перемикатися між п'ятьма режимами:

1. **Переміщення** — додавання та переміщення керуючих вузлів для формування шляху.

2. **Поворот** — повертання вибраного вузла для зігнення сплайну.

3. **Розміщення** — закріплення готового шляху на землі.

4. **Видалення** — перегляд розміщених шляхів (виділено помаранчевим кольором) та видалення тих, які вам більше не потрібні.

5. **Конструктор стилів** — створення та редагування стилів шляхів у сітці скринь.

Інтерфейс користувача нагадує вам перейти в режим **Розміщення**, коли ви готові розміщувати блоки шляху.

## Керування за режимом

### Переміщення, Поворот та Розміщення

* **Додатковий (клацання правою кнопкою миші) на землі** — додавання вузла.
* **Додатковий під час прицілювання до вузла** — видалити цей вузол.
* **Основний (клацання лівою кнопкою миші) на вузлі** — вибрати його.
* **Основний на землі (режим переміщення)** — перемістити вибраний вузол.
* **F (режим повороту)** — змістити напрямок вибраного вузла.
* **F (режим розміщення)** — розмістити шлях на землі.
* **E** — ширина велодоріжки.
* **R** — стиль велодоріжки.
* **Q** — наступний режим.

### Видалити

* **Основний** — вибрати розміщений шлях.
* **F** — видалити вибраний шлях.
* **Q** — наступний режим.

### Дизайнер стилів

* **F** — відкрити менеджер стилів (сітка з подвійними скринями для зважених блокових колон).
* **E** — зберегти стиль шляху (поки скриня відкрита).
* **Q** — наступний режим.

## Попередній перегляд візуальних елементів

Під час редагування білі вузли та лінії показують сплайн. Коричневий попередній перегляд позначає місця розташування блоків, а зелені краї з боків – зелені. У режимі **Видалити** зафіксовані контури помаранчевим кольором.

## Поради

* Спочатку надайте форму сплайну в режимах **Перемістити** та **Повернути**, потім перейдіть до режиму **Розмістити** та натисніть **F**, щоб закріпити його.
* Створюйте власні вигляди в **Дизайнері стилів** — кожен стиль – це зважений стовпець блоків, прокатаних по ширині контуру.
* Контури зберігаються у світі та у вашому місті.
