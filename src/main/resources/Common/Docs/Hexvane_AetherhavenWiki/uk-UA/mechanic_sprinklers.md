# Дощувачі

Дощувачі – це металеві помічники для великих полів. Активуйте один, і він оновлюватиме посіви в зоні навколо дощувача один раз на день на світанку. Його також можна активувати вручну за допомогою блоку. Розблоковується, якщо потоваришувати з фермером. Є чотири рівні дощувача, які можна розблокувати зі збільшенням радіуса поливу.
