# Плаваючі подарунки

Іноді загорнутий подарунок ширяє над містом. Збийте його, перш ніж він попливе.

Подарунки бувають трьох кольорів. Кожен колір містить різні скарби в одній подарунковій коробці.

Білі подарунки часто містять креслення будівель, золоті монети та корисні речі.

Зелені подарунки містять ювелірні вироби, золоті монети та корисні речі.

Червоні подарунки містять предмети меблів, золоті монети та корисні речі.
