# Персонал творця сюжету

Персонал творця сюжету реєструє **власні будівлі**, які ви побудували у світі: площа, спеціальні блоки, експорт префабів, витрати та (за бажанням) живу ділянку у вашому місті. Більшість гравців повинні використовувати **Декорацію** або **Варіант**, а не повні типи робочих місць, наведені нижче.

Відкрийте свій **міський журнал → Посібник → Механіка → Персонал творця сюжету** (ця сторінка) під час вивчення процесу. У грі: екіпіруйте персонал, натисніть **F**, щоб розпочати або відкрити панель поточного кроку, **первинним клацанням** блоки у світі, **Q** / **E** попередній / наступний крок, **R** для скасування.

## Рекомендовані шляхи

| Мета | Тип будівлі | Нотатки |
|------|----------------|-------|
| Косметична збірка, без завдань | **Декорація** | Додаткова полиця міських записів; без логіки виробництва чи жителів села. |
| Альтернативний вигляд існуючої будівлі | **Варіант** | Виберіть, якою **головною** будівлею вона вважається (будинок, сарай, корчма тощо). Підкроки відповідають цьому основному типу. |
| Нове робоче місце / виробнича ділянка (модифікація) | **Робота** | Для додавання нових типів робочих місць; потрібен блок управління, виробниче сховище та точка інтересу робочої поверхні. |

## Типи будівель (вибір)

**Декорація** — Парки, реквізит та споруди, які **не повинні** використовуватися як будинки, магазини або робочі місця. Мінімальна необхідна кількість місць.

**Варіант** — Збірна конструкція, яка **вважається** іншим ідентифікатором будівлі, що вже є в модифікації (наприклад, будинок на замовлення, який вважатиметься `plot_house`). Ви вибираєте основний тип зі спадного списку; важливі місця відповідають цій основній будівлі.

**Дім** — Житлова ділянка: полиця міських записів + точка інтересу сну.

**Робота** — **Використання розробником / автором контенту.** Визначає нову ділянку в стилі **робочого місця**: полиця міських записів, виробниче сховище та точка інтересу робочої поверхні. Використовуйте, коли ви додаєте новий тип виробничої або робочої будівлі, а не для звичайних косметичних варіантів.

**Зручності** — Розваги або дозвілля (парк, зручності у стилі вівтаря): полиця + точка інтересу для розваг/сидіння.

**Магазин** — Кіоск або прилавок магазину: полиця + точка інтересу з тегом «робочий майданчик» у магазині.

**Заїзд** — Повне планування заїзду: полиця, робоча поверхня, ліжка, місце для їжі, місця для відродження господаря заїзду та відвідувачів (і додатковий слот для відродження майстра гільдії).

**Ратуша** — Громадський центр: полиця, блок скарбниці, точка інтересу для столу для планування.

**Зала гільдії** — Гільдія шукачів пригод: полиця, робоча поверхня, точки відродження шукачів пригод.

### Перекриття та плутанина

- **Варіант** проти **Дім / Робота / …** — Варіант означає «виглядає інакше, поводиться як X». Виберіть **Варіант** + основний тип, а не **Дім**, якщо ви переробляєте зовнішній вигляд існуючої ігрової будівлі.
- **Робота** проти **Магазин** — **Магазин** призначений для торгових кіосків. **Робота** призначений для ферм, млинів, кузень та інших виробничих робочих місць.
- **Зручності** проти **Прикраси** — **Прикраса** майже не має ігрових гачків. **Зручності** встановлюють теги розваг/зручностей та POI для розкладів селян.
- **Готель**, **Ратуша** та **Гільдія** — це повноцінні шаблони; використовуйте **Варіант** лише якщо ви навмисно відповідаєте одному з цих шаблонів.

## Хід (короткий)

1. Позначте два протилежні кути та **зовнішній** кут для сюжетної таблички.

2. Виберіть **тип будівлі** (та **варіант**, якщо застосовно).

3. Розмістіть **важливі місця** (блоки даються по одному за кожен підкрок).

4. Введіть **назву та ідентифікатор** (назва файлу префабу йде після ідентифікатора).

5. Відредагуйте **теги**, якщо потрібно.

6. Відкрийте **налаштування будівлі** (F): вартість золота скарбниці, дні самостійного будівництва, варіант префабу з порожнім простором та секції складання.
7. **Експортуйте префаб** за допомогою F на кроці збереження форми (використовуються налаштування з кроку 6).
8. Встановіть **матеріали для будівництва** (віртуальна скриня; предмети повертаються до вас, коли ви продовжите).
9. Перегляньте та збережіть.
