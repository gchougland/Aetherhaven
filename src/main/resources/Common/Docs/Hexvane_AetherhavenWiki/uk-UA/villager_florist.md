**Айві Блумвелл** продає рослини та квіти зі своєї **квіткової крамниці** після її будівництва. Вона з'являється в корчмі після того, як **ринкова лавка Векс** завершена.

Використайте **Показати тижневий розклад** нижче, щоб побачити, куди Айві ходить щодня.

### Завдання

#### Квіткова крамниця Айві
Айві хоче справжню крамницю, де вона могла б ділитися своїми рослинами з містом.

1. Поговоріть з Айві в корчмі та прийміть завдання.
2. Візьміть **креслення** крамниці у Айві.
3. Використайте креслення на своїй **лавці для виготовлення ділянки**, щоб вивчити роботу квіткової крамниці.
4. Зробіть жетон ділянки для крамниці та побудуйте збірний будинок для квіткової крамниці.
5. Знайдіть Айві в крамниці та завершіть завдання діалогом.

#### Дім Айві
Навіть квіткар, який цілий день розмовляє зі своїми рослинами, заслуговує на тихе місце для відпочинку.

1. Візьміть жетон ділянки будинку у Айві.
2. Закріпіть та побудуйте збірний будинок.
3. Призначте Айві мешканцем блоку управління будинком.
4. Знайдіть Айві та завершіть завдання в діалозі.
