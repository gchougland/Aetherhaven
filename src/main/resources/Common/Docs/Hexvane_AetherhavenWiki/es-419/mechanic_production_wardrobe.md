# Armario de producción

Los edificios de producción utilizan un cofre tipo armario para configurar y acceder a los recursos generados. Busca el armario en el edificio e interactúa con él para abrir la ventana de producción. Puedes alternar entre los recursos disponibles para producir usando las flechas. Cada tipo de recurso se almacena por separado. Seleccionar varias unidades del mismo recurso aumenta la velocidad de producción. La página de desbloqueos te permite desbloquear nuevos recursos para generar a cambio de parte de ese recurso y monedas de oro.

*En el futuro podrás mejorar el almacenamiento máximo y la velocidad de producción de los edificios.*
