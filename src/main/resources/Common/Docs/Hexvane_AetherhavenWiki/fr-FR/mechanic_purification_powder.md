# Poudre de purification

La poudre de purification permet de supprimer les points d'apparition des ennemis dans les structures générées. En tenant la poudre, le joueur verra apparaître de petites versions tournantes des créatures à l'endroit où elles apparaissent périodiquement dans la structure. Utiliser la poudre sur ces points d'apparition les supprimera définitivement. Débloqué en devenant ami avec la Prêtresse.
