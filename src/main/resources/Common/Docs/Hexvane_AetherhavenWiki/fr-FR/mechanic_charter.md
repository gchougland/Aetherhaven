# Charte de la ville

La charte est le point d'ancrage de votre ville. Placez-la une seule fois pour la créer, nommez-la et faites apparaître le villageois aîné pour commencer votre aventure de construction.

**Conseils**

* Si vous dissolvez la ville, tous les villageois et bâtiments seront supprimés.

* Vous pouvez déplacer la charte à l'aide du bouton de son menu.
