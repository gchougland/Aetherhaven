# 区画トークン

**区画トークン**は、**区画配置杖**で建物の種類を選択し、ワールド上に区画を配置するためにインベントリに所持するアイテムです。

## 区画製作台

**区画製作台**で区画トークンを製作します。製作台では、材料を投入する前に建物の**3Dプレビュー**が表示されます。製作台は**都市計画デスク**で製作し、他の作業台と同様に設置できます。

ほとんどのストーリークエストでは、最初のトークンはクエスト依頼者から直接入手できます。その後、補充や追加のトークンは通常、製作台から入手できます。

## 区画設計図

一部の建物は、風船から既製のトークンがドロップされるのではなく、**区画設計図**が必要になります。

1. 設計図アイテムを**使用**して、区画製作台でその区画を永久にアンロックします。

2. 製作台を開き、区画トークンを製作します（材料とゴールドが必要。他のトークンと同様）。

3. **区画配置杖**を装備し、足跡を杭で固定します。

**白い浮遊ギフト**には設計図が入っていることが多いです。緑のギフトには宝石類、赤いギフトには家具が入っていることが多いです。風船型のギフトは以前よりも入手困難になっています。

## 回収

余った区画トークン（ギフトから入手したバリアントトークンを含む）は、不要になった場合、作業台で**回収**して金貨に交換できます。

**ヒント**

* 建物に商人の屋台がある場合は、「ゲームシステム」の「プレイヤーショップとショップスポット」の項目を参照してください。

* 花屋、花火師、クリスタルキーパーのショップクエストでは、トークンではなく設計図が報酬として得られます。
