# はじめに

このページでは、何もない場所から、金を稼ぎ、村人を迎える町へと発展させるまでの道のりをご紹介します。

## 町づくり

1. 作業台で**町づくりデスク**を作成します。

2. デスクを使って**町の設立許可証**と**区画配置杖**を作成します。

3. 町の中心となる場所に町の設立許可証を設置します。町は最初はランダムな名前になります。後で町の設立許可証を開いて名前を変更できます。

4. **長老ライレン**が現れます。彼に話しかけてクエストを開始しましょう。

町の設立許可証は町の境界を示します。町の設立許可証の移動や交換については、「ゲームシステム」の**町の設立許可証**のページをご覧ください。

## 最初のクエスト：宿屋を建てよう

ライレンはあなたに**宿屋を建てる**ように依頼します。具体的には、以下の手順で進めます。

1. ライレンに話しかけてクエストを受諾します。彼はあなたに**宿屋の区画トークン**を渡します（建築クエストの区画トークンは、計画デスクではなくクエスト依頼者から受け取ります）。

2. **区画配置杖**を装備し、宿屋の敷地を適切な場所に杭で固定します。

3. 指定された木材と石材を区画の看板まで運び、建設を完了させます。

宿屋が完成すると、**宿屋の主人**が引っ越してきます。宿屋はあなたの最初の本格的な建物であり、町の記録の拠点となります。

## 宿屋のメリット

宿屋は単なる壁と屋根以上のものです。

* **訪問者**は滞在できます。宿屋には一度に最大2人まで宿泊できます。訪問者クエストで滞在が固定されている場合を除き、ゲストリストは毎朝更新されます。

* 宿屋には**町の記録棚**があり、村人のニーズを確認したり、友達を町に招待したり、後で贈り物の履歴を確認したりできます。


宿泊客に関する詳しい情報は、「ゲームシステム」の「宿屋のプールと宿泊客」をご覧ください。

## お金と税金

あなたの町は、朝の「十分の一税」で**金貨**を稼ぎます。住民としてカウントされる各村人は、快適度に応じて税金を支払います。快適度とは、**空腹度**、**エネルギー**、**楽しさ**のメーターが良好な状態であることを意味します。

税金の徴収は、町民のうち少なくとも1人がオンラインになっている間行われます。町役場を建設した後、財務部を開くと、金貨の集計状況と、誰がいくら支払ったかの内訳を確認できます。

宴会ボーナス、政策、その他の収入を増やす方法については、「ゲームシステム」の「財務部と税金」をご覧ください。

## 町役場と財務部

宿屋が完成したら、再びライレンに話しかけてください。彼は**町役場を建てる**ことを提案します。宿屋を建てたのと同じ方法で建設してください。クエストで入手した区画トークンを使用し、設置用の杖を使ってから、看板の場所に材料を運びます。 **町役場**には、金貨を保管する**金庫**ブロックがあります。また、**町の記録棚**と計画スペースも備えています。税金の預け入れ、引き出し、そして税制上の項目の確認をすべて一箇所で行いたい場合は、町役場が必要です。

## 市民とは

村人が町の一員となるには、2つの方法があります。

**職場（町での仕事に必須）**
村人の仕事（農場、商店、製粉所など）のための区画を建設し、完成させます。その建物にある**管理ブロック**を使って、村人を職場に割り当てます。職場が決まるまでは、村人は正式な住民ではなく、ゲストまたは訪問者です。

**家（任意）**
村人が働くために**家屋の区画**は必須ではありません。家を建てて村人を登録すれば、村人はそこで夜を過ごすことができます。睡眠は**エネルギー**を回復させ、毎朝支払う金貨の額にも影響します。 **楽しみ**のために**公園**を作りましょう（下記参照）。

成長の準備ができたら、宿屋で村人や訪問者からクエストの依頼を受けましょう。新しい職場を完成させるごとに、新たな住民が加わります。

## ヒント

* 村人の**楽しさ**が不足しがちなら、**公園**を作りましょう。公園のベンチは、楽しさを回復させる主な手段です。**ゲームシステム**を開き、「村人のニーズ」ページで、空腹、エネルギー、楽しさについて詳しく読んでください。

* より良い価格、レシピ、マイルストーン報酬を得たいなら、村人と頻繁に会話したり、贈り物をしたりしましょう。「ゲームシステム」の**評判**を参照してください。

* **役場**を建設した後は、**ゲームシステム**で**ギルドホールと衛兵**、**クエスト掲示板**、**観光ポータル**、その他のゲーム中盤のシステムについて読んでください。

* サーバーホストは、`/ah starterkit`などのクリエイティブモードツールを使用して、クラフトをスキップできます。これはテスト用であり、通常のプレイヤーのプレイ方法ではありません。
