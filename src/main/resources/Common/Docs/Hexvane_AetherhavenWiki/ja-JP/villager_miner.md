**ゴルク・ストーンベイン**は、通常、**鉱夫小屋**で勤務しています。

### クエスト

#### ゴルクの家
ゴルクは、他の区画トークンを持つ者と同様に、宿屋の床ではなく、ちゃんとした家を欲しがっています。

1. ゴルクから家の区画トークンを受け取ります。

2. プレハブ住宅を杭打ちして建設します。

3. 住宅管理ブロックでゴルクを居住者として設定します。

4. ゴルクを見つけ、会話でクエストを完了します。

#### ゴルクの鉱夫小屋
ゴルクが宿屋を混雑させることなく石や鉱石を運べるように、ちゃんとした小屋と作業台を用意してあげましょう。

1. ゴルクから鉱夫小屋の区画トークンを受け取ります。

2. プレハブ住宅を杭打ちして建設します。

3. 作業台のゴルクを見つけ、会話でクエストを完了してください。

### 友情報酬

友情レベルが上がるごとに、ゴルクを訪ねて会話で報酬を受け取りましょう。

- **友情レベル50:** **光る指輪 **1個**

- **友情レベル100:** **大きな光る指輪 **1個**
