# 浮かぶ贈り物

時折、包まれた贈り物が街の上空を漂っています。流されてしまう前に撃ち落としましょう。

贈り物は3色あります。それぞれの色の贈り物箱には、異なる宝物が入っています。

白い贈り物には、建物の設計図、金貨、便利な道具などが入っていることが多いです。

緑の贈り物には、宝石、金貨、便利な道具などが入っています。

赤い贈り物には、家具、金貨、便利な道具などが入っています。
