# 宿屋の宿泊客と訪問者

宿屋では、常住者以外の訪問者を受け入れることができます。宿泊客は最大2名までで、毎日夜明けに更新され、再抽選されます。訪問者クエストを受諾している場合は、クエストは確定され、再抽選されません。

## デバッグ

宿屋の訪問者が表示されない、または何らかの不具合が発生している場合は、`/ah villager fixinn` コマンドを実行してみてください。
