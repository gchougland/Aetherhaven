# ジュエリー

ジュエリーは、世界各地の戦利品チェストから時折入手できます。新しく入手したジュエリーは未鑑定です。ジュエリーの効果を鑑定してもらうには、商人ヴェックスに持っていきましょう。ジュエリーには5つのレアリティ（コモン、アンコモン、レア、ミシック、レジェンダリー）があります。金は銀よりも強く、ネックレスは指輪よりも強いです。宝石の種類によって、ジュエリーがどのステータスに影響を与えるかが決まります。商人との仲が良ければ、鑑定台とジュエリー製作台のレシピを教えてくれます。鑑定台ではジュエリーを無料で鑑定できます。ジュエリー製作台では、金/銀のインゴット、宝石、そして生命のエッセンスを使って、自分だけのジュエリーを作ることができます。生命のエッセンスの量が多いほど、品質が高くなります。

## 宝石のステータス

宝石の種類によって、ジュエリーに付与される3つのプレイヤーステータスが決まります。具体的な数値は、レア度、金属の種類、指輪かネックレスかによって異なります。

* **ゼファー** — スタミナ、シグネチャーエネルギー、酸素
* **トパーズ** — スタミナ、シグネチャーエネルギー、弾薬
* **エメラルド** — 体力、マナ、酸素
* **ダイヤモンド** — 体力、スタミナ、マナ
* **サファイア** — マナ、スタミナ、酸素
* **ルビー** — 体力、スタミナ、弾薬
* **ヴォイドストーン** — マナ、シグネチャーエネルギー、弾薬

**ヒント**

* 余ったジュエリーは村人への贈り物に最適です。贈り物が友好度にどう影響するかについては、「ゲームシステム」の「評判」をご覧ください。
