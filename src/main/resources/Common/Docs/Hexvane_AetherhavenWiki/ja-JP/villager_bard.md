**エリアス・ソーンウッド**は町の**吟遊詩人**です。**ギルドホール**が建設された後、彼は宿屋に現れ、日中はギルドホールで演奏します。

**下の**週間スケジュールを表示**を使って、エリアスの毎日の行き先を確認してください。

### クエスト

#### エリアスの家
エリアスはほとんど毎日ギルドホールで演奏しています。彼は夜、自分だけの静かな屋根の下で過ごしたいと考えています。

1. エリアスから家の区画トークンを受け取ります。

2. プレハブの家を建て、杭を打ちます。

3. 家の管理ブロックでエリアスを居住者として登録します。

4. エリアスを見つけ、会話でクエストを完了します。
