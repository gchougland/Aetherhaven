# 町の記録棚

町の記録棚は、町の情報と管理の中心となる場所です。ニーズタブでは、すべての村人の現在のニーズを確認したり、テレポートボタンを使って村人を自分のところにテレポートさせたりできます。村人の贈り物の好みも確認できます。各村人に贈った贈り物とその反応が表示されます。町の管理タブでは、町にプレイヤーを招待したり管理したりできます。プレイヤー名をクリックすると、そのプレイヤーの町の権限を管理できます。移動ボタンを使って建物を移動できます。（建物を移動する際は注意してください。配置時に建物の一部ではなかったものはすべて破壊されます。動物などのエンティティも含まれます。）

## 生産施設のアップグレード

**生産施設**（農場、製材所、鉱夫小屋、納屋、その他同様の作業場）の棚を開くと、**アップグレード**できます。アップグレードは、建物の種類に応じて生産量または生産能力を向上させます。費用と段階は棚のUIに表示されます。表示されている町の資源または材料で支払ってください。アップグレードはストーリー進行に合わせて継続されます。新しい職場をクリアしたら、棚を確認して最初のティアで何がアンロックされるかを確認してください。
