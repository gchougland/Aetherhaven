**セレン・フェアホロー**は、シフト勤務中は通常**製材所**にいます。

### クエスト

#### セレンの家
セレンは、製材所から借りた屋根ではなく、自分のベッドのある家を望んでいます。

1. セレンから家の区画トークンを受け取ります。

2. プレハブ住宅を杭打ちして建てます。

3. 家の管理ブロックでセレンを居住者として登録します。

4. セレンを見つけて、会話でクエストを完了します。

#### セレンの製材所
セレンが共有スペースをうろうろする代わりに、町のために木材を積み上げて作業できるように、製材所を建設しましょう。

1. セレンから製材所の区画トークンを受け取ります。

2. プレハブ製材所を杭打ちして建てます。

3. デスクにいるセレンを見つけて、会話でクエストを完了します。

### 友情報酬

友情レベルが上がるごとに、相手を訪ねて会話することで報酬を受け取ることができます。

- **友情レベル50**：**薪**の作り方を習得できます。
- **友情レベル100**：**根っこ除去器**の作り方を習得できます。
