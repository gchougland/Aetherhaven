# よくある質問

ここに掲載されている回答は、プレイ中のクイックリファレンスとしてご利用ください。それでも不明な点がある場合は、**ゲームシステム**または**村人**の項目で詳細をご確認ください。

## このMODには*この機能*はありますか？

おそらく実装される予定ですが、ロードマップをご確認ください。MODのDiscordサーバーでは、いつでもご提案を歓迎しています。

## バグ報告や機能提案はどこでできますか？

バグ報告や機能リクエストは、MODのDiscordチャンネルで受け付けています。ゲームのバージョンと、シングルプレイかサーバープレイかを明記していただけると、やり取りの手間が省けます。

## MODのアップデートでセーブデータが破損することはありますか？

データの移行は安全に行えるよう努めていますが、特に長期サーバーでは、メジャーアップデートの前に**ワールドのバックアップ**を取っておくことをお勧めします。

## 既存のプレハブではなく、自分で建物を設計することはできますか？

統合建築ツールは、MODの実装予定機能です。現時点では、建物を追加するにはかなりの設定作業が必要です。建物は建設後に破壊/交換できますが、特定の家具やベンチを壊したり移動したりすると、村人がその建物を使ってニーズを満たすことができなくなる場合があることに注意してください。例えば、ベッドを移動すると、村人はベッドを見つけることができなくなります。メインのMODにクレジット付きであなたの建築物を掲載したい場合は、Discordに建築物投稿チャンネルがあります。
