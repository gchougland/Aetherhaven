# 生産用ワードローブ

生産施設では、生成される資源の設定とアクセスにワードローブ型のチェストを使用します。施設内のワードローブを見つけて操作すると、生産ウィンドウが開きます。矢印を使って、生産可能な資源を切り替えることができます。各資源は個別に保管されます。同じ資源を複数選択すると、生産速度が向上します。アンロックページでは、その資源とゴールドコインを消費することで、新しい資源をアンロックして生成できるようになります。

*将来的には、施設の最大保管容量と生産速度をアップグレードできるようになります。*
