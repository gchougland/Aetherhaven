# クエスト掲示板

ギルドホールにあるクエスト掲示板には、町の日々の仕事が掲載されています。掲示板を操作すると、今日の仕事が3枚表示されたパネルが開きます。

町の住民が少なくとも1人オンラインになっている場合、毎朝新しいカードが更新されます。

## 仕事の種類

### 物資調達

町民が町に物資を届けてほしいと依頼しています。依頼を受け、リストにあるアイテムを集め、**依頼者の会話を通して納品してください。** ランクが上がると、より難しい依頼とより良い報酬が得られます。

### 狩猟

特定のモンスターを一定数倒し、依頼者に報告してください。進行状況はカードとジャーナルに表示されます。

### 襲撃

町の郊外に敵の集団が出現し、町の境界に向かって進軍してきます。集団内のすべてのモンスターを倒すと、依頼完了です。 **マップマーカー**と**襲撃体力ゲージ**は、クエストの対象となる敵を示します。

## ランクと報酬

ボードクエストを完了するごとに、町の**ランクXP**が獲得できます。**町のランク**が高くなると、より難易度の高いティアが解放され、報酬も向上します。カードには**期限**（日数）が表示されています。期限が切れるか、夜明けにスロットがクリアされる前にクエストを完了してください。

報酬には、ゴールド、アイテム、そしてクエストを投稿した村人との評判が含まれます（クエスト内容によっては）。

## 追跡

進行中のボードクエストは、ストーリークエストと同様に、町のジャーナルの**クエスト**タブに表示されます。気が変わった場合は、ジャーナルからボードクエストを放棄できます。

ボードが設置されるギルドホールの建設方法については、「システム」の**ギルドホールと警備員**をご覧ください。
