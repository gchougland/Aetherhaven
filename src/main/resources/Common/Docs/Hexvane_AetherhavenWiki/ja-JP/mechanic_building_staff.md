# 建築スタッフ

区画看板が設置されると、建築スタッフを使って建物を段階的に建設できます。ハイライト表示されたブロックを狙い、各ブロックの配置を確定してください。

区画看板で「建設」ボタンを押すと、建物はゆっくりと建設を開始します。建築スタッフを使用すると、建設速度を上げることができます。スタッフを持っている間、ブロックを配置する場所に緑色の立方体が表示されます。立方体を見ながらスタッフを持った状態でセカンダリアクション（右クリック）を押すと、立方体が拡大し、建物のブロックが配置されます。緑色の立方体が見つからない場合は、プライマリアクション（左クリック）で最も近い緑色の立方体を追尾する弾丸を発射できます。建築スタッフには複数のティアがあり、それぞれ建築範囲が広がります。

スタッフを持っている間、最大マナが増加します。セカンダリアクションでブロックを配置すると、マナバーからブロック1個につき1マナ消費します。スタッフを持ったままセカンダリアクションを数秒間停止すると、マナの回復速度が速くなります。


**ヒント**

* スタッフが高所作業を行う際は、足場を使用してください。

* 大規模な建物は、公演用に建設する際に複数のセクションに分割されます。
