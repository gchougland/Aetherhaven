# Добро пожаловать в руководство

Эта книга находится в вашем городском журнале. Выберите тему слева, чтобы узнать больше.

**Начало работы** расскажет вам об основании города, ваших первых зданиях и о том, как поступают деньги.

**Механика** объяснит инструменты, здания и системы, которые вы будете использовать в городе.

**Жители** познакомит вас с каждым жителем, их сюжетными заданиями, подарками репутации и еженедельными распорядками. Спойлеры к подаркам останутся скрытыми, пока вы сами не решите их показать.
