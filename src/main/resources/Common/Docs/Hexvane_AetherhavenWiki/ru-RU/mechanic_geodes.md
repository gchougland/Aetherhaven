# Геоды

Геоды — это крупные камни, которые редко встречаются при добыче руды и кристаллов. Городской кузнец может расколоть их для вас за определённую плату. Раскалывая геоды, можно получить руду, осколки кристаллов и, изредка, драгоценные камни. Если кузнец достаточно хорошо к вам относится, он поделится рецептом наковальни для геод, которая позволит раскалывать геоды бесплатно.
