# Бассейн в гостинице и посетители

В гостинице могут размещаться посетители, не являющиеся постоянными жителями. Гостиница может вместить до 2 посетителей одновременно, обновление и перераспределение происходит ежедневно на рассвете. Если вы приняли задание на посетителя, оно будет заблокировано и не будет перераспределено.

## Отладка

Если посетители гостиницы не отображаются или с ними что-то не так, попробуйте выполнить команду `/ah villager fixinn`.
