# Гильдия и стража

**Гильдия** — это общественное здание, которое строится в середине игры, где собираются искатели приключений. **Лира Фэйрхоллоу** просит вас построить его после того, как будет построена ратуша. Описание задания по строительству смотрите на странице жителя деревни.

После завершения строительства вы можете нанять **стражей**, нарисовать **маршруты патрулирования** и использовать **командный пункт** для обзора поля боя сверху.

## Наём стражей

Поговорите с искателями приключений в гильдии, чтобы нанять их в качестве **стражей**. Стражи бывают рыцарями, лучниками и магами. Они патрулируют ваш город и сражаются с враждебными мобами. Они не будут нападать на жителей деревни, туристов или других стражей.

Стражам нужен маршрут или приказы, чтобы знать, куда идти. Неназначенные стражи по-прежнему защищают находящиеся поблизости угрозы, когда это возможно.

## Патронажная палочка

Изготовьте **патронажную палочку** на **столе городского планирования**. Синие искорки отмечают сохраненные маршруты только во время удержания волшебной палочки.

### Режим строительства (по умолчанию)

* **Щелчок правой кнопкой мыши по земле** — добавить точку патрулирования.

* **Щелчок правой кнопкой мыши по точке** — удалить её.

* **Щелчок левой кнопкой мыши по точке на сохраненном маршруте** — выбрать этот маршрут для редактирования.

* **F** — назвать и сохранить маршрут (требуется не менее двух точек).

* **R** — переключать режим **замкнутого круга** (охранники движутся по кругу от последней точки обратно к первой) на **постоянно туда-обратно**.

* **E** — начать новый маршрут.

* **Q** — переключиться в режим назначения.

### Режим назначения

* **Щелчок левой кнопкой мыши по точке маршрута** — выбрать сохраненный маршрут.

* **F** — открыть список охранников и назначить кого-либо на маршрут.

* **E** — удалить охранника с выбранного маршрута.

* **Q** — переключиться в режим строительства.

Выбранные маршруты подсвечиваются **зелёным**; другие маршруты остаются **синими**. Охранники, имеющие более одного маршрута, по очереди проходят каждый круг.

## Командный пункт

Разместите в городе **стульё для командного пункта охранников** (доступно в творческом режиме или по мере развития игры). **Используйте** его, чтобы войти в **режим управления** — вид сверху на ваш город в стиле стратегии в реальном времени.

### Камера и выделение

* **WASD** — панорамирование поля боя.

* **Пробел / Ctrl** — масштабирование вверх и вниз.

* **Клавиши прокрутки или цифровые клавиши** — переключение инструментов управления.

* **Щёлкните по охраннику** — выберите его.

* **Shift + щелчок** — добавление или удаление из выделения.

* **Перетащите рамку** — выберите сразу много охранников.

### Приказы

* **Инструмент атаки/перемещения** — щёлкните правой кнопкой мыши по земле, чтобы отправить выбранных охранников. **Способность 1** переключает режимы атаки и перемещения, а также только перемещения. **Способность 2** останавливает выбранных охранников.

* **Инструмент фокусировки огня** — щелкните правой кнопкой мыши по существу, чтобы сосредоточить на нем своих охранников.

* **Инструмент стойки** — **Способность 1** переключает боевую стойку (оборонительная, агрессивная, стояние на месте, отказ от огня) для выбранных охранников.

* **Инструмент освобождения** — щелкните правой кнопкой мыши, чтобы освободить выбранных охранников от ваших приказов.

* **Выбрать всех / по типу** — кнопки списка на HUD.

* **Инструмент выхода из командного пункта (слот панели быстрого доступа 8)** — выйти из командного режима.

Командный пункт должен находиться **внутри ваших городских земель**, чтобы работать. Вам нужен как минимум один наемный охранник.
