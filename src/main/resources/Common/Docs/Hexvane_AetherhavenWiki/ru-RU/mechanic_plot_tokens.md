# Жетоны участков

**Жетоны участков** — это предметы, которые вы держите в инвентаре, чтобы выбрать тип здания на **менеджере по размещению участков**, а затем разместить его на карте мира.

## Верстак для создания участков

Создавайте жетоны участков на **верстаке для создания участков**. Верстак показывает **3D-предварительный просмотр** здания, прежде чем вы потратите материалы. Создайте верстак на **столе городского планирования**, а затем разместите его, как любую другую рабочую станцию.

В большинстве сюжетных заданий первый жетон выдается непосредственно от квестодателя. После этого замены и дополнительные копии обычно появляются на верстаке.

## Чертежи участков

Некоторые здания доступны только по **чертежам участков**, а не по готовым жетонам, выпадающим из воздушных шаров.

1. **Используйте** чертеж, чтобы навсегда разблокировать этот участок на вашем верстаке для создания участков.

2. Откройте верстак и изготовьте жетон участка (материалы плюс золото, как и для других жетонов).

3. Экипируйте **посох размещения участка** и закрепите место.

**Белые летающие подарки** часто содержат чертежи. Зеленые подарки — это украшения; красные — мебель. Подарки в виде воздушных шаров встречаются реже, чем раньше.

## Разборка

Дополнительные жетоны участков — включая варианты жетонов из подарков — можно **разобрать** на золотые монеты на верстаке, если вам не нужна еще одна копия.

**Советы**

* Прочитайте **Магазин игрока и торговые места** в разделе «Механика», если в здании есть торговые лавки.

* Задания в магазинах «Флорист», «Пиротехник» и «Хранитель кристаллов» дают чертежи, а не жетоны напрямую.
