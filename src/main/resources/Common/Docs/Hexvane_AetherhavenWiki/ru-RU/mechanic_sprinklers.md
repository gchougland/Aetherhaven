# Дождевальные установки

Дождевальные установки — это металлические помощники для больших полей. Активируйте одну из них, и она будет ежедневно, на рассвете, поливать посевы в зоне вокруг дождевателя. Её также можно активировать вручную с помощью блока. Разблокируется после того, как вы подружитесь с Фермером. Существует четыре уровня дождевателей, радиус полива которых увеличивается.
