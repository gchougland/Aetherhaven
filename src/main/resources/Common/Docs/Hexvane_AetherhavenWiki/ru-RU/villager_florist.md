**Айви Блумвелл** продает растения и цветы в своем **цветочном магазине** после его постройки. Она появляется в гостинице после того, как **рыночный прилавок Векс** будет достроен.

Используйте **Показать еженедельное расписание** ниже, чтобы увидеть, куда Айви отправляется каждый день.

### Задания

#### Цветочный магазин Айви
Айви хочет открыть настоящий магазин, где она сможет делиться своими растениями с жителями города.

1. Поговорите с Айви в гостинице и примите задание.

2. Возьмите у Айви **чертеж** магазина.

3. Используйте чертеж на **верстаке для создания участков**, чтобы изучить цветочный магазин.

4. Создайте жетон участка для магазина и постройте префаб цветочного магазина.

5. Найдите Айви в магазине и завершите задание в диалоге.

#### Дом Айви
Даже флорист, которая весь день разговаривает со своими растениями, заслуживает тихого места для отдыха.

1. Возьмите у Айви жетон участка под дом.

2. Установите колышек и постройте сборный дом.

3. Назначьте Айви жительницей в блоке управления домом.

4. Найдите Айви и завершите задание в диалоге.
