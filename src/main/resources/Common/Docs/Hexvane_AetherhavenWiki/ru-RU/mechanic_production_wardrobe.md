# Производственный шкаф

В производственных зданиях используется сундук в виде шкафа для настройки и доступа к производимым ресурсам. Найдите шкаф в здании и взаимодействуйте с ним, чтобы открыть окно производства. Вы можете переключаться между доступными ресурсами для производства с помощью стрелок. Каждый тип ресурса хранится отдельно. Выбор нескольких одинаковых ресурсов увеличивает скорость их производства. На странице разблокировки вы можете разблокировать новые ресурсы для производства за счет части этого ресурса и золотых монет.

*В будущем вы сможете увеличить максимальное хранилище и скорость производства зданий.*
