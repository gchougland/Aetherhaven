# Жители деревни

На каждой странице описаны **квесты**, **награды за дружбу**, **еженедельный распорядок** и **предпочтения в подарках** для одного из жителей. Используйте журнал, если хотите видеть тот же список подарков в скрытом режиме во время игры.
