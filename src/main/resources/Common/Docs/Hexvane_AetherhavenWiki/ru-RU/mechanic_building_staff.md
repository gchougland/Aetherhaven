# Строительный посох

После установки таблички с указанием участка, строительный посох позволяет вам поэтапно развивать сооружение. Наводите прицел на выделенные блоки и подтверждайте каждую партию.

После нажатия кнопки «СТРОИТЬ» на табличке с указанием участка, здание начнет медленно строиться. Использование строительного посоха позволяет ускорить этот процесс. Пока вы держите посох, в местах, где нужно разместить блоки, появятся зеленые кубы. Удерживая дополнительное действие (правая кнопка мыши) посохом, глядя на эти кубы, вы заставите кубы расшириться и разместить блоки для здания. Если вы не можете найти зеленые кубы, вы можете использовать основное действие (левая кнопка мыши), чтобы выстрелить снарядом, который наводится на ближайший зеленый куб. Существует несколько уровней строительного посоха с увеличивающимся радиусом строительства.

Каждый посох дает дополнительное максимальное количество маны, пока вы его держите. Размещение блоков с помощью дополнительного действия стоит 1 единицу маны за блок из вашей шкалы маны. Если вы прекратите использовать дополнительное действие на пару секунд, мана будет восстанавливаться быстрее, пока вы продолжаете держать посох.


**Советы**

* Используйте строительные леса, чтобы персонал мог подняться на большую высоту.

* Очень большие здания при строительстве для выступлений делятся на секции.
