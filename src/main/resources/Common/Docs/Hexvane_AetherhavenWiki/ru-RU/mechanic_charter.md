# Устав города

Устав — это ваш городской якорь. Разместите его один раз, чтобы создать город, дайте ему название и призовите старейшину, чтобы начать своё приключение по строительству города.

**Советы**
* Если вы распустите город, все жители и здания будут удалены.

* Вы можете переместить устав, используя кнопку в его меню.
