# Aspersores

Os aspersores são ferramentas metálicas úteis para grandes plantações. Ao ativar um, ele irriga as plantações em uma área ao redor do aspersor uma vez por dia, ao amanhecer. Também pode ser ativado manualmente usando o bloco. Desbloqueado ao se tornar amigo do Fazendeiro. Existem quatro níveis de aspersor para desbloquear, com raio de irrigação crescente.
