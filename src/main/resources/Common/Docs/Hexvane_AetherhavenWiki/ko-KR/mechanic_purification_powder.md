# 정화의 가루

정화의 가루는 생성된 구조물에서 적의 생성 지점을 제거할 수 있게 해줍니다. 가루를 들고 있으면 구조물에서 적이 주기적으로 생성되는 위치에 작은 회전하는 적의 모습이 나타납니다. 이 위치에 가루를 사용하면 생성 지점이 영구적으로 제거됩니다. 여사제와 친해지면 사용할 수 있습니다.
