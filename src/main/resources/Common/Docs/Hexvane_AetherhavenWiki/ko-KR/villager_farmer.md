**이리엔 모스마크**는 보통 근무 시간일 때 **농장**에서 찾을 수 있습니다.

### 퀘스트

#### 이리엔의 농장
이리엔에게 울타리가 쳐진 땅과 작업대를 만들어 주세요. 그러면 그녀는 더 이상 여관 바닥에 줄지어 놓인 밭을 꿈꾸지 않아도 될 거예요.

1. 이리엔에게서 농장 부지 토큰을 가져옵니다.

2. 농장 부지에 말뚝을 박고 조립식 건물을 짓습니다.

3. 작업대에서 이리엔을 찾아 대화창에서 퀘스트를 완료합니다.

#### 이리엔의 집
이리엔은 주전자 옆에 남이 빌려 쓴 마룻바닥이 아니라, 자기 집 서까래 아래에 뿌리가 내리길 원해요.

1. 이리엔에게서 집 부지 토큰을 가져옵니다.

2. 집 조립식 건물을 설치하고 짓습니다.

3. 집 관리 화면에서 이리엔을 거주자로 지정합니다.

4. 이리엔을 찾아 대화창에서 퀘스트를 완료합니다.

### 우정 보상

우정 레벨이 각 단계에 도달하면 해당 동료를 방문하여 대화를 통해 보상을 받으세요.

- **우정 25:** **스프링클러 철** 제작법을 배웁니다.
- **우정 50:** **스프링클러 토륨** 제작법을 배웁니다.
- **우정 75:** **스프링클러 코발트** 제작법을 배웁니다.
- **우정 100:** **스프링클러 아다만타이트** 제작법을 배웁니다.
