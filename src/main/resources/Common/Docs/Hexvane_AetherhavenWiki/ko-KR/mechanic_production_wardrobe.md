# 생산 창고

생산 건물은 생산된 자원을 구성하고 접근하기 위해 옷장 형태의 상자를 사용합니다. 건물에서 옷장을 찾아 상호작용하면 생산 창이 열립니다. 화살표를 사용하여 생산 가능한 자원을 순환하며 선택할 수 있습니다. 각 자원 유형은 별도로 저장됩니다. 동일한 자원을 여러 개 선택하면 생산 속도가 빨라집니다. 잠금 해제 페이지에서는 해당 자원과 금화를 소모하여 새로운 자원을 생산할 수 있도록 잠금 해제할 수 있습니다.

*향후 건물의 최대 저장 용량과 생산 속도를 업그레이드할 수 있게 될 예정입니다.*
