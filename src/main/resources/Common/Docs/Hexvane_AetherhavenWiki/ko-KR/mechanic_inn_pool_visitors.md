# 여관 투숙객 및 방문객

여관은 상주 투숙객이 아닌 방문객을 맞이할 수 있습니다. 여관은 한 번에 최대 2명의 방문객을 수용할 수 있으며, 매일 새벽에 방문객 목록이 갱신되고 새로운 방문객이 생성됩니다. 방문객의 퀘스트를 수락한 경우, 해당 방문객은 고정되어 갱신되지 않습니다.

## 디버깅

여관 방문객이 표시되지 않거나 문제가 발생하는 경우, `/ah villager fixinn` 명령어를 실행해 보세요.
