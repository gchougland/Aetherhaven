# 길드 회관과 경비병

**길드 회관**은 모험가들이 모이는 중반부 마을 회관입니다. 마을 회관이 완공되면 **라이라 페어할로우**가 길드 회관 건설을 의뢰합니다. 건설 퀘스트에 대한 자세한 내용은 그녀의 마을 주민 페이지를 참조하세요.

길드 회관이 완공되면 **경비병**을 고용하고, **순찰 경로**를 설정하고, **지휘소**에서 전장을 위에서 내려다보는 시점으로 볼 수 있습니다.

## 경비병 고용

길드 회관에서 모험가들에게 말을 걸어 **경비병**을 고용하세요. 경비병은 기사, 궁수, 마법사로 구성되어 있으며, 마을을 순찰하고 적대적인 몬스터와 싸웁니다. 마을 주민, 관광객, 다른 경비병은 공격하지 않습니다.

경비병은 순찰 경로 또는 명령이 있어야 이동할 곳을 알 수 있습니다. 배정되지 않은 경비병도 가능한 경우 주변의 위협을 방어합니다.

## 순찰 지팡이

**마을 계획 데스크**에서 **순찰 지팡이**를 제작하세요. 지팡이를 들고 있을 때만 저장된 순찰 경로에 파란색 반짝임이 표시됩니다.

### 건설 모드 (기본값)

* **땅을 마우스 오른쪽 버튼으로 클릭** - 순찰 지점을 추가합니다.

* **지점을 마우스 오른쪽 버튼으로 클릭** - 지점을 제거합니다.

* **저장된 경로의 지점을 마우스 왼쪽 버튼으로 클릭** - 해당 경로를 편집 모드로 선택합니다.

* **F** - 경로 이름을 지정하고 저장합니다(최소 두 개의 지점이 필요합니다).

* **R** - **폐쇄 루프**(경비병이 마지막 지점에서 첫 번째 지점으로 돌아오는 순환 순찰)와 **왕복 순찰** 모드를 전환합니다.

* **E** - 새로운 경로를 생성합니다.

* **Q** - 할당 모드로 전환합니다.

### 할당 모드

* **경로 지점을 마우스 왼쪽 버튼으로 클릭** - 저장된 경로를 선택합니다.

* **F** - 경비병 목록을 열고 해당 경로에 경비병을 할당합니다.

* **E** - 선택한 경로에서 경비병을 해제합니다.

* **Q** - 건설 모드로 전환합니다.

선택된 경로는 **녹색**으로 빛나고, 다른 경로는 **파란색**으로 표시됩니다. 여러 경로를 담당하는 경비병은 각 순환 순찰을 번갈아 수행합니다.

## 지휘소

마을에 **경비 지휘소** 의자를 설치하세요(크리에이티브 모드 또는 진행 상황 잠금 해제). **이 의자를** 사용하면 **지휘 모드**에 진입하여 마을을 위에서 내려다보는 RTS 스타일 시점으로 볼 수 있습니다.

### 카메라 및 선택

* **WASD** - 전장을 이동합니다.

* **스페이스/Ctrl** - 위아래로 이동하여 확대/축소합니다.

* **스크롤 또는 숫자 키** - 명령 도구를 전환합니다.

* **경비병 클릭** - 경비병을 선택합니다.

* **Shift + 클릭** - 선택 항목에 경비병을 추가하거나 제거합니다.

* **상자 드래그** - 여러 경비병을 한 번에 선택합니다.

### 명령

* **공격 이동/이동 도구** - 땅을 마우스 오른쪽 버튼으로 클릭하여 선택한 경비병을 이동시킵니다. **능력 1**은 공격 이동과 이동 전용 모드를 전환합니다. **능력 2**는 선택한 경비병을 정지시킵니다.

* **집중 사격 도구** - 적을 마우스 오른쪽 버튼으로 클릭하여 경비병의 집중 사격을 명령합니다.

* **자세 전환 도구** — **능력 1**을 사용하여 선택한 경비병의 전투 자세(방어, 공격, 제자리 유지, 사격 중지)를 전환합니다.

* **해제 도구** — 마우스 오른쪽 버튼을 클릭하여 선택한 경비병을 명령에서 해제합니다.

* **모두 선택 / 유형별 선택** — HUD의 병사 목록 버튼입니다.

* **명령 종료 도구(단축키 슬롯 8)** — 명령 모드를 종료합니다.

명령소는 작동하려면 **마을 부지 내**에 있어야 합니다. 최소 한 명의 고용된 경비병이 필요합니다.

## 퀘스트 게시판

길드 회관에는 일일 심부름, 사냥, 레이드 임무에 대한 **퀘스트 게시판**도 있습니다. 메커니즘 항목의 **퀘스트 게시판**을 참조하십시오.
