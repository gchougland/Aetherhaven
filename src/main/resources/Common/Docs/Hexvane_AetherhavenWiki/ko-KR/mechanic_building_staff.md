# 건축 지팡이

부지 표지판이 나타나면 건축 지팡이를 사용하여 구조물을 단계적으로 건설할 수 있습니다. 강조 표시된 블록을 조준하고 각 배치를 확인하세요.

부지 표지판에서 '건설' 버튼을 누르면 건물이 천천히 건설되기 시작합니다. 건축 지팡이를 사용하면 건설 속도를 높일 수 있습니다. 지팡이를 들고 있으면 블록을 놓아야 할 위치에 초록색 큐브가 나타납니다. 지팡이를 든 상태에서 보조 동작(마우스 오른쪽 버튼)을 누르고 있으면 큐브가 확장되어 건물에 필요한 블록을 배치합니다. 초록색 큐브를 찾을 수 없는 경우 기본 동작(마우스 왼쪽 버튼)을 사용하여 가장 가까운 초록색 큐브를 추적하는 투사체를 발사할 수 있습니다. 건축 지팡이는 등급에 따라 건설 반경이 증가합니다.

각 지팡이는 들고 있는 동안 최대 마나량을 증가시킵니다. 보조 동작으로 블록을 배치하면 마나 바에서 블록 하나당 1의 마나가 소모됩니다. 몇 초 동안 보조 동작을 사용하지 않으면 지팡이를 들고 있는 동안 마나가 더 빨리 회복됩니다.

**팁**

* 높은 곳에 직원이 올라갈 때는 비계를 사용하세요.

* 매우 큰 건물은 성능 향상을 위해 여러 구역으로 나누어 건축합니다.
