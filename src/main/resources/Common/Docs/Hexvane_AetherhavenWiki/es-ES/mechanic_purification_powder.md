# Polvo de purificación

El polvo de purificación permite al jugador eliminar los puntos de aparición de enemigos en las estructuras generadas. Al sostener el polvo, el jugador podrá ver pequeñas versiones giratorias de las criaturas que aparecen periódicamente en la estructura. Usar el polvo sobre estas criaturas eliminará el punto de aparición de forma permanente. Se desbloquea al hacerse amigo de la Sacerdotisa.
