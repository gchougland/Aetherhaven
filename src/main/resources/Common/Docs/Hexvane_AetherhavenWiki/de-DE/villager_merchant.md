**Vex Sunderlane** betreibt einen **Gemischtwarenladen** an **Ladenplätzen** im Marktstand, sobald dieser gebaut ist. Der Warenbestand wird bei Sonnenaufgang aufgefüllt; drücke **F** auf einem Platz, um einzukaufen. Siehe **Spielerladen und Ladenplätze** unter Mechaniken.

### Quests

#### Vex' Zuhause
Vex kann seine Waren überall lagern. Sie möchte aber trotzdem eine trockene Ecke, die auf ihr Klopfen reagiert.

1. Nimm das Hausgrundstück von Vex.

2. Platziere das Haus-Fertighaus und baue es.

3. Weise Vex im Hausverwaltungsblock als Bewohner zu.

4. Suche Vex auf und schließe die Quest im Dialog ab.

#### Vex' Marktstand
Gib Vex eine Theke und ein Dach, damit Schrott einen sicheren Platz zum Landen hat.

1. Nimm das Marktstand-Grundstück von Vex.

2. Platziere das Marktstand-Fertighaus und baue es.

3. Suche Vex an seinem Stand auf und schließe die Quest im Dialog ab.

#### Dein eigener Laden
Errichte einen Laden, in dem du Waren an Stadtbewohner und Touristen verkaufen kannst.

1. Stelle zuerst **Vex' Marktstand** fertig.

2. Nimm das **Spielerladen**-Grundstückstoken von Vex.

3. Platziere das Spielerladen-Fertighaus und baue es.

4. Suche Vex auf und schließe die Quest im Dialog ab.

### Freundschaftsbelohnungen

Besuche Vex, sobald eure Freundschaft eine bestimmte Stufe erreicht hat, um die Belohnung im Dialog abzuholen.

- **Freundschaft 50:** Du lernst, die **Schätzbank** herzustellen.

- **Freundschaft 100:** Du lernst, die **Schmuckwerkbank** herzustellen.
