# Häufig gestellte Fragen

Die Antworten hier dienen als Kurzübersicht während des Spielens. Falls etwas unklar bleibt, finden Sie detailliertere Informationen unter **Spielmechaniken** oder **Bewohner**.

## Wird die Mod *diese* Funktion enthalten?

Die Antwort ist wahrscheinlich ja, aber werfen Sie einen Blick auf die Roadmap. Vorschläge sind im Discord-Kanal der Mod jederzeit willkommen.

## Wo kann ich Fehler melden oder Funktionen vorschlagen?

Fehler und Funktionswünsche können im Discord-Kanal der Mod eingereicht werden. Die Angabe Ihrer Spielversion und ob Sie im Einzelspielermodus oder auf einem Server spielen, spart viel Zeit und Aufwand.

## Werden Spielstände durch Mod-Updates beschädigt?

Wir bemühen uns, Datenmigrationen sicher zu gestalten, aber **sichern Sie Ihre Welt** vor größeren Updates – insbesondere auf Servern mit langer Laufzeit.

## Kann ich eigene Gebäude entwerfen, anstatt die vorhandenen Fertigbauten zu verwenden?

Integrierte Bauwerkzeuge sind als Funktion für die Mod geplant. Das Hinzufügen von Gebäuden erfordert derzeit einige Konfigurationsschritte. Gebäude können nach ihrer Errichtung abgerissen oder ersetzt werden. Beachte jedoch, dass das Zerstören oder Verschieben bestimmter Möbelstücke/Bänke dazu führen kann, dass Dorfbewohner sie nicht mehr nutzen können. Wenn du beispielsweise ihr Bett verschiebst, finden sie es nicht mehr. Auf unserem Discord-Server gibt es einen Kanal für Bauwerkseinreichungen. Wenn du möchtest, dass dein Bauwerk mit Namensnennung im Haupt-Mod vorgestellt wird, kannst du dies dort tun.
