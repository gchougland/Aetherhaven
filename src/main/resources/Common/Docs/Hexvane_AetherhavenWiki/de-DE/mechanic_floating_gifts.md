# Schwebende Geschenke

Manchmal schwebt ein verpacktes Geschenk über der Stadt. Schieß es ab, bevor es davonfliegt!

Es gibt Geschenke in drei Farben. Jede Farbe birgt unterschiedliche Schätze in einer passenden Geschenkbox.

Weiße Geschenke enthalten oft Baupläne, Goldmünzen und nützliche Vorräte.

Grüne Geschenke enthalten Schmuck, Goldmünzen und nützliche Vorräte.

Rote Geschenke enthalten Möbelstücke, Goldmünzen und nützliche Vorräte.
