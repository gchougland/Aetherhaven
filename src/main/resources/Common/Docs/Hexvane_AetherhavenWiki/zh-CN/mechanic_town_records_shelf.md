# 城镇记录架

城镇记录架是您城镇信息和控制的中心。在“需求”选项卡中，您可以查看所有村民的当前需求，并使用传送按钮将他们传送到您身边。您还可以查看村民的礼物偏好。这里会显示您送给每个村民的礼物以及他们的反馈。在“城镇管理”选项卡中，您可以邀请和管理城镇中的玩家。您可以点击玩家名称来管理他们的城镇权限。您可以使用移动按钮重新排列建筑物。（移动建筑物时请小心，任何在建筑物放置时不属于该建筑物的物品都将被摧毁，包括动物等实体。）

## 生产建筑升级

打开**生产建筑**（农场、伐木场、矿工小屋、谷仓和类似的工作场所）的记录架即可**升级**它。升级会根据建筑类型提高产量或容量。费用和等级显示在记录架界面中——使用城镇资源或材料支付，费用按列表显示。

升级效果会随着剧情推进而保留。完成新的工作场所后，请查看货架，了解第一级解锁的内容。
