# 任务板

**公会大厅**的任务板会发布你城镇的每日任务。与任务板互动即可打开一个三张卡片组成的面板，显示今日的任务。

每天**黎明**，只要你城镇中至少有一名成员在线，新的卡片就会刷新。

## 任务类型

### 收集

有村民需要你帮忙把物资运回镇上。接受任务，收集清单上的物品，然后**通过与村民对话**提交。等级越高，任务难度越大，奖励也越丰厚。

### 狩猎

击杀一定数量的特定怪物，然后向任务发布者汇报。进度会显示在任务卡片和你的任务日志中。

### 突袭

一群敌对生物会在**城镇郊外**刷新，并向你的城镇边界进发。击杀这群生物中的所有敌人即可完成任务。**地图标记**和**突袭血条**会显示哪些敌人计入任务进度。

## 等级与奖励

完成每个公告板任务都会为您的城镇赢得**等级经验值**。更高的**城镇等级**可以解锁难度更高的任务层级，并获得更丰厚的奖励。任务卡片会显示以天为单位的**时间限制**——请在任务过期或任务栏位在黎明清空前完成。

奖励包括金币、物品以及任务发布村民的声望（如有）。

## 任务追踪

活跃的公告板任务会与剧情任务一起显示在城镇日志的**任务**标签页中。如果您改变主意，可以从日志中放弃某个公告板任务。

有关如何建造公告板所在的公会大厅，请参阅“机制”下的**公会大厅和守卫**。
