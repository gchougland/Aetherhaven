# 地块创建器

地块创建器用于记录您在世界中建造的**自定义建筑**：占地面积、特殊方块、预制件导出、成本，以及（可选）在您的城镇中创建一个实时地块。大多数玩家应该使用**装饰**或**变体**，而不是下面列出的完整工作场所类型。

在熟悉流程时，请打开您的**城镇日志 → 指南 → 机制 → 地块创建器**（此页面）。游戏过程中：装备该创建器，按**F**开始或打开当前步骤面板，**单击**世界中的方块，**Q** / **E**上一步/下一步，**R**取消。

## 推荐路径

| 目标 | 建筑类型 | 备注 |

|------|----------------|-------|

| 装饰性建筑，无工作 | **装饰** | 可选的城镇记录架；无生产或村民逻辑。 |

| 现有建筑的替代外观 | **变体** |选择它属于哪个**主要**建筑类型（房屋、谷仓、旅馆等）。子步骤遵循该主要类型。|

| 新建工作场所/生产用地（模组）| **工作** | 用于添加新的工作场所类型；需要管理模块、生产存储和工作台面兴趣点。|

## 建筑类型（选择器）

**装饰** — 公园、道具和建筑，**不应**用作住宅、商店或工作场所。所需位置最少。

**变体** — 预制件，**计入**模组中已有的其他建筑 ID（例如，计入 `plot_house` 的自定义房屋）。从下拉菜单中选择主要类型；重要位置与该主要建筑相匹配。

**住宅** — 住宅用地：城镇记录架 + 睡眠兴趣点。

**工作区** — **开发者/内容作者使用。** 定义一个新的**工作区**式地块：城镇记录架、生产仓库和工作台面兴趣点。用于添加新的生产或工作建筑类型，不适用于普通外观装饰。

**休闲设施** — 娱乐或休闲（公园、祭坛式休闲设施）：记录架 + 娱乐/休憩兴趣点。

**商店** — 摊位或商店柜台：记录架 + 带有商店标签的工作兴趣点。

**旅店** — 完整的旅店布局：记录架、工作台面、床位、用餐区、旅店老板和访客刷新点（以及可选的公会会长刷新点）。

**市政厅** — 市政中心：记录架、金库、规划台兴趣点。

**公会大厅** — 冒险者公会：记录架、工作台面、冒险者刷新点。

### 重叠与混淆

- **变体** 与 **住宅/工作场所/…** — “变体”用于“外观不同，功能类似 X”。如果您要重新设计现有游戏建筑的外观，请选择 **变体** + 主类型，而不是 **住宅**。

- **工作场所** 与 **商店** — **商店** 用于商贩摊位。**工作场所** 用于农场、磨坊、铁匠铺和其他生产场所。

- **休闲设施** 与 **装饰** — **装饰** 几乎没有游戏机制关联。**休闲设施** 设置村民日程的娱乐/休闲标签和兴趣点。

- **旅店**、**市政厅** 和 **公会大厅** 是完整的模板；仅当您有意匹配这些模板之一时才使用 **变体**。

## 流程（简版）

1. 标记两个对角和一个**外侧**地块标志角。

2. 选择**建筑类型**（以及适用的**变体**）。

3. 放置**重要位置**（方块会在每个子步骤中逐个放置）。

4. 输入**名称和 ID**（预制件文件名紧随 ID 之后）。

5. 如有需要，编辑**标签**。

6. 打开**建筑设置**（F）：金库金币消耗、自建天数、空地预制件选项和组装部分。

7. 在保存形状步骤中按 F **导出预制件**（使用步骤 6 中的设置）。

8. 设置**建筑材料**（虚拟箱子；物品会在您继续操作时返回）。

9. 检查并保存。

## 权限

默认情况下，配置可能允许所有人使用地块创建器；服务器可以改为要求 `aetherhaven.plot.creator` 权限。
