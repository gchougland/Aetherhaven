# 路径设计铲

**路径设计铲** 可以让你在城镇中绘制曲线路径，预览路径效果，并将方块放置在地面上。握持该工具时，会显示一个包含关键提示的状态面板。

在**城镇规划台**制作。

## 模式

按**Q**键可在五种模式之间切换：

1. **移动** — 添加和重新定位控制节点以塑造路径形状。

2. **旋转** — 旋转选定的节点以弯曲样条曲线。

3. **放置** — 将完成的路径固定在地面上。

4. **移除** — 查看已放置的路径（橙色高亮显示）并删除不再需要的路径。

5. **样式设计器** — 在网格状的箱子中创建和编辑路径样式。

当您准备放置路径方块时，HUD 会提醒您切换到**放置**模式。

## 按模式控制

### 移动、旋转和放置

* **在地面上使用辅助键（右键单击）** — 添加节点。

* **瞄准节点时使用辅助键** — 移除该节点。

* **在节点上使用主键（左键单击）** — 选择该节点。

* **在地面上使用主键（移动模式）** — 移动选定的节点。

* **F（旋转模式）** — 微调选定节点的方向。

* **F（放置模式）** — 将路径放置在地面上。

* **E** — 循环调整路径宽度。

* **R** — 循环调整路径样式。

* **Q** — 切换到下一个模式。

### 移除

* **主键** — 选择已放置的路径。

* **F** — 移除选定的路径。

* **Q** — 切换到下一个模式。

### 样式设计器

* **F** — 打开样式管理器（用于显示加权方块列的双格网格）。

* **E** — 保存路径样式（在样式管理器打开时）。

* **Q** — 进入下一模式。

## 预览效果

编辑时，白色节点和线条显示样条曲线。棕色预览标记方块的放置位置，两侧带有绿色边缘。**移除** 模式下，已确定的路径会以橙色显示。

## 提示

* 先在**移动**和**旋转**中调整样条曲线的形状，然后切换到**放置**并按**F**将其固定。

* 在**样式设计器**中创建自定义外观 — 每种样式都是沿着路径宽度滚动的加权方块列。

* 路径会保留在游戏世界和您的城镇存档中。
