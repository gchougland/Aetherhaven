**维克斯·桑德兰**经营着一家**杂货店**，店铺位于市场摊位内，摊位已建成。商品会在黎明时分补货；按下**F**键即可购买。请参阅“机制”下的“玩家商店和店铺位置”部分。

### 任务

#### 维克斯的家

维克斯可以随处堆放物品。但她仍然需要一个干燥的角落，并且有人会回应她的敲门声。

1. 从维克斯那里拿走房屋地块代币。

2. 圈地并建造房屋预制件。

3. 在房屋管理模块中将维克斯指定为住户。

4. 找到维克斯，并通过对话完成任务。

#### 维克斯的市场摊位

给维克斯一个柜台和一个屋顶，这样她就可以把回收物放在一个合适的地方了。

1. 从维克斯那里拿走市场摊位地块代币。

2. 圈地并建造市场摊位预制件。

3. 在摊位找到维克斯，对话完成任务。

#### 你的商店

建造一家商店，向镇民和游客出售商品。

1. 首先完成**维克斯的市场摊位**任务。

2. 从维克斯处获得**玩家商店**地块代币。

3. 圈地并建造玩家商店预制件。

4. 找到维克斯，对话完成任务。

### 友谊奖励

友谊等级达到一定级别后，拜访维克斯，通过对话领取奖励。

- **友谊等级 50：** 教你制作**鉴定台**

- **友谊等级 100：** 教你制作**珠宝制作台**
