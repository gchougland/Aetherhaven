# 入门指南

本页面将带您快速从世界中的一个空地发展成为一个可以赚取金币并欢迎村民的城镇。

## 创建您的城镇

1. 在工作台上制作一个**城镇规划桌**。

2. 使用规划桌制作一份**城镇宪章**和一根**地块放置杖**。

3. 将宪章放置在您希望城镇中心的位置。您的城镇最初会获得一个随机名称。之后您可以打开宪章来更改城镇名称。

4. **长老莱伦**将会出现。与他对话即可开始。

宪章标明了您城镇的边界。您可以在“机制”下的**城镇宪章**页面了解更多关于移动或替换宪章的信息。

## 您的第一个任务：建造旅店

莱伦会请您**建造旅店**。具体操作如下：

1. 与莱伦对话并接受任务。他会给你**旅店地块标记**（建造任务的地块标记由任务发布者发放，而非规划台）。

2. 装备**地块放置杖**，并在合适的位置标记旅店地块。

3. 将列出的木材和石头运到地块标记处，完成建造。

旅店建成后，一位**旅店老板**会入住。旅店是你的第一座真正意义上的建筑，也是城镇记录的存放地。

## 旅店的作用

旅店不仅仅是有墙有顶的建筑。

* **访客**可以停留一段时间。旅店一次最多可容纳两位客人。除非你正在进行需要锁定访客的任务，否则访客名单每天早上都会刷新。

* 旅店内设有一个**城镇记录架**，你可以在这里查看村民的需求、邀请好友来你的城镇，以及稍后查看礼物记录。

想要了解关于客人的完整信息，请阅读“机制”下的“**旅店泳池和访客**”。

## 金钱和税收

你的城镇每天早上通过**什一税**获得**金币**收入。每个算作居民的村民都会根据他们的舒适度缴纳税款。舒适度指的是他们的**饥饿值**、**精力值**和**乐趣值**都处于良好状态。

只要你的城镇中至少有一位成员在线，税收就会自动征收。建造市政厅后，打开国库即可查看金币累计情况以及每位居民的缴款明细。

有关宴会奖励、政策和其他增加收入的方法，请参阅“机制”下的“**国库和税收**”。

## 市政厅和国库

旅店建成后，再次与莱伦对话。他会提供**建造市政厅**的服务。建造市政厅的方法与建造旅店相同：从任务中获得地块代币，使用放置法杖，然后将材料带到告示牌处。

市政厅内设有金库，用于存放您的金币。此外，它还设有城镇档案架和规划空间。如果您想在一个地方进行存款、取款和查看税收记录，就需要市政厅。

## 谁算作居民

村民可以通过两种方式成为您城镇的一部分。

**工作场所（城镇工作的必要条件）**

建造并完成村民工作所需的地块（农场、商店、磨坊等等）。使用该建筑上的**管理模块**将村民分配到工作场所。在村民拥有工作场所之前，他们是访客，而不是与该工作绑定的正式居民。

**房屋（可选）**
村民工作不需要**房屋地块**。如果您建造房屋并登记村民入住，他们晚上就可以在那里睡觉。睡眠可以恢复**能量**，这也有助于他们每天早上缴纳金币。为了**娱乐**，您可以建造一个**公园**（见下文）。

准备好发展壮大后，可以接受旅店村民和游客的任务委托。每完成一个新的工作场所，就能增加一位居民。

## 小贴士

* 如果村民经常感到**无聊**不足，可以建造一个**公园**。公园长椅是补充无聊值的主要途径。打开**游戏机制**，阅读村民需求页面，详细了解饥饿值、能量值和无聊值。

* 经常与村民交谈并赠送礼物，可以获得更优惠的价格、配方和里程碑奖励。请参阅游戏机制下的**声望**。

* 建造**市政厅**后，请阅读游戏机制，了解**公会大厅和卫兵**、**任务板**、**游客传送门**以及其他游戏中期系统。

* 服务器管理员可以使用诸如`/ah starterkit`之类的创造模式工具来跳过制作步骤。这仅用于测试，并非玩家的正常游戏流程。
