# 地块代币

**地块代币**是您物品栏中的物品，用于在**地块放置杆**上选择建筑类型，然后在地图上标记地块位置。

## 地块制作台

在**地块制作台**制作地块代币。制作台会在您投入材料前显示建筑的**3D预览**。在**城镇规划桌**制作制作台，然后像放置其他工作台一样放置它。

大多数剧情任务仍然会直接从任务发布者那里获得第一个代币。之后，替换代币和额外的代币通常来自制作台。

## 地块蓝图

有些建筑需要**地块蓝图**才能建造，而不是像其他建筑那样从气球中掉落现成的代币。

1. **使用**蓝图物品，在您的地块制作台上永久解锁该地块。

2. 打开制作台并制作地块代币（需要材料和金币，与其他代币相同）。

3. 装备**地块放置杖**并标记地块位置。

**白色漂浮礼物**通常包含蓝图。绿色礼物多为珠宝；红色礼物多为家具。气球礼物比以前更稀有。

## 回收

多余的地块标记（包括礼物中的变体标记）可以在工作台上回收，换取金币，前提是您不需要重复的标记。

**提示**

* 如果建筑包含商铺，请阅读“机制”下的**玩家商店和商店位置**。

* 花店、烟火师和水晶守护者商店任务奖励的是蓝图，而不是直接的标记。
