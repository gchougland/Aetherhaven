# 村民需求

镇上的每位村民都有三种需求：**饥饿**、**精力**和**娱乐**。每个需求值都会从空到满。您可以在旅馆或市政厅的城镇记录架上查看这些需求值，具体位置在“需求”选项卡下。

## 为什么需求很重要

随着时间的推移，村民会逐渐感到饥饿、疲惫，并渴望娱乐。当需求值较低时，他们会在镇上寻找合适的地方来满足需求。

需求也与**税收**息息相关。每天早上，居民都会向国库缴纳金币。缴纳的金额部分取决于村民的生活舒适度。生活舒适的村民缴纳的金币更多。保持需求值充足对村民和您的城镇财政都有好处。

## 兴趣点

已建成的建筑会增加村民可以使用的**地点**：床、长椅、柜台、工作台以及类似的方块。您可以将每个地点视为世界中的一个小活动。

* **床** 可以恢复**能量**（包括夜晚房屋内的床）。

* **长椅和座椅**，包括公园长椅，可以恢复**乐趣**。

* **厨房台面、桌子和食物储藏处** 可以恢复**饥饿值**。

* **工作台和商店柜台** 在工作时间可以小幅恢复**饥饿值**和**能量值**。

不同的地块放置不同的地点。农场有耕作台。旅馆有床和用餐区。公园有供人休息的户外长椅。

## 村民如何选择地点

村民遵循每日作息时间，但能量值过低时，他们会暂时离开。如果**饥饿值**过低，他们会寻找食物。如果**能量值**过低，他们会寻找床。如果**乐趣值**过低，他们会寻找长椅或社交场所。

您无需手动点击每个地点。建造合适的土地，村民们会在白天找到它们。

## 夜晚的房屋

**房屋**并非必需。村民只需要他们的**工作场所**地块即可在镇上工作。

如果您将村民分配到房屋，他们晚上就可以在那里睡觉。睡眠可以恢复**能量**，让他们在第二天早上缴纳什一税时保持舒适。如果**娱乐**不足，可以使用**公园**。

## 小贴士

* 如果**娱乐**始终处于最低水平，请在规划台上圈定一个**公园**地块。公园长椅是用来放松的。

* 使用记录架上的**需求**标签，您可以一目了然地查看所有村民，如果您想查看某个村民的情况，还可以将他们传送到您身边。

* 宴会和一些城镇政策会影响您从舒适度高的居民那里获得的金币数量。有关资金方面的信息，请阅读**国库和税收**。
