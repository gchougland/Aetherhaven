# 常见问题解答

此处的答案旨在方便您在游戏过程中快速参考。如果仍有疑问，请查看**游戏机制**或**村民**页面以获取更详细的信息。

## 该模组是否会包含*此*功能？

答案很可能是肯定的，但请查看开发路线图。欢迎在模组的 Discord 服务器中提出您的建议。

## 我在哪里可以报告错误或提出功能建议？

您可以在模组的 Discord 频道提交错误报告和功能请求。提供您的游戏版本以及您是单人游戏还是服务器游戏可以避免很多来回沟通。

## 模组更新后存档会失效吗？

我们会尽力确保数据迁移的安全，但在进行重大更新之前，请务必**备份您的存档**，尤其是在长期运行的服务器上。

## 我可以设计自己的建筑而不是使用现有的预制件吗？

集成建筑工具是该模组计划中的一项功能。目前添加建筑需要进行相当多的配置。建筑建成后可以拆除/重建，但请注意，破坏/移动某些家具/长凳可能会导致村民无法使用这些设施来满足他们的需求。例如，移动床会导致村民找不到床。如果您希望自己的建筑作品在主模组中展示并注明出处，可以前往 Discord 上的建筑提交频道。
