**瓦伊莉丝·普瑞斯玛德**是一位古老的**水晶守护者**，她出售水晶和宝石。你必须在**找到并解救她**之后，她才会光临旅店。获救后，她可以在镇上开设一家水晶商店。

使用下方的**显示每周日程**查看瓦伊莉丝每天的行踪。

### 任务

#### 解救瓦伊莉丝

在探索过程中，你可能会发现瓦伊莉丝被困在石头里。解救她即可完成此任务。之后，她就会开始出现在旅店。

#### 瓦伊莉丝的水晶商店

瓦伊莉丝想要一家像样的商店，与镇上的人们分享她的水晶收藏。

1. 在旅店与瓦伊莉丝对话并接受任务。

2. 从瓦伊莉丝那里获得商店的**蓝图**。

3. 在你的**地块制作台**使用蓝图学习水晶商店的建造方法。

4. 制作一个商店地块代币，并建造水晶商店预制件。

5. 在商店找到瓦伊莉丝，并通过对话完成任务。

#### 瓦伊莉丝的家

即使是古老的水晶守护者，也值得在她水晶的光芒中拥有一处静谧的休憩之所。

1. 从瓦伊莉丝处获得房屋地块代币。

2. 圈地并建造房屋预制件。

3. 在房屋管理模块中将瓦伊莉丝指定为住户。

4. 找到瓦伊莉丝，并通过对话完成任务。
