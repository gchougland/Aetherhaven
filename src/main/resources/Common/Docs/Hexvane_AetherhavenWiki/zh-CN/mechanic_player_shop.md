# 玩家商店和商店位置

**商店位置**方块位于已建成的建筑地块内。它们允许NPC和玩家在世界中出售物品，而不仅仅局限于对话菜单。

## NPC商店

村民商店——**Vex的杂货店**、花店、烟火店、水晶守护者等等——会在**黎明**从战利品表中补充库存。每个位置都会显示一个悬浮的物品展示架；摊位朝向会旋转展示架。

* **F（使用）**——打开带有数量控制（±1、±10、最大值）的购买面板。

* **注视HUD**——当您瞄准有库存的位置时，会显示物品名称、价格和库存。

Vex现在经营着一家**杂货店**，通过他市场摊位和相关建筑中的商店位置出售家具、方块和消耗品。

## 你的专属商店

在建造完**Vex的市场摊位**后，Vex会提供**你的专属商店**任务：

1. 从Vex处领取**玩家商店**地块代币。

2. 圈地并建造玩家商店预制件。

3. 找到Vex，对话完成任务。

玩家商店包含**商店位置**方块和一个**商店保险柜**，用于存放你销售所得的金币。

### 上架物品

* **右键点击商店位置**，手持物品即可上架出售（仅限玩家控制的位置）。

* **再次右键点击**你自己的商品——将其从位置移除。

买家在已上架的商品位置按**F**键即可购买。当有人购买你的商品时，你会收到通知，并且金币会存入**商店保险柜**。

### 谁会来购物

**村民**和**游客**会在访问城镇时浏览玩家商店位置并购买上架的物品。价格和库存很重要——空位会被跳过。

## 权限

城镇成员需要获得许可才能在玩家商店出售物品。城镇所有者可以在城镇记录栏中调整成员权限。
