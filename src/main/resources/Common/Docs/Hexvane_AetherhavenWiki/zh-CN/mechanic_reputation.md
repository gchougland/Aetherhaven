# 声望

**声望** 代表村民对你的信任和好感度。声望是个人化的：你与农夫的声望值不会影响你与商人的声望值。声望值范围为 0 到 100。

更高的声望值可以解锁里程碑奖励，有时还能解锁新的食谱。每个村民的里程碑进度和礼物口味剧透可以在城镇日志的**村民**标签页中查看。礼物历史记录可以在旅馆或市政厅的**城镇记录架**上查看。

## 提升声望的方法

**每天与村民交谈**

每天早晨第一次与村民交谈时，你会获得少量声望加成。在城镇里散步时顺便拜访一下。随着时间的推移，声望值会不断累积。

**赠送礼物**

对话时，手持物品并选择赠送礼物选项。村民会根据他们对礼物的反应做出喜爱、喜欢、中立或厌恶的评价。更好的反应会提升你的声望值。收到他们不喜欢的礼物会降低好感度。

每周每位村民可赠送的礼物数量有限，所以最好把贵重的礼物留给那些你想讨好的人。

**完成任务**

完成长老、旅店老板和其他村民的剧情任务通常会获得声望。任务日志中的“任务”标签页会显示任务奖励的物品和声望值。

## 里程碑奖励

每位村民都有各自的友好度里程碑，每个里程碑对应一定的声望等级（并非所有村民的里程碑步骤都相同）。当你达到某个里程碑时，就会获得奖励。**与该村民对话**即可领取奖励。奖励可以是物品、食谱知识或一段特别的感谢对话。

如果你同时达到了多个里程碑，只需对话一次，就能了解他们欠你的奖励。任务日志中的“村民”标签页会列出每位村民及其里程碑，但不会剧透他们的礼物偏好。

## 城镇记录架上的礼物历史

打开**城镇记录架**（旅馆或市政厅），按村民浏览。您可以查看已赠送的礼物以及村民对每份礼物的感受。这有助于您避免重复送错礼物，并计划下次送什么。

## 小贴士

* **戒指和项链**是每位村民都喜欢的礼物。在了解村民的个人喜好之前，珠宝是可靠的选择。未鉴定的珠宝，只要是实物戒指或项链，也算数。请参阅“机制”下的**珠宝**，了解如何获取和制作珠宝。

* 将每日拜访、任务线和精心准备的礼物结合起来，送给您最关心的村民。

* 里程碑奖励需要亲自领取。如果您跨越了某个里程碑但没有收到任何奖励，请在游戏中找到村民并与其对话。
