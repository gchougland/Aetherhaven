# 旅游传送门

**旅游传送门**会吸引城镇以外的游客。**长老莱伦**会在**市政厅**建成后提供建造任务。

## 建造传送门

1. 与莱伦对话并接受旅游传送门任务。

2. 从莱伦处领取旅游传送门地块代币。

3. 圈地并建造旅游传送门预制件。

4. 找到莱伦并通过对话完成任务。

## 每日访客

每天早上，**游客**可以通过传送门抵达。他们会在城镇中漫步，浏览**商店**（包括玩家商店），并在**夜晚**离开。

游客是经过精心挑选的角色，他们的性格特征会影响他们的对话。他们与**旅店客人**不同——有关旅店双人轮换机制，请参阅“机制”下的“旅店客人池和客人”部分。

## 邀请游客留下

如果您想让游客成为永久居民，请为他们提供**房屋**：

1. 建造房屋地块，并通过相应的房屋任务流程将其分配到管理区。

2. 注册后，他们将像其他居民一样计入城镇生活。

在玩家商店购物的游客会花费真金白银——因此，在您的商店里储备一些实用商品非常重要。

## 小贴士

* 在期待大量游客消费之前，请先完成**您自己的商店**（由Vex提供）——他们会在玩家商店购物。

* 传送门和旅店的功能不同：旅店会将剧情**访客**锁定以完成任务；传送门则会每天带来重复的**游客**。
