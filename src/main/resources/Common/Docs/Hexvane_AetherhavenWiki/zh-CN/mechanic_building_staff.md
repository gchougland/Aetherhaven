# 建筑法杖

地块标志出现后，建筑法杖可让您分阶段建造建筑。瞄准高亮显示的方块，并确认每一批方块。

在地块标志上按下“建造”按钮后，建筑将开始缓慢建造。使用建筑法杖可以加快建造速度。手持法杖时，需要放置方块的位置会出现绿色方块。按住法杖的辅助操作（鼠标右键），同时注视这些方块，方块就会膨胀并放置建筑所需的方块。如果您找不到绿色方块，可以使用主要操作（鼠标左键）发射一枚追踪弹，该追踪弹会锁定最近的绿色方块。建筑法杖有多个等级，等级越高，使用法杖建造的半径越大。

每根法杖在您手持时都会增加额外的最大法力值。使用辅助操作放置方块会消耗您法力条上的每块1点法力值。如果您停止使用辅助操作几秒钟，只要您仍然手持法杖，法力值就会更快地恢复。

**提示**

* 使用脚手架方便工作人员到达更高处。

* 大型建筑在搭建演出场地时会分成多个部分。
