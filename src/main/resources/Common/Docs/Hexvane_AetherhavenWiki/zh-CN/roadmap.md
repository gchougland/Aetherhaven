# 路线图

许多之前的里程碑项目现已加入游戏：**公会大厅和守卫**、**任务板**每日任务、**玩家商店**、**游客传送门**、新村民（建造者、花匠、烟火师、水晶守护者、吟游诗人）、**地块蓝图**、**生产升级**以及经过全面改进的**路径设计铲**。详情请参阅本日志中的**机制**和**村民**部分。
