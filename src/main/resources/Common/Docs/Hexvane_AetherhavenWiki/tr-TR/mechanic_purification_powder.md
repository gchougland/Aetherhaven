# Arındırma Tozu

Arındırma tozu, oyuncunun oluşturulan yapılardaki düşman spawn noktalarını kaldırmasına olanak tanır. Tozu tutarken, oyuncu yapıda periyodik olarak spawn olan küçük, dönen yaratıklar görebilir. Tozu bu yaratıkların üzerine kullanmak, spawn noktasını kalıcı olarak kaldırır. Rahibe ile arkadaş olarak kilidi açılır.
