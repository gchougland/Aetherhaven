# 歡迎來到指南

本書位於您的城鎮日誌中。選擇左側主題即可閱讀更多內容。

**入門指南** 將引導您創建城鎮、建造首批建築以及了解資金來源。

**機制指南** 將解釋您將在城鎮中使用的工具、建築和系統。

**村民指南** 將介紹每位居民、他們的故事任務、聲望禮物和每週例行活動。禮物口味劇透將在您選擇顯示之前保持隱藏狀態。
