# 任務板

**公會大廳**的任務板會發布你城鎮的每日任務。與任務板互動即可開啟一個三張卡片組成的面板，顯示今天的任務。

每天**黎明**，只要你城鎮中至少有一名成員在線，新的卡片就會刷新。

## 任務類型

### 收集

有村民需要你幫忙把物資運回鎮上。接受任務，收集清單上的物品，然後**透過與村民對話**提交。等級越高，任務難度越大，獎勵也越豐厚。

### 狩獵

擊殺一定數量的特定怪物，然後向任務發布者報告。進度會顯示在任務卡和你的任務日誌中。

### 突襲

一群敵對生物會在**城鎮郊外**刷新，並向你的城鎮邊界進發。擊殺這群生物中的所有敵人即可完成任務。 **地圖標記**和**突襲血條**會顯示哪些敵人計入任務進度。

## 等級與獎勵

完成每個公告板任務都會為您的城鎮贏得**等級經驗值**。更高的**城鎮等級**可以解鎖難度更高的任務層級，並獲得更豐厚的獎勵。任務卡會顯示以天為單位的**時間限制**——請在任務過期或任務欄位在黎明清空前完成。

獎勵包括金幣、物品以及任務發布村民的聲望（如有）。

## 任務追蹤

活躍的公告板任務會與劇情任務一起顯示在城鎮日誌的**任務**標籤頁中。如果您改變主意，可以從日誌中放棄某個公告板任務。

有關如何建造公告板所在的公會大廳，請參閱“機制”下的**公會大廳和守衛**。
