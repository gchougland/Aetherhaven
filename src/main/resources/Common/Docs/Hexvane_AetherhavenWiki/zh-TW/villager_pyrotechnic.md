**格魯布爾·斯帕克馬奇**是一位出售炸藥的**煙火師**。你必須**在世界中找到並解救他**，他才會光顧旅店。獲救後，他就可以在鎮上開一家炸彈店了。

使用下方的**顯示每週日程**查看格魯布爾每天的行踪。

### 任務

#### 格魯布爾的逃脫

在探索過程中，你可能會發現格魯布爾被困在蜘蛛繭裡。解救他即可完成此任務。之後他就會開始出現在旅店。

#### 格魯布爾的炸彈店

格魯布爾想要一家像樣的店鋪，向鎮上的人們出售他的炸藥。

1. 在旅館與格魯布爾對話並接受任務。

2. 從格魯布爾那裡獲得店舖的**藍圖**。

3. 在你的**地塊製作台**使用藍圖學習炸彈店的建造方法。

4. 製作一個商店地塊代幣，並建造炸彈商店預製件。

5. 在商店找到格魯布爾，並透過對話完成任務。

#### 格魯布爾的家

即使是喜歡吵鬧的哥布林，有時也需要一張安靜的床。

1. 從格魯布爾那裡拿走房屋地塊代幣。

2. 圈地並建造房屋預製件。

3. 在房屋管理模組中將格魯布爾指定為住戶。

4. 找到格魯布爾，並透過對話完成任務。
