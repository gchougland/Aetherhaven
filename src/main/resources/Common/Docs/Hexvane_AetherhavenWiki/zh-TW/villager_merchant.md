**維克斯桑德蘭**經營著一家**雜貨店**，店舖位於市場攤位內，攤位已建成。商品會在黎明時分補貨；按下**F**鍵即可購買。請參閱「機制」下的「玩家商店和店舖位置」部分。

### 任務

#### 維克斯的家

維克斯可以隨處堆放物品。但她仍然需要一個乾燥的角落，有人會回應她的敲門聲。

1. 從維克斯拿走房屋地塊代幣。

2. 圈地並建造房屋預製件。

3. 在房屋管理模組中將維克斯指定為住戶。

4. 找到維克斯，並透過對話完成任務。

#### 維克斯的市集攤位

給維克斯一個櫃檯和一個屋頂，這樣她就可以把回收物放在一個合適的地方了。

1. 從維克斯拿走市場攤位地塊代幣。

2. 圈地並建造市場攤位預製件。

3. 在攤位找到維克斯，對話完成任務。

#### 你的商店

建造一家商店，向鎮民和遊客出售商品。

1. 先完成**維克斯的市場攤位**任務。

2. 從維克斯取得**玩家商店**地塊代幣。

3. 圈地並建造玩家商店預製件。

4. 找到維克斯，對話完成任務。

### 友誼獎勵

友誼等級達到一定等級後，拜訪維克斯，透過對話領取獎勵。

- **友誼等級 50：** 教你製作**鑑定台**

- **友誼等級 100：** 教你製作**珠寶製作台**
