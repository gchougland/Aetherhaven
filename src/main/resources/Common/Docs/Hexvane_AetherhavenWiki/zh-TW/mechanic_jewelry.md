# 珠寶

珠寶偶爾會在世界各地的戰利品箱中找到。新找到的珠寶未經鑑定。將其帶到商人維克斯處鑑定其效果。珠寶分為 5 種稀有度（普通、罕見、稀有、神話和傳說）。金飾比銀飾更堅固，項鍊比戒指更堅固。寶石的種類決定了珠寶影響的屬性。如果商人對你的好感度夠高，他會分享鑑定台和珠寶製作台的配方。鑑定台可以免費鑑定珠寶。珠寶製作台允許玩家使用金錠/銀錠、寶石和生命精華製作自己的珠寶。提供的生命精華越多，珠寶的品質越高。

## 寶石屬性

每種寶石類型決定了該飾品可以隨機產生的三個玩家屬性。具體數值取決於稀有度、材質以及戒指與項鍊的類型。

* **西風** — 耐力、專屬能量、氧氣

* **黃玉** — 耐力、專屬能量、彈藥

* **祖母綠** — 生命值、魔法值、氧氣

* **鑽石** — 生命值、耐力、魔法值

* **藍寶石** — 魔法值、耐力、氧氣

* **紅寶石** — 生命值、耐力、彈藥

* **虛空石** — 魔法值、專屬能量、彈藥

**提示**

* 多餘的珠寶是送給村民的絕佳禮物。請參閱「機制」下的「聲望」部分，以了解贈送禮物如何影響友善度。
