**瓦伊莉絲·普瑞斯瑪德**是一位古老的**水晶守護者**，她出售水晶和寶石。你必須在**找到並解救她**之後，她才會光臨旅店。獲救後，她可以在鎮上開設一家水晶商店。

使用下方的**顯示每週日程**查看瓦伊莉絲每天的行踪。

### 任務

#### 解救瓦伊莉絲

在探索過程中，你可能會發現瓦伊莉絲被困在石頭裡。解救她即可完成此任務。之後，她就會開始出現在旅館。

#### 瓦伊莉絲的水晶商店

瓦伊莉絲想要一家像樣的商店，與鎮上的人們分享她的水晶收藏。

1. 在旅店與瓦伊莉絲對話並接受任務。

2. 從瓦伊莉絲那裡獲得商店的**藍圖**。

3. 在你的**地塊製作台**使用藍圖學習水晶商店的建造方法。

4. 製作一個商店地塊代幣，並建造水晶商店預製件。

5. 在商店找到瓦伊莉絲，並透過對話完成任務。

#### 瓦伊莉絲的家

即使是古老的水晶守護者，也值得在她水晶的光芒中擁有一處靜謐的休憩之所。

1. 從瓦伊莉絲取得房屋地塊代幣。

2. 圈地並建造房屋預製件。

3. 在房屋管理模組中將瓦伊莉絲指定為住戶。

4. 找到瓦伊莉絲，並透過對話完成任務。
