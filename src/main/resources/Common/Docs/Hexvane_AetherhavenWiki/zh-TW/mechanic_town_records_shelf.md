# 城鎮記錄架

城鎮記錄架是您城鎮資訊和控制的中心。在「需求」標籤中，您可以查看所有村民的當前需求，並使用傳送按鈕將他們傳送到您身邊。您也可以查看村民的禮物偏好。這裡會顯示您送給每個村民的禮物以及他們的回饋。在「城鎮管理」標籤中，您可以邀請和管理城鎮中的玩家。您可以點擊玩家名稱來管理他們的城鎮權限。您可以使用移動按鈕重新排列建築物。 （移動建築物時請小心，任何在建築物放置時不屬於該建築物的物品都將被摧毀，包括動物等實體。）

## 生產建築升級

打開**生產建築**（農場、伐木場、礦工小屋、穀倉和類似的工作場所）的記錄架即可**升級**它。升級會根據建築類型提高產量或容量。費用和等級顯示在記錄架介面中－使用城鎮資源或材料支付，費用按清單顯示。

升級效果會隨著劇情推進而保留。完成新的工作場所後，請查看貨架，以了解第一級解鎖的內容。
