# 村民需求

鎮上的每位村民都有三種需求：**飢餓**、**精力**和**娛樂**。每個需求值都會從空到滿。您可以在旅館或市政廳的城鎮記錄架上查看這些需求值，具體位置在「需求」標籤下。

## 為什麼需求很重要

隨著時間的推移，村民會逐漸感到飢餓、疲憊，並渴望娛樂。當需求值較低時，他們會在鎮上尋找合適的地方來滿足需求。

需求也與**稅收**息息相關。每天早上，居民都會向國庫繳金幣。繳納的金額部分取決於村民的生活舒適度。生活舒適的村民繳的金幣更多。保持需求值充足對村民和您的城鎮財政都有好處。

## 興趣點

已建成的建築會增加村民可以使用的**地點**：床、長椅、櫃檯、工作台以及類似的方塊。您可以將每個地點視為世界中的一個小活動。

* **床** 可以恢復**能量**（包括夜晚房屋內的床）。

* **長椅和座椅**，包括公園長椅，可以恢復**樂趣**。

* **廚房檯面、桌子和食物儲藏處** 可以恢復**飢餓值**。

* **工作台和商店櫃檯** 在工作時間可以小幅恢復**飢餓值**和**能量值**。

不同的地塊放置不同的地點。農場有耕作台。旅館有床和用餐區。公園有供人休息的戶外長椅。

## 村民如何選擇地點

村民遵循每日作息時間，但能量值過低時，就會暫時離開。如果**飢餓值**太低，他們會尋找食物。如果**能量值**太低，他們會尋找床。如果**樂趣值**太低，他們會尋找長椅或社交場所。

您無需手動點擊每個地點。建造合適的土地，村民會在白天找到它們。

## 夜晚的房屋

**房屋**並非必需。村民只需要他們的**工作場所**地塊即可在鎮上工作。

如果您將村民分配到房屋，他們晚上就可以在那裡睡覺。睡眠可以恢復**能量**，讓他們在第二天早上繳納什一稅時保持舒適。如果**娛樂**不足，可以使用**公園**。

## 小貼士

* 如果**娛樂**始終處於最低水平，請在規劃台上圈定一個**公園**地塊。公園長椅是用來放鬆的。

* 使用記錄架上的**需求**標籤，您可以一目了然地查看所有村民，如果您想查看某個村民的情況，還可以將他們傳送到您身邊。

* 宴會和一些城鎮政策會影響您從舒適度高的居民那裡獲得的金幣數量。有關資金方面的信息，請閱讀**國庫和稅收**。
