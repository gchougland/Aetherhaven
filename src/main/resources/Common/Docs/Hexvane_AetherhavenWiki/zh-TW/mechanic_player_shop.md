# 玩家商店和商店位置

**商店位置**方塊位於已建成的建築地塊內。它們允許NPC和玩家在世界中出售物品，而不僅限於對話選單。

## NPC商店

村民商店——**Vex的雜貨店**、花店、煙火店、水晶守護者等等——會在**黎明**從戰利品表中補充庫存。每個位置都會顯示一個懸浮的物品展示架；攤位朝向會旋轉展示架。

* **F（使用）**－開啟具有數量控制（±1、±10、最大值）的購買面板。

* **注視HUD**—當您瞄準有庫存的位置時，會顯示物品名稱、價格和庫存。

Vex現在經營一家**雜貨店**，透過他市場攤位和相關建築中的商店位置出售家具、方塊和消耗品。

## 你的專屬商店

在建造完**Vex的市集攤位**後，Vex會提供**你的專屬商店**任務：

1. 從Vex處領取**玩家商店**地塊代幣。

2. 圈地並建造玩家商店預製件。

3. 找到Vex，對話完成任務。

玩家商店包含**商店位置**方塊和一個**商店保險箱**，用於存放你銷售所得的金幣。

### 上架物品

* **右鍵點擊商店位置**，手持物品即可上架出售（僅限玩家控制的位置）。

* **再次右鍵點擊**你自己的商品－將其從位置移除。

買家在已上架的商品位置按**F**鍵即可購買。當有人購買你的商品時，你會收到通知，金幣會存入**商店保險箱**。

### 誰會來購物

**村民**和**遊客**會在訪問城鎮時瀏覽玩家商店位置併購買上架的物品。價格和庫存很重要——空位會被跳過。

## 權限

城鎮成員需要獲得許可才能在玩家商店出售物品。城鎮所有者可以在城鎮記錄欄中調整成員權限。

請參閱「機制」下的「**地塊代幣**」以了解如何在地塊製作台製作地塊代幣。
