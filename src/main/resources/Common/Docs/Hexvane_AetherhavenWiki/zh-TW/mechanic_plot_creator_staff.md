# 地塊創建器

地塊創建器用於記錄您在世界中建造的**自訂建築**：佔地面積、特殊方塊、預製件匯出、成本，以及（可選）在您的城鎮中創建一個即時地塊。大多數玩家應該使用**裝飾**或**變體**，而不是下面列出的完整工作場所類型。

在熟悉流程時，請開啟您的**城鎮日誌 → 指南 → 機制 → 地塊建立器**（此頁）。遊戲過程中：裝備該創建器，按**F**開始或打開當前步驟面板，**單擊**世界中的方塊，**Q** / **E**上一步/下一步，**R**取消。

## 推薦路徑

| 目標 | 建築類型 | 備註 |

|------|----------------|-------|

| 裝飾性建築，無工作 | **裝飾** | 可選的城鎮記錄架；無生產或村民邏輯。 |

| 現有建築的替代外觀 | **變體** |選擇它屬於哪個**主要**建築類型（房屋、穀倉、旅館等）。子步驟遵循該主要類型。 |

| 新建工作場所/生產用地（模組）| **工作** | 用於新增的工作場所類型；需要管理模組、生產儲存和工作檯面興趣點。 |

## 建築類型（選擇器）

**裝飾** — 公園、道具和建築，**不應**用作住宅、商店或工作場所。所需位置最少。

**變體** — 預製件，**計入**模組中已有的其他建築 ID（例如，計入 `plot_house` 的自訂房屋）。從下拉式選單中選擇主要類型；重要位置與該主要建築相符。

**住宅** — 住宅用地：城鎮記錄架 + 睡眠興趣點。

**工作區** — **開發者/內容作者使用。 ** 定義一個新的**工作區**式地塊：城鎮記錄架、生產倉庫和工作檯面興趣點。用於添加新的生產或工作建築類型，不適用於普通外觀裝飾。

**休閒設施** — 娛樂或休閒（公園、祭壇式休閒設施）：記錄架 + 娛樂/休息興趣點。

**商店** — 攤位或商店櫃檯：記錄架 + 帶有商店標籤的工作興趣點。

**旅館** — 完整的旅館佈置：記錄架、工作檯面、床位、用餐區、旅館老闆和訪客刷新點（以及可選的公會會長刷新點）。

**市政廳** — 市政中心：記錄架、金庫、規劃台興趣點。

**公會大廳** — 冒險者公會：記錄架、工作檯面、冒險者刷新點。

### 重疊與混淆

- **變體** 與 **住宅/工作場所/…** — “變體”用於“外觀不同，功能類似 X”。如果您要重新設計現有遊戲建築的外觀，請選擇 **變體** + 主類型，而不是 **住宅**。

- **工作場所** 與 **商店** — **商店** 用於商販攤位。 **工作場所** 用於農場、磨坊、鐵匠鋪和其他生產場所。

- **休閒設施** 與 **裝飾** — **裝飾** 幾乎沒有遊戲機制關聯。 **休閒設施** 設定村民日程的娛樂/休閒標籤和興趣點。

- **旅館**、**市政廳** 和 **公會大廳** 是完整的模板；僅當您有意匹配這些模板之一時才使用 **變體**。

## 流程（簡版）

1. 標記兩個對角線和一個**外側**地塊標誌角。

2. 選擇**建築類型**（以及適用的**變體**）。

3. 放置**重要位置**（方塊會在每個子步驟中逐一放置）。

4. 輸入**名稱和 ID**（預製件檔案名稱緊跟在 ID 之後）。

5. 如有需要，編輯**標籤**。

6. 開啟**建築設定**（F）：金庫金幣消耗、自建天數、空地預製件選項和組裝部分。

7. 在儲存形狀步驟中按 F **匯出預製件**（使用步驟 6 中的設定）。

8. 設置**建築材料**（虛擬箱子；物品會在您繼續操作時返回）。

9. 檢查並保存。

## 權限

預設情況下，設定可能允許所有人使用地塊建立器；伺服器可以改為要求 `aetherhaven.plot.creator` 權限。
