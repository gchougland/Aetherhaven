# 入門指南

本頁面將帶您快速從世界中的一個空地發展成為一個可以賺取金幣並歡迎村民的城鎮。

## 建立您的城鎮

1. 在工作台上製作一個**城鎮規劃桌**。

2. 使用規劃桌製作一份**城鎮憲章**和一根**地塊放置杖**。

3. 將憲章放置在您希望城鎮中心的位置。您的城鎮最初會獲得一個隨機名稱。之後您可以打開憲章來更改城鎮名稱。

4. **長老萊倫**將會出現。與他對話即可開始。

憲章標示了您城鎮的邊界。您可以在「機制」下的**城鎮憲章**頁面中了解更多關於移動或替換憲章的資訊。

## 您的第一個任務：建造旅館

萊倫會請您**建造旅館**。具體操作如下：

1. 與萊倫對話並接受任務。他會給你**旅店地塊標記**（建造任務的地塊標記由任務發布者發放，而非規劃台）。

2. 裝備**地塊放置杖**，並在適當的位置標記旅館地塊。

3. 將列出的木材和石頭運送到地塊標記處，完成建造。

旅館建成後，一位**旅館老闆**會入住。旅館是你的第一座真正意義上的建築，也是城鎮記錄的存放地。

## 旅館的作用

旅店不只是有牆有頂的建築。

* **訪客**可以停留一段時間。旅店一次最多可容納兩位客人。除非你正在進行需要鎖定訪客的任務，否則訪客名單每天早上都會刷新。

* 旅館內設有一個**城鎮記錄架**，你可以在這裡查看村民的需求、邀請好友來你的城鎮，以及稍後查看禮物記錄。

想要了解關於客人的完整信息，請閱讀“機制”下的“**旅館泳池和訪客**”。

## 金錢和稅收

你的城鎮每天早上透過**什一稅**獲得**金幣**收入。每個算作居民的村民都會根據他們的舒適度繳稅。舒適度指的是他們的**飢餓值**、**精力值**和**樂趣值**都處於良好狀態。

只要你的城鎮中至少有一位成員在線，稅收就會自動徵收。建造市政廳後，打開國庫即可查看金幣累積情況以及每位居民的繳款明細。

有關宴會獎勵、政策和其他增加收入的方法，請參閱「機制」下的「**國庫和稅收**」。

## 市政廳和國庫

旅店建成後，再次與萊倫對話。他會提供**建造市政廳**的服務。建造市政廳的方法與建造旅館相同：從任務中獲得地塊代幣，使用放置法杖，然後將材料帶到告示牌處。

市政廳內設有金庫，用於存放您的金幣。此外，它還設有城鎮檔案架和規劃空間。如果您想在一個地方進行存款、提款和查看稅務記錄，就需要市政廳。

## 誰算是居民

村民可以透過兩種方式成為您城鎮的一部分。

**工作場所（城鎮工作的必要條件）**

建造並完成村民工作所需的土地（農場、商店、磨坊等等）。使用該建築上的**管理模組**將村民分配到工作場所。在村民擁有工作場所之前，他們是訪客，而不是與該工作綁定的正式居民。

**房屋（可選）**
村民工作不需要**房屋地塊**。如果您建造房屋並登記村民入住，他們晚上可以在那裡睡覺。睡眠可以恢復**能量**，這也有助於他們每天早上繳納金幣。為了**娛樂**，您可以建造一個**公園**（見下文）。

準備好發展壯大後，可以接受旅店村民和遊客的任務委託。每完成一個新的工作場所，就能增加一位居民。

## 小貼士

* 如果村民經常感到**無聊**不足，可以建造一個**公園**。公園長椅是補充無聊值的主要途徑。開啟**遊戲機制**，閱讀村民需求頁面，詳細了解飢餓值、能量值和無聊值。

* 經常與村民交談並贈送禮物，可以獲得更優惠的價格、配方和里程碑獎勵。請參閱遊戲機制下的**聲望**。

* 建造**市政廳**後，請閱讀遊戲機制，了解**公會大廳和衛兵**、**任務板**、**遊客傳送門**以及其他遊戲中期系統。

* 伺服器管理員可以使用諸如`/ah starterkit`之類的創造模式工具來跳過製作步驟。這僅用於測試，並非玩家的正常遊戲流程。
