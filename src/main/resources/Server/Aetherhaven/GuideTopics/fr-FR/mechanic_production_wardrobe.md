# Armoire de production

Les bâtiments de production utilisent une armoire pour configurer et accéder aux ressources générées. Trouvez l'armoire dans le bâtiment et interagissez avec elle pour ouvrir la fenêtre de production. Vous pouvez parcourir les ressources disponibles à produire à l'aide des flèches. Chaque type de ressource est stocké séparément. Sélectionner plusieurs exemplaires de la même ressource augmente sa vitesse de production. La page des déblocages vous permet de débloquer de nouvelles ressources à générer en échange d'une partie de cette ressource et de pièces d'or.

*À l'avenir, vous pourrez améliorer la capacité de stockage maximale et la vitesse de production des bâtiments.*
