# Bienvenue dans le guide

Ce livre se trouve dans le journal de votre ville. Choisissez un sujet à gauche pour en savoir plus.

**Premiers pas** vous accompagne dans la fondation de votre ville, la construction de vos premiers bâtiments et la gestion de vos revenus.

**Mécaniques de jeu** explique les outils, les bâtiments et les systèmes que vous utiliserez en ville.

**Villageois** présente chaque habitant, ses quêtes, les cadeaux de réputation qu'il reçoit et ses activités hebdomadaires. Les informations sur le contenu des cadeaux restent cachées jusqu'à ce que vous décidiez de les afficher.
