# Pelle de tracé

La **pelle de tracé** vous permet de dessiner des chemins courbes en ville, de les prévisualiser et de placer des blocs au sol. Un panneau d'informations s'affiche lorsque vous utilisez l'outil.

Fabriquez-la au **bureau d'urbanisme**.

## Modes

Appuyez sur **Q** pour parcourir les cinq modes :

1. **Déplacer** : ajoutez et repositionnez des points de contrôle pour modeler le chemin.

2. **Rotation** : faites pivoter le point sélectionné pour courber la courbe.

3. **Placer** : ancrez le chemin au sol.

4. **Supprimer** : visualisez les chemins placés (surlignés en orange) et supprimez ceux que vous ne souhaitez plus utiliser.

5. **Créateur de styles** : créez et modifiez des styles de chemin dans une grille.

L'interface vous rappelle de passer en mode **Placer** lorsque vous êtes prêt à poser des blocs de chemin.

## Commandes par mode

### Déplacer, Rotation et Placer

* **Clic droit secondaire sur le sol** : ajouter un nœud.

* **Clic droit secondaire en visant un nœud** : supprimer ce nœud.

* **Clic gauche principal sur un nœud** : le sélectionner.

* **Clic gauche principal sur le sol (mode Déplacement)** : déplacer le nœud sélectionné.

* **F (mode Rotation)** : ajuster la direction du nœud sélectionné.

* **F (mode Placer)** : placer le chemin sur le sol.

* **E** : modifier l’épaisseur du chemin.

* **R** : modifier le style du chemin.

* **Q** : passer au mode suivant.

### Supprimer

* **Clic droit principal** : sélectionner un chemin placé.

* **F** : supprimer le chemin sélectionné.

* **Q** : passer au mode suivant.

### Concepteur de styles

* **F** : ouvrir le gestionnaire de styles (grille à double curseur pour les colonnes de blocs pondérés). * **E** — Enregistrer le style du chemin (coffre ouvert).

* **Q** — Mode suivant.

## Aperçu visuel

Pendant l'édition, les nœuds et lignes blancs représentent la spline. Un aperçu marron indique l'emplacement des blocs, avec des bords verts. Le mode **Supprimer** affiche les chemins déjà créés en orange.

## Conseils

* Commencez par modeler la spline dans **Déplacer** et **Rotation**, puis passez en mode **Placer** et appuyez sur **F** pour la fixer.

* Créez des styles personnalisés dans **Concepteur de styles** : chaque style est une colonne de blocs pondérée et déroulée le long du chemin.

* Les chemins sont conservés dans le monde et dans votre sauvegarde de ville.
