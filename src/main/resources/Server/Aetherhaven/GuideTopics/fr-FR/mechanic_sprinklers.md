# Arroseurs

Les arroseurs sont de précieux alliés pour les grands champs. Activez-en un et il arrose les cultures environnantes une fois par jour, à l'aube. Vous pouvez aussi l'activer manuellement à l'aide du bloc. Débloquez-le en devenant ami avec le fermier. Il existe quatre niveaux d'arroseurs à débloquer, offrant des rayons d'arrosage croissants.
