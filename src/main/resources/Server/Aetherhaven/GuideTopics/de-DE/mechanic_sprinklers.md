# Sprinkler

Sprinkler sind die Metallhelfer für große Felder. Aktiviert man einen, erfrischt er einmal täglich bei Sonnenaufgang die Pflanzen in einem Umkreis um den Sprinkler. Er kann auch manuell mit dem Block aktiviert werden. Freigeschaltet werden sie, indem man sich mit dem Bauern anfreundet. Es gibt vier Sprinklerstufen mit jeweils wachsendem Bewässerungsradius.
