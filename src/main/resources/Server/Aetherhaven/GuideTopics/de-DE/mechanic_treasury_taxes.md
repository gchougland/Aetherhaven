# Schatzkammer und Steuern

Die Schatzkammer enthält das Stadtgold. Die Einwohner zahlen morgens einen Zehnten, der sich nach ihrem aktuellen Bedarf richtet. Die Stadt generiert Steuern, solange mindestens ein Stadtmitglied auf dem Server ist, selbst in nicht geladenen Chunks. Solange kein Stadtmitglied online ist, werden keine Steuern generiert. Eine Aufschlüsselung der Steuern finden Sie im zweiten Tab. Es gibt verschiedene Möglichkeiten, die Steuereinnahmen zu erhöhen, z. B. durch Feste, die Gründerstatue und Stadtrichtlinien.
