# Reinigungspulver

Mit Reinigungspulver kann der Spieler die Spawnpunkte von Gegnern in generierten Strukturen entfernen. Solange der Spieler das Pulver hält, sieht er kleine, sich drehende Versionen von Monstern an den Stellen, an denen diese normalerweise regelmäßig in der Struktur erscheinen würden. Die Anwendung des Pulvers entfernt den Spawnpunkt dauerhaft. Freigeschaltet durch Freundschaft mit der Priesterin.
