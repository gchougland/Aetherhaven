# Bastón de construcción

Una vez que aparece un cartel de parcela, el bastón de construcción te permite construir la estructura por etapas. Apunta a los bloques resaltados y confirma cada grupo.

Tras pulsar CONSTRUIR en un cartel de parcela, el edificio comenzará a construirse lentamente. Usar el bastón de construcción acelera este proceso. Mientras sostienes el bastón, aparecerán cubos verdes donde se deben colocar los bloques. Manteniendo pulsada la acción secundaria (botón derecho del ratón) con el bastón mientras miras estos cubos, estos se expandirán y colocarán los bloques para la construcción. Si no encuentras ningún cubo verde, puedes usar la acción principal (botón izquierdo del ratón) para disparar un proyectil que te guiará al cubo verde más cercano. Hay varios niveles de bastón de construcción con un radio de construcción creciente.

Cada bastón otorga maná máximo adicional mientras lo sostienes. Colocar bloques con la acción secundaria cuesta 1 punto de maná por bloque de tu barra de maná. Si dejas de usar la acción secundaria durante un par de segundos, el maná se recarga más rápido mientras sigues sosteniendo el bastón.

**Consejos**

* Utilice andamios para que el personal pueda alcanzar lugares altos.

* Los edificios muy grandes se dividen en secciones al construir para representaciones.
