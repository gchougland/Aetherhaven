**Aviso:** Esta hoja de ruta **no es definitiva**. Las prioridades, el orden y el alcance pueden cambiar a medida que el mod evoluciona. Los elementos que se muestran a continuación son objetivos e ideas, no promesas ni fechas de lanzamiento.

# Hoja de ruta

## Incluido en la versión 2.0

Muchos elementos que antes eran hitos importantes ya están en el juego: **salón del gremio y guardias**, misiones diarias del **tablero de misiones**, **tiendas de jugadores**, **portal turístico**, nuevos aldeanos (Constructor, Florista, Pirotécnico, Guardián de Cristales, Bardo), **planos de parcelas**, **mejoras de producción** y la **pala de diseño de caminos** renovada. Consulta **Mecánicas** y **Aldeanos** en este diario para obtener más detalles.

## Hitos (orden actual)

1. **Actualización del Museo**
2. **Actualización de la Red Comercial**
3. **Actualización de Viviendas para Jugadores**
4. **Actualización de Edificios Personalizados** (flujos de trabajo ampliados para la creación de parcelas)
