# Geodos

Geodos são rochas irregulares encontradas raramente ao minerar minérios e cristais. O ferreiro da cidade pode quebrá-los para você mediante pagamento. Minérios, fragmentos de cristal e, raramente, gemas podem ser obtidos ao quebrar geodos. Se o ferreiro gostar bastante de você, ele compartilhará uma receita para a Bigorna de Geodos, que permitirá abrir geodos gratuitamente.
