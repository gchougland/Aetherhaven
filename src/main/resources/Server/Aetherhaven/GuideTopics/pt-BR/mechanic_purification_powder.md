# Pó de Purificação

O Pó de Purificação permite ao jogador remover pontos de surgimento de inimigos em estruturas geradas. Ao segurar o pó, o jogador poderá ver pequenas versões giratórias de criaturas nos locais onde elas surgiriam periodicamente na estrutura. Usar o pó nesses locais removerá o ponto de surgimento permanentemente. Desbloqueado ao fazer amizade com a Sacerdotisa.
