# Bem-vindo ao guia

Este livro está dentro do seu diário da cidade. Escolha um tópico à esquerda para ler mais.

**Primeiros Passos** explica como fundar uma cidade, construir seus primeiros edifícios e como o dinheiro entra.

**Mecânica** explica as ferramentas, edifícios e sistemas que você usará na cidade.

**Moradores** apresenta cada morador, suas missões de história, presentes de reputação e rotinas semanais. Os spoilers sobre o gosto dos presentes ficam ocultos até que você decida mostrá-los.
