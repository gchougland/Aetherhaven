# Carta da Cidade

A carta é o ponto central da sua cidade. Coloque-a uma vez para criar a cidade, nomeie o local e gere o aldeão Ancião para começar sua aventura de construção.

**Dicas**
* Se você dissolver a cidade, todos os aldeões e construções serão removidos.

* Você pode mover a carta usando o botão no menu dela.
