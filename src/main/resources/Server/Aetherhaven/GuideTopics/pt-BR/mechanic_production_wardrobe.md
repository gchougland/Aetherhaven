# Guarda-roupa de Produção

Os edifícios de produção utilizam um guarda-roupa para configurar e acessar os recursos gerados. Encontre o guarda-roupa no edifício e interaja com ele para abrir a janela de produção. Você pode alternar entre os recursos disponíveis para produção usando as setas. Cada tipo de recurso é armazenado separadamente. Selecionar vários recursos iguais aumenta a velocidade de produção. A página de desbloqueios permite desbloquear novos recursos para geração, ao custo de alguns desses recursos e moedas de ouro.

*No futuro, você poderá aumentar a capacidade máxima de armazenamento e a velocidade de produção dos edifícios.*
