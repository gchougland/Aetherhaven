# Estatutos del pueblo

Los estatutos son el punto de partida de tu pueblo. Colócalos una vez para crearlo, dale un nombre y haz aparecer al aldeano Anciano para comenzar tu aventura de construcción.

**Consejos**
* Si disuelves el pueblo, todos los aldeanos y edificios desaparecerán.

* Puedes mover los estatutos usando el botón en su menú.
