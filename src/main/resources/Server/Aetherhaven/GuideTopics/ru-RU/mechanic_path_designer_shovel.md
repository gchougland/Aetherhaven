# Лопата для создания дорожек

Лопата для создания дорожек позволяет рисовать изогнутые дорожки в городе, просматривать их и размещать блоки на земле. При удержании инструмента появляется панель состояния с подсказками.

Изготовьте её на **столе городского планирования**.

## Режимы

Нажмите **Q** для переключения между пятью режимами:

1. **Перемещение** — добавление и изменение положения узлов управления для придания формы дорожке.

2. **Вращение** — поворот выбранного узла для изгиба сплайна.

3. **Размещение** — цементирование готовой дорожки на земле.

4. **Удаление** — просмотр размещенных дорожек (выделены оранжевым) и удаление тех, которые вам больше не нужны.

5. **Конструктор стилей** — создание и редактирование стилей дорожек в сетке сундуков.

HUD напоминает о необходимости переключиться в режим **Размещение**, когда вы будете готовы укладывать блоки дорожек.

## Управление по режимам

### Перемещение, вращение и размещение

* **Вторичный (щелчок правой кнопкой мыши) на земле** — добавить узел.

* **Вторичный (при наведении на узел)** — удалить этот узел.

* **Основной (щелчок левой кнопкой мыши) на узле** — выбрать его.

* **Основной на земле (режим перемещения)** — переместить выбранный узел.

* **F (режим вращения)** — изменить направление выбранного узла.

* **F (режим размещения)** — разместить путь на земле.

* **E** — изменить ширину пути.

* **R** — изменить стиль пути.

* **Q** — следующий режим.

### Удаление

* **Основной** — выбрать размещенный путь.

* **F** — удалить выбранный путь.

* **Q** — следующий режим.

### Дизайнер стилей

* **F** — открыть менеджер стилей (сетка с двойным сундуком для столбцов из взвешенных блоков).

* **E** — сохранить стиль пути (пока сундук открыт).

* **Q** — перейти в следующий режим.

## Предварительный просмотр

Во время редактирования белые узлы и линии отображают сплайн. Коричневый индикатор предварительного просмотра отмечает места, куда будут помещены блоки, с зелеными краями по бокам. В режиме **Удалить** вместо этого отображаются зафиксированные пути оранжевым цветом.

## Советы

* Сначала сформируйте сплайн в **Переместить** и **Повернуть**, затем переключитесь на **Разместить** и нажмите **F**, чтобы закрепить его.

* Создавайте пользовательские варианты оформления в **Дизайнере стилей** — каждый стиль представляет собой столбец из взвешенных блоков, свернутый вдоль ширины пути.

* Пути сохраняются в мире и в сохранении вашего города.
