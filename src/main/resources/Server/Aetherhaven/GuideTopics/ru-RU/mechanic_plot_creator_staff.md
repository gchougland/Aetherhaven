# Помощник создателя участков

Помощник создателя участков регистрирует **построенные вами в мире пользовательские здания**: площадь застройки, специальные блоки, экспорт префабов, стоимость и (по желанию) активный участок в вашем городе. Большинству игроков следует использовать **Декоративные** или **Варианты**, а не полные типы рабочих мест, указанные ниже.

Откройте свой **журнал города → Руководство → Механика → Помощник создателя участков** (эта страница), изучая процесс. В игре: экипируйте помощницу, нажмите **F**, чтобы начать или открыть панель текущего шага, **щелкните основной кнопкой мыши** по блокам в мире, **Q** / **E** предыдущий/следующий шаг, **R** для отмены.

## Рекомендуемые пути

| Цель | Тип здания | Примечания |

|------|----------------|-------|

| Косметическая постройка, без рабочих мест | **Декоративные** | Дополнительная полка записей города; без логики производства или жителей. |

| Альтернативный внешний вид существующего здания | **Вариант** | Выберите, к какому **основному** зданию оно относится (дом, сарай, гостиница и т. д.). Подэтапы следуют за этим основным типом. |

| Новый участок для рабочего места / производства (моддинг) | **Работа** | Для добавления новых типов рабочих мест; необходимы блок управления потребностями, склад для производства и точка интереса рабочей поверхности. |

## Типы зданий (выбор)

**Декор** — Парки, декорации и постройки, которые **не** должны использоваться в качестве домов, магазинов или рабочих мест. Минимальное количество необходимых мест.

**Вариант** — Префаб, который **считается** другим идентификатором здания, уже присутствующим в моде (например, пользовательский дом, который считается как `plot_house`). Вы выбираете основной тип из выпадающего списка; важные места соответствуют этому основному зданию.

**Дом** — Жилой участок: полка с городскими записями + точка интереса для сна.

**Работа** — **Использование разработчиками/авторами контента.** Определяет новый участок в стиле **рабочего места**: полка с городскими записями, склад производства и точка интереса с рабочей поверхностью. Используйте при добавлении нового типа производственного или рабочего здания, а не для обычных косметических вариантов.

**Удобство** — Развлечения или отдых (парк, алтарь): полка + точка интереса для отдыха/сидения.

**Магазин** — Торговая лавка или прилавок: полка + точка интереса с пометкой «работа» и «магазин».

**Трактир** — Полная планировка трактира: полка, рабочая поверхность, кровати, место для еды, точки появления трактирщика и посетителей (и дополнительный слот для появления мастера гильдии).

**Ратуша** — Общественный центр: полка, казначейский блок, точка интереса «стол планирования».

**Гильдия** — Гильдия искателей приключений: полка, рабочая поверхность, точки появления искателей приключений.

### Пересечение и путаница

- **Вариант** против **Дом / Работа / …** — Вариант означает «выглядит иначе, ведет себя как X». Выбирайте **Вариант** + основной тип, а не **Дом**, если вы меняете внешний вид существующего игрового здания.

- **Работа** против **Магазин** — **Магазин** предназначен для торговых лавок. **Работа** — для ферм, мельниц, кузниц и других производственных помещений.

- **Удобства** против **Декорации** — **Декорации** практически не имеют игровых связей. **Удобства** задают метки развлечений/удобств и точки интереса для расписания жителей деревни.

- **Трактир**, **Ратуша** и **Гильдия** — это полноценные шаблоны; используйте **Вариант** только если вы намеренно подбираете под один из этих шаблонов.


## Последовательность действий (кратко)

1. Отметьте два противоположных угла и **внешний** угол для таблички с указанием участка.

2. Выберите **тип здания** (и **вариант**, если применимо).

3. Разместите **важные места** (блоки размещаются по одному за каждый подшаг).

4. Введите **имя и идентификатор** (имя файла префаба следует за идентификатором).

5. При необходимости отредактируйте **теги**.

6. Откройте **настройки здания** (F): стоимость золота в казначействе, количество дней самостоятельного строительства, опция префаба для пустого пространства и секции сборки.

7. **Экспортируйте префаб** с помощью F на шаге сохранения формы (используются настройки из шага 6).

8. Установите **строительные материалы** (виртуальный сундук; предметы возвращаются к вам при продолжении).

9. Проверьте и сохраните.
