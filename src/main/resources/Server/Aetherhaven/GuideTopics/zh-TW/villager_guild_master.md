**萊拉·費爾霍洛**負責管理建成後的**公會大廳**。冒險者們會聚集於此，你可以僱用他們擔任**守衛**，負責巡邏和對抗敵對生物。巡邏路線和指揮所的位置請參閱「機制」下的**公會大廳和守衛**。

使用下方的**顯示每週行程**查看萊拉每天的行程。

### 任務

#### 建造公會大廳

萊拉想要一個像樣的公會大廳，冒險者可以在這裡登記，也可以僱用守衛。

1. 先完成**城鎮大廳**的建造，然後前往旅館與萊拉對話。

2. 從萊拉領取公會大廳地塊代幣。

3. 圈地並建造公會大廳預製件。

4. 在公會大廳找到萊拉，並透過對話完成任務。

#### 萊拉的家

萊拉從早到晚負責公會大廳的日常運作。她渴望夜晚能擁有一個屬於自己的寧靜空間。

1. 從萊拉領取房屋地塊代幣。

2. 圈地並建造房屋預製件。

3. 在房屋管理欄中將萊拉指定為住戶。

4. 找到萊拉，並透過對話完成任務。
