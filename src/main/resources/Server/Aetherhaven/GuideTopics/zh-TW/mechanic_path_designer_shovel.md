# 路徑設計鏟

**路徑設計鏟** 可以讓你在城鎮中繪製曲線路徑，預覽路徑效果，並將方塊放置在地面上。握持工具時，會顯示一個包含關鍵提示的狀態面板。

在**城鎮規劃台**製作。

## 模式

按**Q**鍵可在五種模式之間切換：

1. **移動** — 新增和重新定位控制節點以塑造路徑形狀。

2. **旋轉** — 旋轉選取的節點以彎曲樣條曲線。

3. **放置** — 將完成的路徑固定在地面上。

4. **移除** — 檢視已放置的路徑（橘色高亮顯示）並刪除不再需要的路徑。

5. **樣式設計器** — 在網格狀的箱子中建立和編輯路徑樣式。

當您準備放置路徑方塊時，HUD 會提醒您切換到**放置**模式。

## 按模式控制

### 移動、旋轉與放置

* **在地面上使用輔助鍵（右鍵）** — 新增節點。

* **瞄準節點時使用輔助鍵** — 移除該節點。

* **在節點上使用主鍵（左鍵單擊）** — 選擇該節點。

* **在地面上使用主鍵（移動模式）** — 移動選定的節點。

* **F（旋轉模式）** — 微調選取節點的方向。

* **F（放置模式）** — 將路徑放置在地面上。

* **E** — 循環調整路徑寬度。

* **R** — 循環調整路徑樣式。

* **Q** — 切換到下一個模式。

### 移除

* **主鍵** — 選擇已放置的路徑。

* **F** — 移除選取的路徑。

* **Q** — 切換到下一個模式。

### 樣式設計器

* **F** — 開啟樣式管理器（用於顯示加權方塊列的雙格網格）。

* **E** — 儲存路徑樣式（在樣式管理器開啟時）。

* **Q** — 進入下一模式。

## 預覽效果

編輯時，白色節點和線條顯示樣條曲線。棕色預覽標記方塊的放置位置，兩側帶有綠色邊緣。 **移除** 模式下，已確定的路徑會以橘色顯示。

## 提示

* 先在**移動**和**旋轉**中調整樣條曲線的形狀，然後切換到**放置**並按**F**將其固定。

* 在**樣式設計器**中建立自訂外觀 — 每種樣式都是沿著路徑寬度捲動的加權方塊列。

* 路徑會保留在遊戲世界和您的城鎮存檔中。
