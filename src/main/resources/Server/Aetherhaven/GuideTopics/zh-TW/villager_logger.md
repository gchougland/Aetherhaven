**塞倫·費爾霍洛** 通常在**伐木場**值班時出現。

### 任務

#### 塞倫的家

塞倫想要一個不是從伐木場借來的屋頂，以及一張真正屬於自己的床。

1. 從塞倫那裡拿到房屋地塊代幣。

2. 圈定並建造房屋預製件。

3. 在房屋管理欄中將塞倫指定為住戶。

4. 找到塞倫，並透過對話完成任務。

#### 塞倫的伐木場

建造一座伐木場，這樣塞倫就可以把成捆的木材加工成木材堆，供鎮上使用，而不是在公共休息室裡踱來踱去。

1. 從塞倫那裡拿到伐木場地塊代幣。

2. 圈定並建造伐木場預製件。

3. 在辦公桌旁找到塞倫，並透過對話完成任務。

### 友誼獎勵

當您的友誼達到相應等級時，請與他們對話領取獎勵。

- **友誼 50：** 教您製作 **柴火**

- **友誼 100：** 教您製作 **除根劑**
