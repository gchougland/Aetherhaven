# 建築法杖

地塊標誌出現後，建築法杖可讓您分階段建造建築。瞄準高亮顯示的方塊，並確認每一批方塊。

在地塊標誌上按下“建造”按鈕後，建築將開始緩慢建造。使用建築法杖可以加快建造速度。手持法杖時，需要放置方塊的位置會出現綠色方塊。按住法杖的輔助操作（滑鼠右鍵），同時注視這些方塊，方塊就會膨脹並放置建築所需的方塊。如果您找不到綠色方塊，可以使用主要操作（滑鼠左鍵）發射一枚追蹤彈，該追蹤彈會鎖定最近的綠色方塊。建築法杖有多個等級，等級越高，使用法杖建造的半徑越大。

每根法杖在您手持時都會增加額外的最大法力值。使用輔助操作放置方塊會消耗您法力條上的每塊1點法力值。如果您停止使用輔助操作幾秒鐘，只要您仍然手持法杖，法力值就會更快恢復。

**提示**

* 使用鷹架方便工作人員到達更高處。

* 大型建築在搭建演出場地時會分成多個部分。
