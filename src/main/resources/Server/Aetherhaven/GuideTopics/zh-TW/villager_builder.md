**羅文·里奇克拉夫特**是城鎮的**建造者**。他的小屋建成後，他會在工作時間前往仍在建造中的地塊，一邊在告示牌旁工作，一邊幫助它們更快地發展。

使用下方的**顯示每週行程**查看羅文每天的行程。

### 任務

#### 羅文的建造者小屋

為羅文建造一個合適的小屋，讓他可以規劃建築並幫助城鎮發展。

1. 在旅館與羅文對話並接受任務。

2. 從羅文處領取建造者小屋地塊代幣。

3. 圈定並建造建造者小屋預製件。

4. 在小屋找到羅文，並透過對話完成任務。

#### 羅文的家

即使是像羅文這樣熱愛建築的建造者，也需要一個安靜的休息場所。

1. 從羅文處領取房屋地塊代幣。

2. 圈地並建造房屋預製件。

3. 在房屋管理模組中將羅文指定為住戶。

4. 找到羅文，並透過對話完成任務。
