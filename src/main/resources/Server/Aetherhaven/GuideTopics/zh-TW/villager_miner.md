**戈魯克·石脈**通常在**礦工小屋**值班時出現。

### 任務

#### 戈魯克的家

戈魯克想要一間像樣的房子，而不是擠在旅館的樓上，就像其他擁有地塊代幣的人一樣。

1. 從戈魯克拿走房屋地塊代幣。

2. 圈定並建造房屋預製件。

3. 在房屋管理欄中將戈魯克指定為住戶。

4. 找到戈魯克，並透過對話完成任務。

#### 戈魯克的礦工小屋

給戈魯克一個像樣的棚子和工作台，這樣他就可以搬運石頭和礦石，而不會佔用旅館的空間。

1. 從戈魯克拿走礦工小屋地塊代幣。

2. 圈定並建造礦工小屋預製件。

3. 在工作台找到戈魯克，並透過對話完成任務。

### 友情獎勵

友情等級達到一定等級後，即可拜訪他們並透過對話領取獎勵。

- **友情等級 50：**獲得 **1** × **發光戒指**

- **友情等級 100：**獲得 **1** × **大型發光戒指**
