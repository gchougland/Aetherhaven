# 聲望

**聲望** 代表村民對你的信任和好感度。聲望是個人化的：你與農夫的聲望價值不會影響你與商人的聲望價值。聲望值範圍為 0 到 100。

更高的聲望值可以解鎖里程碑獎勵，有時還能解鎖新的食譜。每個村民的里程碑進度和禮物口味劇透可以在城鎮日誌的**村民**標籤頁中查看。禮物歷史記錄可以在旅館或市政廳的**城鎮記錄架**上查看。

## 提升聲望的方法

**每天與村民交談**

每天早晨第一次與村民交談時，你會獲得少量聲望加成。在城鎮散步時順便去拜訪一下。隨著時間的推移，聲望值會不斷累積。

**贈送禮物**

對話時，手持物品並選擇贈送禮物選項。村民會根據他們對禮物的反應做出喜愛、喜歡、中立或厭惡的評價。更好的反應會提升你的聲望值。收到他們不喜歡的禮物會降低好感度。

每週每位村民可贈送的禮物數量有限，所以最好把貴重的禮物留給那些你想討好的人。

**完成任務**

完成長老、旅館老闆和其他村民的劇情任務通常會獲得聲望。任務日誌中的「任務」標籤頁會顯示任務獎勵的物品和聲望值。

## 里程碑獎勵

每位村民都有各自的友善里程碑，每個里程碑對應一定的聲望等級（並非所有村民的里程碑步驟都相同）。當你達到某個里程碑時，就會獲得獎勵。 **與該村民對話**即可領取獎勵。獎勵可以是物品、食譜知識或一段特別的感謝對話。

如果你同時達到了多個里程碑，只要對話一次，就能了解他們欠你的獎勵。任務日誌中的「村民」標籤頁會列出每位村民及其里程碑，但不會劇透他們的禮物偏好。

## 城鎮記錄架上的禮物歷史

打開**城鎮記錄架**（旅館或市政廳），按村民瀏覽。您可以查看已贈送的禮物以及村民對每份禮物的感受。這有助於您避免重複送錯禮物，並計劃下次送什麼。

## 小貼士

* **戒指和項鍊**是每位村民都喜歡的禮物。在了解村民的個人喜好之前，珠寶是可靠的選擇。未鑑定的珠寶，只要是實體戒指或項鍊，也算數。請參閱「機制」下的**珠寶**，以了解如何取得和製作珠寶。

* 將每日拜訪、任務線和精心準備的禮物結合起來，送給您最關心的村民。

* 里程碑獎勵需親自領取。如果您跨越了某個里程碑但沒有收到任何獎勵，請在遊戲中找到村民並與他們對話。
