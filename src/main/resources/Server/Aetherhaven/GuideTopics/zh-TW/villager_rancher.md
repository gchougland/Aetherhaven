**薩倫·梅多倫** 值班時通常會在**穀倉**。

### 任務

#### 薩倫的穀倉

建造一個穀倉，以便薩倫·梅多倫可以照顧牲畜、收集獸皮和羊毛，並儲備肉類和雞蛋。

1. 從薩倫處領取穀倉地塊代幣。

2. 圈定並建造穀倉預製件。

3. 在農活台找到薩倫，並透過對話完成任務。

#### 薩倫的家

薩倫想要一間可以放靴子和睡覺的房子，而不是畜欄旁堆放的稻草和飼料桶。

1. 從薩倫處領取房屋地塊代幣。

2. 圈定並建造房屋預製件。

3. 在房屋管理欄中將薩倫指定為住戶。

4. 找到薩倫，並透過對話完成任務。

### 友情獎勵

友情等級達到相應等級後，即可拜訪好友並透過對話領取獎勵。

- **友情等級 50：** 學會製作 **成長藥劑**

- **友情等級 100：** 學會製作 **獵刀**
