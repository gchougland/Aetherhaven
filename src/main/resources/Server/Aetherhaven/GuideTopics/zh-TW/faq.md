# 常見問題解答

此處的答案旨在方便您在遊戲過程中快速參考。如果仍有疑問，請查看**遊戲機制**或**村民**頁面以獲取更詳細的資訊。

## 該模組是否會包含*此*功能？

答案很可能是肯定的，但請查看開發路線圖。歡迎在模組的 Discord 伺服器中提出您的建議。

## 我可以在哪裡回報錯誤或提出功能建議？

您可以在模組的 Discord 頻道提交錯誤報告和功能請求。提供您的遊戲版本以及您是單人遊戲還是伺服器遊戲可以避免很多來回溝通。

## 模組更新後存檔會失效嗎？

我們會盡力確保資料遷移的安全，但在進行重大更新之前，請務必**備份您的存檔**，尤其是在長期運行的伺服器上。

## 我可以設計自己的建築而不是使用現有的預製件嗎？

整合建築工具是此模組計畫中的功能。目前添加建築需要進行相當多的配置。建築物建成後可以拆除/重建，但請注意，破壞/移動某些家具/長凳可能會導致村民無法使用這些設施來滿足他們的需求。例如，移動床會導致村民找不到床。如果您希望自己的建築作品在主模組中展示並註明出處，可以前往 Discord 上的建築提交頻道。
