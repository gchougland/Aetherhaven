# 旅遊傳送門

**旅遊傳送門**會吸引城鎮以外的遊客。 **長老萊倫**會在**市政廳**建成後提供建造任務。

## 建造傳送門

1. 與萊倫對話並接受旅遊傳送門任務。

2. 從萊倫處領取旅遊傳送門地塊代幣。

3. 圈地並建造旅遊傳送門預製件。

4. 找到萊倫並透過對話完成任務。

## 每日訪客

每天早上，**遊客**可以透過傳送門抵達。他們會在城鎮中漫步，瀏覽**商店**（包括玩家商店），並在**夜晚**離開。

遊客是經過精心挑選的角色，他們的性格特徵會影響他們的對話。他們與**旅店客人**不同－有關旅店雙人輪換機制，請參閱「機制」下的「旅館客人池和客人」部分。

## 邀請遊客留下

如果您想讓遊客成為永久居民，請為他們提供**房屋**：

1. 建造房屋地塊，並透過相應的房屋任務流程將其分配到管理區。

2. 註冊後，他們將像其他居民一樣計入城鎮生活。

在玩家商店購物的遊客會花費真金白銀——因此，在您的商店裡儲備一些實用商品非常重要。

## 小貼士

* 在期待大量遊客消費之前，請先完成**您自己的商店**（由Vex提供）—他們會在玩家商店購物。

* 傳送門和旅館的功能不同：旅館會將劇情**訪客**鎖定以完成任務；傳送門則會每天帶來重複的**遊客**。
