# 地塊代幣

**地塊代幣**是您物品欄中的物品，用於在**地塊放置桿**上選擇建築類型，然後在地圖上標記地塊位置。

## 地塊製作台

在**地塊製作台**製作地塊代幣。製作台會在您投入材料前顯示建築物的**3D預覽**。在**城鎮規劃桌**製作製作台，然後像放置其他工作台一樣放置它。

大多數劇情任務仍然會直接從任務發布者那裡獲得第一個代幣。之後，替換代幣和額外的代幣通常來自製作台。

## 地塊藍圖

有些建築物需要**地塊藍圖**才能建造，而不是像其他建築物那樣從氣球中掉落現成的代幣。

1. **使用**藍圖物品，在您的地塊製作台上永久解鎖該地塊。

2. 打開製作台並製作地塊代幣（需要材料和金幣，與其他代幣相同）。

3. 裝備**地塊放置杖**並標記地塊位置。

**白色漂浮禮物**通常包含藍圖。綠色禮物多為珠寶；紅色禮物多為家具。氣球禮物比以前更稀有。

## 回收

多餘的地塊標記（包括禮物中的變體標記）可以在工作台上回收，換取金幣，前提是您不需要重複的標記。

**提示**

* 如果建築物包含商鋪，請閱讀「機制」下的**玩家商店和商店位置**。

* 花店、煙火師和水晶守護者商店任務獎勵的是藍圖，而不是直接的標記。
