**艾薇·布魯姆韋爾**會在她的**花店**建成後出售植物和鮮花。她會在**維克斯的市場攤位**建成後出現在旅館。

使用下方的**顯示每週行程**查看艾薇每天的行程。

### 任務

#### 艾薇的花店

艾薇想要一家像樣的花店，與鎮上的居民分享她的植物。

1. 在旅店與艾薇對話並接受任務。

2. 從艾薇那裡獲得花店的**藍圖**。

3. 在你的**地塊製作台**使用藍圖學習花店建造。

4. 製作一個商店地塊代幣並建造花店預製件。

5. 在花店找到艾薇，並透過對話完成任務。

#### 艾薇的家

即使是整天和植物說話的花藝師，也需要一個安靜的休息場所。

1. 從艾薇那裡拿到房屋地塊代幣。

2. 圈地並建造房屋預製件。

3. 在房屋管理欄中將艾薇指定為住戶。

4. 找到艾薇，並透過對話結束任務。
