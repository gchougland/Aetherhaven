**アイビー・ブルームウェル**は、**花屋**が完成すると、そこで植物や花を販売します。**ベックスの露店**が完成すると、彼女は宿屋に現れます。

下の**週間スケジュールを表示**を使って、アイビーが毎日どこへ行くかを確認してください。

### クエスト

#### アイビーの花屋
アイビーは、町の人々に自分の育てた植物を届けられる、ちゃんとしたお店を持ちたいと思っています。

1. 宿屋でアイビーに話しかけ、クエストを受諾してください。

2. アイビーから店の**設計図**を受け取ってください。

3. 設計図を**区画クラフトベンチ**で使用して、花屋の作り方を覚えてください。

4. 店区画トークンを作成し、花屋のプレハブを建設してください。

5. 店でアイビーを見つけ、会話でクエストを完了してください。

#### アイビーの家
一日中植物に話しかけている花屋だって、静かに休める場所が必要です。

1. アイビーから住宅用地トークンを受け取る。

2. プレハブ住宅を建設し、杭を打ち込む。

3. 住宅管理ブロックでアイビーを居住者として登録する。

4. アイビーを見つけ、会話でクエストを完了する。
