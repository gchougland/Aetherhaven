# ギルドホールと衛兵

**ギルドホール**は、冒険者たちが集まる中盤の公共施設です。**ライラ・フェアホロー**は、町役場が完成した後、ギルドホールの建設を依頼してきます。建設クエストについては、彼女の村人ページをご覧ください。

ギルドホールが完成すると、**衛兵**を雇ったり、**巡回ルート**を設定したり、**司令部**を使って戦場を俯瞰したりできるようになります。

## 衛兵の雇用

ギルドホールにいる冒険者に話しかけて、**衛兵**を雇いましょう。衛兵は騎士、弓兵、魔法使いの3種類がいます。彼らは町を巡回し、敵対的なモンスターと戦います。村人、観光客、他の衛兵は攻撃しません。

衛兵は、巡回ルートや命令がないと行動できません。任務が割り当てられていない衛兵も、可能な限り近くの脅威を防御します。

## 巡回杖

**巡回杖**は、**町計画デスク**で作成できます。青い光は、杖を持っている間だけ保存済みのルートを示します。

### 構築モード（デフォルト）

* **地面を右クリック** — 巡回地点を追加します。

* **地点を右クリック** — 地点を削除します。

* **保存済みのルート上の地点を左クリック** — そのルートを選択して編集します。

* **F** — ルートに名前を付けて保存します（最低2つの地点が必要です）。

* **R** — **閉ループ**（警備員が最後の地点から最初の地点に戻るループ）と**往復**を切り替えます。

* **E** — 新しいルートを作成します。

* **Q** — 割り当てモードに切り替えます。

### 割り当てモード

* **ルート上の地点を左クリック** — 保存済みのルートを選択します。

* **F** — 警備員リストを開き、ルートに警備員を割り当てます。

* **E** — 選択したルートから警備員を削除します。

* **Q** — 構築モードに切り替えます。


選択されたルートは**緑色**に光り、その他のルートは**青色**のままです。複数のルートを担当する警備兵は、各ループを順番に巡回します。

## 指揮所

町に**警備兵指揮所**の椅子を設置します（クリエイティブモードまたは進行状況に応じてアンロックされます）。**これを使用する**と、**指揮モード**に入ることができます。これは、町を俯瞰するRTSスタイルの視点です。

### カメラと選択

* **WASD** - 戦場の視点をパンします。

* **スペースキー / Ctrlキー** - 上下に移動してズームします。

* **スクロールキーまたは数字キー** - コマンドツールを切り替えます。

* **警備兵をクリック** - 警備兵を選択します。

* **Shiftキーを押しながらクリック** - 選択に追加または削除します。

* **ボックスをドラッグ** - 複数の警備兵を一度に選択します。

### 命令

* **攻撃移動 / 移動ツール** - 地面を右クリックすると、選択した警備兵が移動します。 **アビリティ1**は攻撃移動と移動のみを切り替えます。**アビリティ2**は選択した衛兵を停止させます。

* **集中攻撃ツール** — クリーチャーを右クリックすると、衛兵の攻撃対象をそのクリーチャーに集中させます。

* **スタンスツール** — **アビリティ1**は選択した衛兵の戦闘スタンス（防御、攻撃、待機、射撃停止）を切り替えます。

* **解放ツール** — 右クリックすると、選択した衛兵の命令を解除します。

* **すべて選択／種類別選択** — HUD上の名簿ボタン。

* **コマンド終了ツール（ホットバースロット8）** — コマンドモードを終了します。

コマンドポストは**町の領地内**に設置する必要があります。少なくとも1人の衛兵を雇用する必要があります。

## クエストボード

ギルドホールには、毎日のお使い、狩猟、襲撃の依頼を表示する**クエストボード**もあります。詳細は「メカニクス」の**クエストボード**をご覧ください。
