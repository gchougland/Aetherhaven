**ローワン・リッジクラフト**は町の**建設者**です。小屋が完成すると、彼は勤務時間中に建設中の区画へ出向き、看板の作業をしながら建設を早める手助けをします。

下の**週間スケジュールを表示**を使って、ローワンが毎日どこへ行くのかを確認してください。

### クエスト

#### ローワンの建設小屋
ローワンに、建設計画を立て、町の発展に貢献できる立派な小屋を与えましょう。

1. 宿屋でローワンに話しかけ、クエストを受諾する。

2. ローワンから建設小屋の区画トークンを受け取る。

3. 建設小屋のプレハブを杭打ちして建てる。

4. 小屋でローワンを見つけ、会話でクエストを完了する。

#### ローワンの家
優れた建築に情熱を注ぐ建設者にも、静かに休める場所が必要です。


1. ローワンから住宅用地トークンを受け取る。

2. プレハブ住宅を建設し、杭を打ち込む。

3. 住宅管理ブロックでローワンを居住者として登録する。

4. ローワンを見つけ、会話でクエストを完了する。
