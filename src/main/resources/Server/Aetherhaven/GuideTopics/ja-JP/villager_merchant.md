**ベックス・サンダーレーン**は、マーケットの屋台が完成すると、**ショップスポット**で**雑貨店**を経営します。商品は夜明けに補充されます。購入するには、スポットで**F**キーを押してください。詳細は「ゲームシステム」の「プレイヤーショップとショップスポット」をご覧ください。

### クエスト

#### ベックスの家
ベックスはどこにでも在庫を積み重ねることができます。それでも、ノックに反応してくれる、雨風をしのげる場所が欲しいのです。

1. ベックスから家の区画トークンを受け取ります。

2. プレハブの家を建て、杭を打ちます。

3. 家の管理ブロックでベックスを居住者として設定します。

4. ベックスを見つけ、会話でクエストを完了します。

#### ベックスのマーケットの屋台
ベックスにカウンターと屋根を与え、サルベージ品を安全に保管できる場所を作りましょう。

1. ベックスからマーケットの屋台区画トークンを受け取ります。

2. プレハブのマーケットの屋台を建て、杭を打ちます。

3. 屋台でベックスを見つけ、会話でクエストを完了させましょう。

#### 自分だけの店
町民や観光客に商品を販売できる店を建てましょう。

1. まず**ベックスの屋台**を完成させましょう。

2. ベックスから**プレイヤーショップ**の区画トークンを受け取りましょう。

3. プレイヤーショップのプレハブを設置し、建築しましょう。

4. ベックスを見つけ、会話でクエストを完了させましょう。

### 友情報酬

友情レベルが上がるごとに、ベックスを訪ねて会話で報酬を受け取りましょう。

- **友情レベル50**：**鑑定台**の製作方法を習得できます。
- **友情レベル100**：**宝石製作台**の製作方法を習得できます。
