# パスデザイナーシャベル

**パスデザイナーシャベル**を使うと、街中に曲線状のパスを描き、プレビューして、ブロックを地面に配置できます。ツールを持っている間は、キーヒントが表示されるステータスパネルが表示されます。

**都市計画デスク**で作成できます。

## モード

**Q**キーを押すと、5つのモードが切り替わります。

1. **移動** — コントロールノードを追加・移動してパスの形状を調整します。

2. **回転** — 選択したノードを回転させてスプラインを曲げます。

3. **配置** — 完成したパスを地面に固定します。

4. **削除** — 配置済みのパス（オレンジ色でハイライト表示されます）を確認し、不要なパスを削除します。

5. **スタイルデザイナー** — チェストグリッドでパスのスタイルを作成・編集します。

パスブロックを配置する準備ができたら、HUDに**配置**モードに切り替えるよう通知が表示されます。


## モード別操作

### 移動、回転、配置

* **地面上で右クリック（セカンダリーキー）** — ノードを追加します。

* **ノードを選択した状態で右クリック（セカンダリーキー）** — そのノードを削除します。

* **ノード上で左クリック（プライマリーキー）** — ノードを選択します。

* **移動モードで地面上でクリック（プライマリーキー）** — 選択したノードを移動します。

* **回転モードでFキー** — 選択したノードの方向を微調整します。

* **配置モードでFキー** — パスを地面に配置します。

* **Eキー** — パスの幅を切り替えます。

* **Rキー** — パスのスタイルを切り替えます。

* **Qキー** — 次のモードへ移動します。

### 削除

* **配置済みのパスを選択（プライマリーキー）** — 配置済みのパスを削除します。

* **Qキー** — 次のモードへ移動します。


### スタイルデザイナー

* **F** — スタイルマネージャーを開きます（重み付きブロック列用の二重チェストグリッド）。

* **E** — パススタイルを保存します（チェストが開いている状態）。

* **Q** — 次のモードに切り替えます。

## プレビュー表示

編集中は、白いノードと線がスプラインを示します。茶色のプレビューはブロックが配置される場所を示し、緑色のエッジが両側に表示されます。**削除**モードでは、確定済みのパスがオレンジ色で表示されます。

## ヒント

* まず**移動**と**回転**でスプラインの形状を整え、次に**配置**に切り替えて**F**を押して確定します。

* **スタイルデザイナー**でカスタムルックを作成できます。各スタイルは、パスの幅に沿って転がされた重み付きブロック列です。

* パスはワールドとタウンのセーブデータに保持されます。
