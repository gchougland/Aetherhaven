**イリエンヌ・モスマーク**は、勤務中は通常**農地**にいます。

### クエスト

#### イリエンヌの農地
イリエンヌに柵で囲まれた土地とベンチを与えて、彼女が宿屋の床に並ぶ夢を見なくて済むようにしましょう。

1. イリエンヌから農地トークンを受け取ります。

2. 農地のプレハブを杭で固定し、建築します。

3. 農作業台にいるイリエンヌを見つけ、会話でクエストを完了します。

#### イリエンヌの家
イリエンヌは、やかんの横にある借り物の床板ではなく、自分の家である屋根裏の根っこが欲しいのです。

1. イリエンヌから家の区画トークンを受け取ります。

2. 家のプレハブを設置し、建築します。

3. 家の管理ブロックでイリエンヌを居住者として設定します。

4. イリエンヌを見つけて、会話でクエストを完了してください。

### 友情報酬

友情レベルが上がるごとに、イリエンヌを訪ねて会話で報酬を受け取りましょう。

- **友情レベル25:** **スプリンクラーアイアン**の製作方法を習得
- **友情レベル50:** **スプリンクラートリウム**の製作方法を習得
- **友情レベル75:** **スプリンクラーコバルト**の製作方法を習得
- **友情レベル100:** **スプリンクラーアダマンタイト**の製作方法を習得
