# ガイドへようこそ

このガイドは、あなたの町のジャーナルの中にあります。左側のトピックを選択して、詳細をご覧ください。

**はじめに**では、町の設立、最初の建物の建設、そしてお金の流れについて説明します。

**システム**では、町で使用する道具、建物、システムについて説明します。

**住民**では、各住民、ストーリークエスト、評判ギフト、そして週ごとのルーティンを紹介します。ギフトの好みに関するネタバレは、あなたが公開を選択するまで表示されません。
