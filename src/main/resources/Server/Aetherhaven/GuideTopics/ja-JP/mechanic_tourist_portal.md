# 観光客ポータル

**観光客ポータル**は、町外から旅行者を呼び込みます。**長老ライレン**は、**町役場**が完成した後、建設クエストを提供します。

## ポータルの建設

1. ライレンに話しかけ、観光客ポータル建設クエストを受諾します。

2. ライレンから観光客ポータル用地トークンを受け取ります。

3. 杭を打ち込み、観光客ポータルのプレハブを建設します。

4. ライレンを見つけ、会話でクエストを完了します。

## 毎日の訪問

毎朝、**観光客**がポータルを通って町にやって来ます。彼らは町を散策し、**ショップスポット**（プレイヤーショップを含む）を見て回り、**夜**に去っていきます。

観光客は、個性的な性格特性を持つ厳選されたキャラクターで、会話の内容もそれに合わせて変化します。彼らは**宿屋の宿泊客**とは別です。宿屋の宿泊客のローテーションについては、「宿屋のプールと宿泊客」の項目を参照してください。



## 観光客を滞在に誘う

観光客を永住者にするには、**家**を提供しましょう。

1. 住宅用地を建設し、適切な住宅クエストの流れを通して管理ブロックに割り当てます。

2. 登録が完了すると、他の住民と同様に町の生活に貢献するようになります。

プレイヤーの出品物を購入する観光客は、自分のポケットからリアルゴールドを消費します。そのため、ショップのスペースに役立つ商品を揃えておくことが重要です。

## ヒント

* 観光客の消費を期待する前に、**自分の店**（Vexから入手）を完成させましょう。観光客はプレイヤーのショップのスペースから商品を購入します。

* ポータルと宿屋は異なる役割を果たします。宿屋はクエストのためにストーリー上の**訪問者**を閉じ込め、ポータルは毎日訪れる**観光客**を呼び込みます。
