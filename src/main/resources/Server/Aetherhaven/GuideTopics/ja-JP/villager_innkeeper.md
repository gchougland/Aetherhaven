**コリン・モスカップ**は、勤務中は通常**宿屋**にいます。

### クエスト

#### 息抜きの場所
コリンは、町の人々が家事の合間に少し休憩できるよう、ベンチのある小さな公園を欲しがっています。

1. コリンから公園用地トークンを受け取ります。

2. 杭を打ち、公園を建設します。

3. 宿屋でコリンを見つけ、会話でクエストを完了します。

#### コリンの家
コリンはまず他の人に食事を与えます。彼は、夜が明けたら自分の散らかったものを隠せるドアが欲しいと思っています。

1. コリンから家用地トークンを受け取ります。

2. 杭を打ち、プレハブ住宅を建設します。

3. 住宅管理ブロックでコリンを居住者として設定します。

4. コリンを見つけ、会話でクエストを完了します。


### 友情報酬

友情レベルが上がるごとに、相手を訪ねて会話を通して報酬を受け取りましょう。

- **友情レベル50**：**宴会テーブル**の作り方を教えてくれます。
- **友情レベル75**：**次の友情イベントを見るために相手を訪ねましょう。
- **友情レベル100**：**次の友情イベントを見るために相手を訪ねましょう。
