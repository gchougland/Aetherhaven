**ライラ・フェアホロウ**は、ギルドホールが完成すると運営を担います。冒険者たちはここに集まり、彼らを**衛兵**として雇うことができます。衛兵はパトロールを行い、敵対的なモンスターと戦います。パトロールルートと司令部については、「システム」の「ギルドホールと衛兵」をご覧ください。

下の**週間スケジュールを表示**を使って、ライラの毎日の行動を確認しましょう。

### クエスト

#### ギルドホールを建てよう
ライラは、冒険者が登録でき、衛兵を雇えるような立派なギルドホールを望んでいます。

1. まず**町役場**を完成させ、宿屋でライラに話しかけてください。

2. ライラからギルドホールの区画トークンを受け取ってください。

3. ギルドホールのプレハブを杭打ちして建ててください。

4. ギルドホールでライラを見つけ、会話でクエストを完了してください。


#### ライラの家
ライラは夜明けから夕暮れまでギルドホールを切り盛りしています。彼女は夜、自分だけの静かな屋根の下で過ごしたいと願っています。

1. ライラから家の区画トークンを受け取ります。

2. プレハブ住宅を設置し、建てます。

3. 住宅管理ブロックでライラを居住者として登録します。

4. ライラを見つけ、会話でクエストを完了します。
