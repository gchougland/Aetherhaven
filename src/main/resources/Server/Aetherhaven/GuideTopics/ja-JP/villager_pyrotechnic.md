**グラブル・スパークマッチ**は、爆発物を売るゴブリンの**花火師**です。彼が宿屋を訪れるようになるには、**ワールド内で彼を見つけて解放する**必要があります。救出後、彼は町に爆弾屋を開店します。

下の**週間スケジュールを表示**を使って、グラブルが毎日どこへ行くかを確認してください。

### クエスト

#### グラブルの大脱走
探索中に、蜘蛛の繭に閉じ込められたグラブルを見つけるかもしれません。彼を解放すると、このクエストは完了です。その後、彼は宿屋に現れるようになります。

#### グラブルの爆弾屋
グラブルは、町の人々に爆発物を売るためのちゃんとした店を持ちたいと思っています。

1. 宿屋でグラブルに話しかけ、クエストを受諾する。

2. グラブルから店の**設計図**を受け取る。

3. 設計図を**区画作成台**で使用して、爆弾屋を習得しましょう。

4. 店舗区画トークンを作成し、爆弾屋のプレハブを建設しましょう。

5. 店でグラブルを見つけ、会話でクエストを完了させましょう。

#### グラブルの家
騒がしいゴブリンだって、時には静かなベッドが必要です。

1. グラブルから家の区画トークンを受け取りましょう。

2. 杭を打ち込み、家のプレハブを建設しましょう。

3. 家の管理ブロックでグラブルを住人として設定しましょう。

4. グラブルを見つけ、会話でクエストを完了させましょう。
