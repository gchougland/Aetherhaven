# 評判

**評判**とは、村人があなたをどれだけ信頼し、好んでいるかを示す指標です。これは個人的なもので、農夫との評判は商人との評判には影響しません。評判は0から100までの範囲で表示されます。

評判が高くなると、マイルストーン報酬や新しいレシピがアンロックされます。マイルストーンの進行状況や各キャラクターのプレゼントの好みは、町の日記の**村人**タブで確認できます。プレゼントの履歴は、宿屋または役場の**町の記録棚**で確認できます。

## 評判を上げる方法

**毎日話しかける**
新しい朝を迎えて初めて村人と話すと、評判が少し上がります。町を歩いているついでに立ち寄ってみましょう。評判は徐々に上がっていきます。

**プレゼントを贈る**
会話中に、手にアイテムを持った状態でプレゼントの選択肢を選びましょう。村人はプレゼントに対して「大好き」「好き」「どちらでもない」「嫌い」の反応を示します。良い反応ほど評判が上がります。気に入らない贈り物は、好感度を下げる原因になります。

村人一人につき、週に贈れる贈り物の数には制限があります。好印象を与えたい村人には、特別な贈り物をしましょう。

**クエストを完了する** 長老、宿屋の主人、その他の村人から受けられるストーリークエストを完了すると、好感度が上がることがよくあります。ジャーナルの**クエスト**タブには、クエストで報酬が得られるアイテムと好感度が表示されます。

## マイルストーン報酬

各村人には、それぞれ好感度が一定レベルに達すると達成できるマイルストーンが設定されています（キャラクターによって達成条件は異なります）。マイルストーンを達成すると、報酬がもらえます。**その村人に話しかける**ことで報酬を受け取ることができます。報酬はアイテム、レシピ、特別な感謝の会話などです。

複数のマイルストーンを同時に達成した場合は、一度話しかけて、それぞれの村人があなたに与えてくれるものを受け取りましょう。ジャーナルの**村人**タブには、各キャラクターとそのマイルストーンが一覧表示されていますが、贈り物の好みはネタバレにならないようになっています。


## 町の記録棚で贈り物の履歴を確認

**町の記録棚**（宿屋または役場）を開いて、村人ごとに閲覧しましょう。これまでに贈った贈り物と、それぞれの贈り物に対する村人の反応を確認できます。これは、同じ失敗を繰り返さず、次の贈り物を考えるのに役立ちます。

## ヒント

* **指輪とネックレス**は、すべての村人の好きな贈り物リストに載っています。相手の好みがわかるまでは、ジュエリーは確実な選択肢です。たとえ正体不明のジュエリーでも、実際に指輪やネックレスを手にすれば、贈り物としてカウントされます。ジュエリーの入手方法や製作方法については、「ゲームシステム」の「ジュエリー」の項目をご覧ください。

* 毎日訪問したり、クエストをこなしたり、心のこもった贈り物をしたりして、特に大切な村人にプレゼントしましょう。

* マイルストーン報酬は、直接村人に渡して受け取ります。マイルストーンを達成したのに何も起こらない場合は、ゲーム内で村人を見つけて話しかけてみましょう。
