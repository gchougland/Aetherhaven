**ヴァエリス・プリズムシェード**は、クリスタルと宝石を販売する古代の**クリスタルキーパー**です。彼女が宿屋を訪れるようになるには、**彼女をワールド内で見つけて解放する**必要があります。救出後、彼女は町にクリスタルショップを開店します。

下の**週間スケジュールを表示**を使って、ヴァエリスの毎日の行動を確認しましょう。

### クエスト

#### ヴァエリスの救出
探索中に、石に閉じ込められたヴァエリスを見つけるかもしれません。彼女を解放すると、このクエストは完了です。その後、彼女は宿屋に現れるようになります。

#### ヴァエリスのクリスタルショップ
ヴァエリスは、町の人々に自分のクリスタルコレクションを共有できる、ちゃんとした店を持ちたいと思っています。

1. 宿屋でヴァエリスに話しかけ、クエストを受諾します。

2. ヴァエリスから店の**設計図**を受け取ります。

3. 設計図を**製作台**で使用して、クリスタルショップの作り方を習得します。 4. ショップ区画トークンを作成し、クリスタルショップのプレハブを建設します。

5. ショップでヴァエリスを見つけ、会話でクエストを完了します。

#### ヴァエリスの家
古代のクリスタルの守護者でさえ、石の光に包まれた静かな休息場所を必要としています。

1. ヴァエリスから家の区画トークンを受け取ります。

2. 家のプレハブを杭打ちして建設します。

3. 家の管理ブロックでヴァエリスを居住者として設定します。

4. ヴァエリスを見つけ、会話でクエストを完了します。
