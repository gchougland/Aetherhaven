# ロードマップ

## バージョン2.0で実装

以前のマイルストーン項目の多くがゲームに実装されました：**ギルドホールと衛兵**、**クエストボード**（デイリークエスト）、**プレイヤーショップ**、**観光ポータル**、新しい村人（建築家、花屋、花火師、クリスタルキーパー、吟遊詩人）、**区画設計図**、**生産アップグレード**、そして改良された**パスデザイナーシャベル**。詳細は、このジャーナルの**メカニクス**と**村人**の項目をご覧ください。


## マイルストーン（現在の順序）

1. **博物館アップデート**
2. **交易ネットワークアップデート**
3. **プレイヤー住宅アップデート**
4. **カスタム建築アップデート**（区画作成ワークフローの拡張）
