# 区画作成スタッフ

区画作成スタッフは、ワールドに構築した**カスタム建物**を登録します。登録内容は、設置面積、特殊ブロック、プレハブのエクスポート、コスト、そして（オプションで）町内の稼働中の区画です。ほとんどのプレイヤーは、下記の完全な作業場タイプではなく、**装飾**または**バリアント**を使用してください。

操作の流れを学ぶ際は、**町のジャーナル → ガイド → メカニクス → 区画作成スタッフ**（このページ）を開いてください。プレイ中は、スタッフを装備し、**F**キーを押して開始するか、現在のステップパネルを開きます。ワールド内のブロックを**プライマリークリック**し、**Q**キーまたは**E**キーで前のステップまたは次のステップへ移動、**R**キーでキャンセルします。

## 推奨パス

| 目標 | 建物タイプ | 注記 |

|------|----------------|-------|

| 装飾用建物、仕事なし | **装飾** | オプションで町の記録棚を追加可能。生産や村人のロジックはなし。 |

| 既存の建物の別バージョン | **バリアント** | **メイン**の建物としてカウントする建物（家、納屋、宿屋など）を選択してください。サブステップは、選択したメインタイプに従います。|

| 新しい職場/生産区画（モッディング）| **作業** | 新しい職場タイプを追加する場合。管理ブロック、生産倉庫、作業面POIが必要です。|

## 建物タイプ（選択）

**装飾** — 家、店、職場として**機能しない**公園、小道具、建造物。最低限必要な場所。

**バリアント** — 既にMODに存在する別の建物IDとして**カウントされる**プレハブ（例：`plot_house`としてカウントされるカスタムハウス）。ドロップダウンからメインタイプを選択します。重要な場所は、選択したメイン建物と一致します。

**家** — 居住区画：町の記録棚 + 睡眠POI。


**職場** — **開発者/コンテンツ作成者向け** 新しい**職場**スタイルの区画を定義します：町の記録棚、生産倉庫、作業台POI。新しい生産施設や職業施設タイプを追加する場合に使用してください。通常の外観変更には使用しないでください。

**アメニティ** — 娯楽施設（公園、祭壇型アメニティ）：棚 + 娯楽/休憩用POI。

**ショップ** — 屋台または店舗カウンター：棚 + ショップタグ付きの作業用POI。

**宿屋** — 完全な宿屋のレイアウト：棚、作業台、ベッド、食事場所、宿屋の主人と訪問者のスポーン地点（オプションでギルドマスターのスポーン地点も）。

**市役所** — 市民の拠点：棚、財務ブロック、計画デスクPOI。

**ギルドホール** — 冒険者ギルド：棚、作業台、冒険者のスポーン地点。


### 重複と混乱

- **バリアント** と **ホーム / ワーク / …** — バリアントは「見た目が異なり、Xのように動作する」建物に使用します。既存のゲームプレイ用建物の外観を変更する場合は、**ホーム**ではなく、**バリアント**とメインタイプを選択してください。

- **ワーク** と **ショップ** — **ショップ**は商人の屋台に使用します。**ワーク**は農場、製粉所、鍛冶場、その他の生産作業場に使用します。

- **アメニティ** と **装飾** — **装飾**はゲームプレイ上の要素がほとんどありません。**アメニティ**は、村人のスケジュールに合わせて、楽しさ/アメニティのタグとPOIを設定します。

- **宿屋**、**町役場**、**ギルドホール**は完全なテンプレートです。**バリアント**は、これらのテンプレートのいずれかに意図的に合わせる場合にのみ使用してください。


## 手順（概要）

1. 対角線上の2つの角と、**外側**の区画標識の角をマークします。

2. **建物タイプ**（該当する場合は**バリエーション**も）を選択します。

3. **重要な場所**を配置します（ブロックは各サブステップごとに1つずつ配置されます）。

4. **名前とID**を入力します（プレハブファイル名はIDの後に続きます）。

5. 必要に応じて**タグ**を編集します。

6. **建物設定**（Fキー）を開きます：金庫の金貨コスト、セルフビルド日数、空きスペースプレハブオプション、アセンブリセクション。

7. 形状保存ステップで**プレハブをエクスポート**します（ステップ6の設定が使用されます）。

8. **建築資材**を設定します（仮想チェスト。アイテムは続行時に返却されます）。

9. 確認して保存します。

## 権限

デフォルトでは、設定により、すべてのユーザーが区画作成ツールを使用できる場合があります。サーバーは代わりに`aetherhaven.plot.creator`権限を要求することができます。
