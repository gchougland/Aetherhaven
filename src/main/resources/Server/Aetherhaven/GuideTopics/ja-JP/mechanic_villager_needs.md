# 村人のニーズ

村人全員は、**空腹**、**エネルギー**、**楽しみ**という3つのニーズを抱えています。それぞれのメーターは空から満タンまで変化します。これらのメーターは、宿屋または役場の「ニーズ」タブにある村の記録棚で確認できます。

## ニーズが重要な理由

村人は時間が経つにつれて徐々に空腹になり、疲れ、娯楽を求めるようになります。メーターが低くなると、村人はそれを解消するために村内の適切な場所を探します。

ニーズは**税金**にも関係しています。毎朝、住民は金貨を国庫に納めます。納める金額は、村人の快適さによって部分的に決まります。快適な村人ほど多く納めます。メーターを高く保つことは、村人にとっても、村の財政にとっても良いことです。

## 注目スポット

完成した建物には、村人が利用できる**スポット**が追加されます。ベッド、ベンチ、カウンター、作業台などのブロックが設置されます。それぞれのスポットは、村人による小さな行動を表していると考えてください。



* **ベッド**は**エネルギー**を回復します（夜間の家の中のベッドも含む）。

* **ベンチや椅子**（公園のベンチを含む）は**楽しさ**を回復します。

* **キッチンカウンター、テーブル、食料保管庫**は**空腹**を回復します。

* **作業台や店のカウンター**は、勤務時間中に**空腹**と**エネルギー**を少し回復します。

場所によって配置が異なります。農場には作業台があります。宿屋にはベッドと食事スペースがあります。公園にはリラックスするための屋外ベンチがあります。

## 村人が場所を選ぶ方法

村人は日課に従って行動しますが、メーターが非常に低くなると、しばらくの間、その場を離れることがあります。**空腹**が深刻な場合は、食料を探しに行きます。**エネルギー**が低い場合は、ベッドを探します。**楽しさ**が低い場合は、ベンチや社交スポットを探します。

それぞれの場所を自分でクリックする必要はありません。適切な区画を建設すれば、村人たちは日中、自然とそれらを見つけてくれます。

## 夜間の家

**家**は必須ではありません。村人は町で仕事をするために、**職場**の区画だけが必要です。

誰かを家に割り当てると、夜はそこで眠ることができます。睡眠によって**エネルギー**が回復し、翌朝の十分の一税を納める際に快適な状態を保つことができます。**楽しさ**が不足している場合は、**公園**を利用しましょう。

## ヒント

* **楽しさ**のメーターが常に最低値の場合は、計画デスクから**公園**の区画を確保しましょう。公園のベンチはリラックスするために設置されています。

* 記録棚の**ニーズ**タブを使用すると、全員の状況を一目で確認でき、必要に応じて村人をテレポートさせて様子を伺うことができます。

* 宴会や一部の町の政策によって、快適な住民から得られる金貨の額が変わる場合があります。お金に関する詳細は**財務と税金**をご覧ください。
