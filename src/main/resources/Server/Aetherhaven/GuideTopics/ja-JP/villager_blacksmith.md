**ギャレン・ヴェイル**は、勤務時間中は通常**鍛冶屋**にいます。

### クエスト

#### ギャレンの鍛冶場
ギャレンは、コリンの床板の上で気が狂う前に、ちゃんとした鍛冶場と武器作業台を手に入れたいと思っています。

1. ギャレンから鍛冶屋の区画トークンを受け取ります。

2. 鍛冶屋のプレハブを杭打ちして建設します。

3. 武器作業台にいるギャレンを見つけ、会話でクエストを完了します。

#### ギャレンの家
ギャレンは作業中に煙と火花が出ています。夜は誰かの夕食の匂いがしない屋根が欲しいと思っています。

1. ギャレンから家の区画トークンを受け取ります。

2. 家のプレハブを杭打ちして建設します。

3. 家管理ブロックでギャレンを居住者として設定します。

4. ギャレンを見つけ、会話でクエストを完了します。 ### 友情報酬

友情レベルが上がるごとに、相手を訪ねて会話を通して報酬を受け取りましょう。

- **友情レベル25**：**岩石**×32**
- **友情レベル50**：**晶洞金床**の製作方法を習得
