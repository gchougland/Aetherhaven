# 財政と税金

財政ブロックには町の金が保管されます。住民は、現在のニーズ充足度に応じて毎朝の十分の一税を支払います。町は、たとえチャンクが読み込まれていなくても、町民が一人でもサーバーに接続していれば税金を徴収します。町民が誰もオンラインになっていない場合は、税金は徴収されません。税金の内訳は2番目のタブで確認できます。祝宴、創設者の像、町の政策など、税収を増やす方法は他にもいくつかあります。
