**ターレン・メドウラン**は、勤務中は通常**納屋**にいます。

### クエスト

#### ターレンの納屋
ターレン・メドウランが家畜の世話をし、皮や羊毛を集め、食料庫に肉や卵を保管できるよう、納屋を建てましょう。

1. ターレンから納屋用地トークンを受け取ります。

2. 納屋のプレハブを杭で固定し、建てます。

3. 農作業台にいるターレンを見つけ、会話でクエストを完了します。

#### ターレンの家
ターレンは、家畜小屋のそばに藁や飼料バケツがあるだけではなく、ブーツを履いて眠れる家が欲しいと思っています。

1. ターレンから家用地トークンを受け取ります。

2. 家のプレハブを杭で固定し、建てます。

3. 家管理ブロックでターレンを居住者として設定します。

4. ターレンを見つけて、会話でクエストを完了してください。

### 友情報酬

友情レベルが上がるごとに、ターレンを訪ねて会話で報酬を受け取りましょう。

- **友情レベル50:** **成長血清**の製作方法を習得できます。
- **友情レベル100:** **狩猟ナイフ**の製作方法を習得できます。
