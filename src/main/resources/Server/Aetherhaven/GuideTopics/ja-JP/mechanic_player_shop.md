# プレイヤーショップとショップスポット

**ショップスポット**ブロックは、完成した建築区画内に設置されます。これにより、NPCやプレイヤーは、会話メニューだけでなく、ゲーム内でアイテムを販売できるようになります。

## NPCショップ

村人のショップ（**Vexの雑貨店**、花屋、花火師、クリスタルキーパーなど）は、**夜明け**に戦利品テーブルから商品を補充します。各スポットには、浮遊するアイテムディスプレイが表示され、店の向きによってディスプレイが回転します。

* **Fキー（使用）** — 数量コントロール（±1、±10、最大）付きの購入パネルを開きます。

* **HUD表示** — 在庫のあるスポットを狙うと、アイテム名、価格、在庫数が表示されます。

Vexは、市場の屋台や関連建物のショップスポットを通じて、家具、ブロック、消耗品を販売する**雑貨店**を経営しています。


## 自分だけのショップ

**Vexのマーケット屋台**が完成すると、Vexは**自分だけのショップ**を提案します。

1. Vexから**プレイヤーショップ**の区画トークンを受け取ります。

2. プレイヤーショップのプレハブを設置し、建築します。

3. Vexを見つけ、会話でクエストを完了します。

プレイヤーショップには**ショップスペース**ブロックと、売上金を保管する**ショップ金庫**が含まれています。

### アイテムの出品

* アイテムを持った状態で**ショップスペースを右クリック**すると、出品できます（プレイヤーが管理するスペースのみ）。

* 自分の出品アイテムを**もう一度右クリック**すると、スペースから削除できます。

購入者は、商品が入ったスペースで**F**キーを押して購入します。誰かがあなたの出品アイテムを購入すると通知が届き、売上金は**ショップ金庫**に入金されます。

### 誰が買い物をする？

**村人**と**観光客**は、町を訪れた際にプレイヤーショップのスペースを閲覧し、出品されているアイテムを購入します。価格と在庫状況が重要です。空きスペースはスキップされます。

## 権限

町民はプレイヤーショップのスペースで販売するには許可が必要です。町のオーナーは町の記録棚からメンバーの権限を調整できます。

区画トークンの作成方法については、「メカニズム」の「区画トークン」を参照してください。
