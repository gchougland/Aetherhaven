# 부지 생성 도구

부지 생성 도구는 월드에 건설한 **맞춤 건물**을 등록합니다. 건물 크기, 특수 블록, 프리팹 내보내기, 비용, 그리고 (선택적으로) 마을에 있는 실제 부지 정보를 확인할 수 있습니다. 대부분의 플레이어는 아래의 전체 작업장 유형보다는 **장식** 또는 **변형** 유형을 사용하는 것이 좋습니다.

사용법을 익히는 동안에는 **마을 일지 → 가이드 → 메커니즘 → 부지 생성 도구**(이 페이지)를 열어 보세요. 게임 플레이 방법: 도구를 장착하고 **F** 키를 눌러 시작하거나 현재 단계 패널을 엽니다. 월드에 있는 블록을 **마우스 오른쪽 버튼으로 클릭**하고, **Q** 또는 **E** 키를 눌러 이전/다음 단계로 이동합니다. **R** 키를 눌러 취소합니다.

## 추천 경로

| 목표 | 건물 유형 | 참고 사항 |

------|----------------|-------|

| 장식용 건물, 직업 없음 | **장식** | 선택 사항: 마을 기록 선반, 생산 또는 주민 로직 없음 |

| 기존 건물의 다른 모양 | **변형** | 어떤 **주요** 건물로 간주할지 선택하세요(집, 헛간, 여관 등). 하위 단계는 선택한 주요 유형에 따라 진행됩니다. |

| 새로운 작업장/생산 부지(모딩) | **작업장** | 새로운 작업장 유형을 추가합니다. 관리 블록, 생산 저장소, 작업대 POI가 필요합니다. |

## 건물 유형(선택기)

**장식** — 공원, 소품, 주택, 상점 또는 작업장으로 **사용되지 않는** 건축물입니다. 최소한의 필수 공간이 필요합니다.

**변형** — 모드에 이미 있는 다른 건물 ID로 **간주되는** 프리팹입니다(예: `plot_house`으로 간주되는 맞춤형 주택). 드롭다운에서 주요 유형을 선택합니다. 중요한 공간은 선택한 주요 건물과 일치해야 합니다.

**주택** — 주거용 부지: 마을 기록 보관소 + 수면 POI.

**작업장** — **개발자/콘텐츠 제작자용**. 새로운 **작업장** 스타일의 부지를 정의합니다. 마을 기록 보관소, 생산 저장소, 작업대 POI가 포함됩니다. 새로운 생산 또는 직업 건물 유형을 추가할 때 사용하세요. 일반적인 외형 변경에는 사용하지 마세요.

**편의시설** - 오락 또는 여가 시설(공원, 제단형 편의시설): 선반 + 오락/휴식 공간 POI

**상점** - 가판대 또는 상점 카운터: 선반 + 상점 태그가 지정된 작업 POI

**여관** - 완전한 여관 배치: 선반, 작업대, 침대, 식사 공간, 여관 주인 및 방문객 생성 위치(선택 사항으로 길드 마스터 생성 위치 포함)

**시청** - 시민 중심지: 선반, 재정 블록, 계획 데스크 POI

**길드 회관** - 모험가 길드: 선반, 작업대, 모험가 생성 위치

### 중복 및 혼동

- **변형** vs **집/작업장/…** - 변형은 "외형은 다르지만 X처럼 작동하는" 건물을 의미합니다. 기존 게임플레이 건물의 외형을 변경하는 경우 **집**이 아닌 **변형** + 기본 유형을 선택하세요.

- **작업장** vs **상점** — **상점**은 상인 가판대를 위한 것이고, **작업장**은 농장, 제분소, 대장간 및 기타 생산 작업장을 위한 것입니다.

- **편의시설** vs **장식** — **장식**은 게임 플레이에 거의 영향을 미치지 않습니다. **편의시설**은 재미/편의시설 태그와 주민 일정에 대한 관심 지점(POI)을 설정합니다.

- **여관**, **마을 회관**, **길드 회관**은 완전한 템플릿입니다. **변형**은 의도적으로 이러한 템플릿 중 하나와 일치시키려는 경우에만 사용하세요.

## 진행 과정 (간략)

1. 마주 보는 두 모서리와 **바깥쪽** 부지 표지판 모서리를 표시합니다.

2. **건물 유형**을 선택합니다(해당하는 경우 **변형**도 선택).

3. **중요 위치**를 배치합니다(블록은 하위 단계마다 하나씩 제공됩니다).

4. **이름**과 **ID**를 입력합니다(프리팹 파일 이름은 ID 뒤에 옵니다).

5. 필요한 경우 **태그**를 편집합니다. 6. **건축 설정**(F)을 엽니다. 재정 금 비용, 자가 건설 일수, 빈 공간 프리팹 옵션, 조립 섹션을 설정합니다.

7. 저장 단계에서 F 키를 눌러 **프리팹 내보내기**를 합니다(6단계의 설정이 사용됩니다).

8. **건축 자재**를 설정합니다(가상 상자; 계속 진행하면 아이템이 다시 나타납니다).

9. 검토 후 저장합니다.

## 권한
