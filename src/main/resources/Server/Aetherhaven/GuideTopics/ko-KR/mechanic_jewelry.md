# 장신구

장신구는 세계 곳곳의 전리품 상자에서 가끔 발견할 수 있습니다. 새로 획득한 장신구는 미확인 상태입니다. 장신구를 상인 벡스에게 가져가면 장신구의 효과를 감정받을 수 있습니다. 장신구는 일반, 희귀, 매우 희귀, 신화, 전설의 5가지 등급으로 나뉩니다. 금은 은보다 강하고, 목걸이는 반지보다 강합니다. 보석의 종류에 따라 장신구가 어떤 능력치에 영향을 미치는지 결정됩니다. 상인이 당신을 충분히 좋아하면 감정대와 장신구 제작대 제작법을 알려줍니다. 감정대는 장신구를 무료로 감정해 줍니다. 장신구 제작대는 금/은괴, 보석, 생명 정수를 사용하여 플레이어가 직접 장신구를 제작할 수 있게 해줍니다. 생명 정수를 많이 사용할수록 품질이 높아집니다.

## 보석 능력치

각 보석 종류는 해당 장신구에 부여되는 세 가지 플레이어 능력치를 결정합니다. 정확한 수치는 희귀도, 금속 종류, 그리고 반지인지 목걸이인지에 따라 다릅니다.

* **제피르** — 스태미나, 시그니처 에너지, 산소
* **토파즈** — 스태미나, 시그니처 에너지, 탄약
* **에메랄드** — 체력, 마나, 산소
* **다이아몬드** — 체력, 스태미나, 마나
* **사파이어** — 마나, 스태미나, 산소
* **루비** — 체력, 스태미나, 탄약
* **보이드스톤** — 마나, 시그니처 에너지, 탄약

**팁**

* 여분의 장신구는 마을 주민에게 선물하기 좋습니다. 선물이 친밀도에 미치는 영향은 **평판** 항목을 참조하세요.
