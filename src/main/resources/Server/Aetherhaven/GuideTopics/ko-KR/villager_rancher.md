**탈렌 메도우런**은 근무 중일 때는 보통 **헛간**에서 찾을 수 있습니다.

### 퀘스트

#### 탈렌의 헛간
탈렌 메도우런이 가축을 돌보고, 가죽과 양털을 모으고, 고기와 달걀을 보관할 수 있도록 헛간을 지어주세요.

1. 탈렌에게서 헛간 부지 토큰을 받으세요.

2. 헛간 조립식 건물을 짓고 말뚝을 박으세요.

3. 농사 작업대에서 탈렌을 찾아 대화창에서 퀘스트를 완료하세요.

#### 탈렌의 집
탈렌은 가축 우리 옆에 짚과 사료통만 두는 곳이 아니라, 신발을 보관하고 잠을 잘 수 있는 집을 원합니다.

1. 탈렌에게서 집 부지 토큰을 받으세요.

2. 집 조립식 건물을 짓고 말뚝을 박으세요.

3. 집 관리 화면에서 탈렌을 거주자로 지정하세요.

4. 탈렌을 찾아 대화창에서 퀘스트를 완료하세요.

### 우정 보상

우정 레벨이 각 단계에 도달하면 해당 친구를 방문하여 대화를 통해 보상을 받으세요.

- **우정 50:** **성장 촉진제** 제작법을 배웁니다.

- **우정 100:** **사냥용 칼** 제작법을 배웁니다.
