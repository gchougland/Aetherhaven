# 로드맵

## 2.0 버전에 포함된 항목

이전 마일스톤에서 선보였던 많은 항목들이 이제 게임에 추가되었습니다. **길드 홀과 경비병**, **퀘스트 게시판** 일일 퀘스트, **플레이어 상점**, **관광객 포털**, 새로운 주민(건축가, 꽃집 주인, 불꽃놀이 장인, 수정지기, 음유시인), **경작지 설계도**, **생산 시설 업그레이드**, 그리고 완전히 새롭게 개선된 **길 설계 도구 삽** 등이 있습니다. 자세한 내용은 이 저널의 **메커니즘** 및 **주민** 부분을 참조하세요.

## 주요 개발 일정 (현재 순서)

1. **박물관 업데이트**
2. **거래 네트워크 업데이트**
3. **플레이어 하우징 업데이트**
4. **맞춤 건물 업데이트** (확장된 부지 생성 워크플로)
