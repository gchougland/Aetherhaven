# 수정 결정체

수정 결정체는 광석과 수정을 채굴할 때 드물게 발견되는 덩어리진 암석입니다. 마을의 대장장이가 소정의 금액을 받고 수정 결정체를 깨뜨려 줍니다. 수정 결정체를 깨뜨리면 광석, 수정 조각, 그리고 드물게 보석을 얻을 수 있습니다. 대장장이와 좋은 관계를 유지하면 수정 결정체를 무료로 열 수 있는 '수정 결정체 모루' 제작법을 알려줍니다.
