# 가이드에 오신 것을 환영합니다

이 책은 마을 일지 안에 있습니다. 왼쪽에서 주제를 선택하여 자세히 읽어보세요.

**시작하기** 마을을 건설하고, 처음 건물을 짓고, 수입을 얻는 방법을 안내합니다.

**게임 시스템** 마을에서 사용하게 될 도구, 건물, 시스템에 대해 설명합니다.

**주민** 각 주민의 이야기, 퀘스트, 평판 선물, 주간 일과를 소개합니다. 선물 취향에 대한 스포일러는 직접 보여주기 전까지 숨겨져 있습니다.
