# 자주 묻는 질문

여기에 있는 답변은 게임 플레이 중에 빠르게 참고할 수 있도록 제공됩니다. 여전히 이해가 안 되는 부분이 있다면 **게임 메커니즘** 또는 **마을 주민** 부분을 확인하여 더 자세한 정보를 알아보세요.

## 이 모드에 *이* 기능이 포함될 예정인가요?

아마도 포함될 가능성이 높지만, 로드맵을 확인해 주세요. 모드 디스코드 채널에서 언제든지 의견을 보내주시면 감사하겠습니다.

## 버그를 신고하거나 기능을 제안하려면 어떻게 해야 하나요?

버그 및 기능 요청은 모드 디스코드 채널에 제출해 주세요. 게임 버전과 싱글 플레이인지 서버 플레이인지 알려주시면 더욱 효율적으로 처리할 수 있습니다.

## 모드 업데이트 시 저장 데이터가 손실되나요?

데이터 마이그레이션은 안전하게 진행되도록 노력하고 있지만, 특히 장기 운영 서버의 경우 주요 업데이트 전에 **월드를 백업**하는 것이 좋습니다.

## 기존 프리팹 대신 직접 건물을 디자인할 수 있나요?

통합 건축 도구는 모드에 추가될 예정인 기능입니다. 현재로서는 건물을 추가하려면 상당한 설정이 필요합니다. 건물을 건설한 후에는 파괴하거나 다시 설치할 수 있지만, 특정 가구나 벤치를 부수거나 옮기면 주민들이 해당 가구나 벤치를 이용하지 못하게 될 수 있다는 점에 유의하세요. 예를 들어 침대를 옮기면 주민들이 침대를 찾을 수 없게 됩니다. 여러분의 건축물을 메인 모드에 소개하고 싶으시다면, 디스코드의 건축물 제출 채널을 이용해 주세요.
