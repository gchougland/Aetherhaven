# 길 디자인 삽

길 디자인 삽을 사용하면 마을에 곡선 길을 그리고 미리 보고, 블록을 땅에 놓을 수 있습니다. 도구를 들고 있으면 주요 힌트가 포함된 상태 표시줄이 나타납니다.

**마을 계획 책상**에서 제작할 수 있습니다.

## 모드

**Q** 키를 눌러 다음 다섯 가지 모드를 순환하며 선택할 수 있습니다.

1. **이동** - 제어 노드를 추가하고 위치를 조정하여 길의 모양을 만듭니다.

2. **회전** - 선택한 노드를 돌려 스플라인을 구부립니다.

3. **배치** - 완성된 길을 땅에 고정합니다.

4. **제거** - 배치된 길(주황색으로 강조 표시됨)을 확인하고 더 이상 필요하지 않은 길을 삭제합니다.

5. **스타일 디자이너** - 상자 그리드에서 길 스타일을 만들고 편집합니다.

HUD는 길 블록을 놓을 준비가 되면 **배치** 모드로 전환하라는 알림을 표시합니다.

## 모드별 조작법

### 이동, 회전, 배치

* **지면에서 마우스 오른쪽 버튼을 클릭(보조)** - 노드를 추가합니다.

* **노드를 조준한 상태에서 보조 버튼을 클릭** - 해당 노드를 제거합니다.

* **노드에서 마우스 왼쪽 버튼을 클릭** - 노드를 선택합니다.

* **지면에서 마우스 왼쪽 버튼을 클릭(이동 모드)** - 선택한 노드를 이동합니다.

* **F 키(회전 모드)** - 선택한 노드의 방향을 약간 조정합니다.

* **F 키(배치 모드)** - 지면에 경로를 배치합니다.

* **E 키** - 경로 너비를 변경합니다.

* **R 키** - 경로 스타일을 변경합니다.

* **Q 키** - 다음 모드로 넘어갑니다.

### 제거

* **마법** - 배치된 경로를 선택합니다.

* **F 키** - 선택한 경로를 제거합니다.

* **Q 키** - 다음 모드로 넘어갑니다.

### 스타일 디자이너

* **F** 키로 스타일 관리자(가중 블록 열을 위한 이중 상자 그리드)를 엽니다.

* **E** 키로 경로 스타일을 저장합니다(상자가 열려 있는 동안).

* **Q** 키로 다음 모드로 이동합니다.

## 미리보기

편집 중에는 흰색 노드와 선이 스플라인을 보여줍니다. 갈색 미리보기는 블록이 배치될 위치를 표시하고, 녹색 테두리가 양쪽에 나타납니다. **제거** 모드에서는 확정된 경로가 주황색으로 표시됩니다.

## 팁

* 먼저 **이동**과 **회전**으로 스플라인의 모양을 조정한 다음, **배치**로 전환하고 **F** 키를 눌러 고정하세요.

* **스타일 디자이너**에서 사용자 지정 스타일을 만들 수 있습니다. 각 스타일은 경로 너비를 따라 배치된 가중치 블록 열입니다.

* 경로는 월드와 마을 저장 파일에 저장됩니다.
