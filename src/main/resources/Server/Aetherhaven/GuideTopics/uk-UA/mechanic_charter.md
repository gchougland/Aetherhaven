# Міська хартія

Хартія – це ваш міський якір. Розмістіть її один раз, щоб створити місто, дайте назву місцю та поставте старійшину села, щоб розпочати свою пригоду з будівництва міста.

**Поради**
* Якщо ви розпустите місто, всі селяни та будівлі будуть видалені.
* Ви можете перемістити хартію за допомогою кнопки в її меню.
