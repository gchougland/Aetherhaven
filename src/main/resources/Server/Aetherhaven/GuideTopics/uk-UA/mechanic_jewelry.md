# Ювелірні вироби

Ювелірні вироби іноді можна знайти у скринях зі здобиччю по всьому світу. Щойно знайдені ювелірні вироби не ідентифікуються. Принесіть їх до Векса-Торговця, щоб визначити їх вплив. Ювелірні вироби бувають 5 видів рідкості (Звичайні, Незвичайні, Рідкісні, Міфічні та Легендарні). Золото міцніше за срібло, а намиста міцніші за персні. Тип дорогоцінного каміння визначає, на які характеристики впливають ювелірні вироби. Якщо торговець достатньо вас полюбить, він поділиться рецептами для Оцінювальної лавки та Верстака для виготовлення ювелірних виробів. Верстак для оцінки оцінить ювелірні вироби безкоштовно. Верстак для виготовлення ювелірних виробів дозволяє гравцеві створювати власні ювелірні вироби, використовуючи золоті/срібні злитки, дорогоцінні камені та життєву есенцію. Чим більше життєвої есенції надається, тим вища якість.

## Характеристики дорогоцінного каміння

Кожен тип дорогоцінного каменю визначає, які три характеристики гравця може викинути виріб. Точні цифри залежать від рідкості, металу та кільця проти намиста.

* **Зефір** — Витривалість, Фірмова Енергія, Кисень
* **Топаз** — Витривалість, Фірмова Енергія, Боєприпаси
* **Смарагд** — Здоров'я, Мана, Кисень
* **Алмаз** — Здоров'я, Витривалість, Мана
* **Сапфір** — Мана, Витривалість, Кисень
* **Рубін** — Здоров'я, Витривалість, Боєприпаси
* **Камінь Порожнечі** — Мана, Фірмова Енергія, Боєприпаси

**Поради**

* Додаткові коштовності стануть чудовими подарунками для жителів села. Дивіться **Репутація** у розділі Механіка, щоб дізнатися, як подарунки впливають на дружбу.
