# Порошок для очищення

Порошок для очищення дозволяє гравцеві видаляти точки появи ворогів у згенерованих структурах. Тримаючи порошок, гравець зможе бачити невеликі обертові версії мобів там, де вони періодично з'являтимуться в структурі. Використання порошку на цьому місці назавжди видалить точку появи ворогів. Розблоковується, якщо подружитися зі Жрицею.
