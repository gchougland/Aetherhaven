# Жеоди

Жеоди — це масивні камені, які рідко зустрічаються під час видобутку руд і кристалів. Міський коваль може розколоти їх для вас за певну плату. Руди, осколки кристалів і рідко дорогоцінні камені можна отримати, розбиваючи жеоди. Якщо коваль достатньо вас полюбить, він поділиться рецептом жеодного ковадла, яке дозволить безкоштовно відкрити жеоди.
