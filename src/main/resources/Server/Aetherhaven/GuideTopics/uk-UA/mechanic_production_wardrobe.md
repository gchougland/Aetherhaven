# Виробнича шафа

Виробничі будівлі використовують скриню у стилі шафи для налаштування та доступу до згенерованих ресурсів. Знайдіть шафу в будівлі та взаємодійте з нею, щоб відкрити вікно виробництва. Ви можете перемикатися між доступними ресурсами для виробництва за допомогою стрілок. Кожен тип ресурсу зберігається окремо. Вибір кількох однакових ресурсів збільшує швидкість їх виробництва. Сторінка розблокування дозволяє розблокувати нові ресурси для генерації за рахунок частини цього ресурсу та золотих монет.

*У майбутньому ви зможете покращити максимальне зберігання та швидкість виробництва будівель.*
