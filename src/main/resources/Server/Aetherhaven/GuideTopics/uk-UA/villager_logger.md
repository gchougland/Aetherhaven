**Серен Фейрхоллоу** зазвичай знаходиться на **лісопиломні** під час зміни.

### Завдання

#### Дім Серен
Серен хоче дах, який не позичений з подвір'я лісопилки, з ліжком, яке насправді її.

1. Візьміть жетон ділянки будинку у Серен.
2. Закріпіть та побудуйте збірний будинок.
3. Призначте Серен мешканцем блоку управління будинком.
4. Знайдіть Серен та завершіть завдання в діалозі.

#### Лісопиломатка Серен
Збудуйте лісопильну, щоб Серен могла перетворювати кільця деревини на стоси для міста, замість того, щоб ходити по кімнаті відпочинку.

1. Візьміть жетон ділянки лісопилки у Серен.
2. Закріпіть та побудуйте збірний будинок лісопилки.
3. Знайдіть Серен за столом та завершіть завдання в діалозі.

### Нагороди за дружбу

Відвідуйте їх після того, як ваша дружба досягне кожного рівня, щоб отримати нагороду через діалог.

- **Дружба 50:** навчає створювати **Дрова**
- **Дружба 100:** навчає створювати **Видаляч коренів**
