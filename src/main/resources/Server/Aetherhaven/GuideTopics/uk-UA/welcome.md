# Ласкаво просимо до путівника

Ця книга знаходиться у вашому міському журналі. Виберіть тему ліворуч, щоб дізнатися більше.

**Початок роботи** проведе вас через заснування міста, ваші перші будівлі та те, як надходять гроші.

**Механіка** пояснює інструменти, будівлі та системи, які ви використовуватимете в місті.

**Сельські жителі** знайомлять вас з кожним мешканцем, його сюжетними завданнями, подарунками репутації та щотижневими розпорядками. Спойлери щодо подарунків залишаються прихованими, доки ви не вирішите їх показати.
