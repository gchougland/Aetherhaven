# Магазин гравця та місця для магазинів

Блоки **місця для магазинів** знаходяться всередині готових будівельних ділянок. Вони дозволяють NPC та гравцям продавати предмети у світі, а не лише через діалогові меню.

## Магазини NPC

Сільські магазини — **універсальний магазин Векса**, Квітковий магазин, Піротехнік, Зберігач кристалів та інші — поповнюють запаси на **світанку** з таблиць здобичі. Кожна ділянка показує плаваючу вітрину предметів; обличчя кіоску обертає дисплей.

* **F (використання)** — відкриває панель покупок з контролем кількості (±1, ±10, макс.).
* **Погляд на HUD** — показує назву предмета, ціну та наявність, коли ви цілитеся в заповнену ділянку.

Векс тепер керує **універсальним магазином**, продаючи меблі, блоки та витратні матеріали через місця для магазинів на своєму ринковому кіоску та пов'язаних будівлях.

## Ваш власний магазин

Після того, як **ринковий кіоск Векса** побудовано, Векс пропонує **Власний магазин**:

1. Візьміть жетон ділянки **магазину гравця** у Векса.

2. Розмістіть та побудуйте префаб магазину гравця.

3. Знайдіть Векс та завершіть квест у діалозі.

Магазин гравця містить блоки **місця для магазину** та **сейф для магазину**, у якому зберігається золото з ваших продажів.

### Предмети списку

* **Клацніть правою кнопкою миші на місці магазину**, тримаючи предмет у руках — виставте його на продаж (лише місця, контрольовані гравцем).
* **Знову клацніть правою кнопкою миші** на власному списку — видаліть його з місця.

Покупці натискають **F** на заповнених місцях, щоб придбати. Ви отримуєте сповіщення, коли хтось купує ваш список, а золото накопичується в **сейфі магазину**.

### Хто купує

**Селяни** та **туристи** переглядають місця для магазинів гравців та купують предмети зі списку, коли відвідують місто. Ціна та запаси мають значення — порожні місця пропускаються.

## Дозволи

Члени міста потребують дозволу на продаж на місцях для магазинів гравців. Власник міста може налаштувати дозволи членів на полиці міських записів.

Дивіться **Жетони сюжету** в розділі Механіка для створення жетонів сюжету на верстаті для створення сюжету.
