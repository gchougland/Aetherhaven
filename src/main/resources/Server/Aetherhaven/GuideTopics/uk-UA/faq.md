# Часті запитання

Відповіді тут призначені для швидкого ознайомлення під час гри. Якщо щось все ще незрозуміло, перегляньте **Механіка** або **Селяни** для отримання детальнішої інформації.

## Чи матиме мод *цю* функцію?

Відповідь, ймовірно, так, але перевірте дорожню карту. Пропозиції завжди вітаються в Discord-каналі мода.

## Де я можу повідомити про помилки або запропонувати функції?

Помилки та запити на функції можна надсилати на канал Discord мода. Включення вашої версії гри та того, чи ви граєте в одиночному режимі, чи на сервері, заощаджує багато часу.

## Чи будуть збереження працювати несправно під час оновлення мода?

Ми намагаємося забезпечити безпеку міграції даних, але **зробіть резервну копію свого світу** перед основними оновленнями, особливо на довговічних серверах.

## Чи можу я проектувати власні будівлі замість використання існуючих префабів?

Інтегровані інструменти будівництва – це запланована функція для мода. Наразі для додавання будівель потрібно багато налаштувань. Ви можете зруйнувати/замінити будівлю після її зведення, але майте на увазі, що поломка/переміщення певних меблів/лавок може перешкодити селянам використовувати її для задоволення своїх потреб. Наприклад, якщо пересунути ліжко, вони не зможуть його знайти. У Discord є канал для подання заявок на збірки, якщо ви хочете, щоб ваша збірка була представлена в основному моді з посиланням на автора.
