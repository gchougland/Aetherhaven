# Скарбниця та податки

У блоці скарбниці зберігається міське золото. Мешканці сплачують ранкову десятину залежно від задоволення своїх поточних потреб. Місто генеруватиме податки, поки хоча б один член міста знаходиться на сервері, навіть невивантаженими порціями. Податки не генеруватимуться, поки жоден член міста не буде онлайн. Розподіл податків можна переглянути на другій вкладці. Існує кілька додаткових способів збільшити свій дохід від податків, таких як свята, статуя засновника та міська політика.
