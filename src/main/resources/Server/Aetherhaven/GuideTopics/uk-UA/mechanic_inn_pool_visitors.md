# Басейн та відвідувачі готелю

Готель може приймати відвідувачів, які не проживають там постійно. Готель може вмістити до 2 відвідувачів одночасно, щодня оновлюючись та перезапускаючись на світанку. Якщо ви прийняли завдання для відвідувачів, вони заблоковані та не будуть перезапускатися.

## Налагодження

Якщо відвідувачі готелю не з'являються або мають якісь проблеми, спробуйте виконати команду `/ah villager fixinn`.
