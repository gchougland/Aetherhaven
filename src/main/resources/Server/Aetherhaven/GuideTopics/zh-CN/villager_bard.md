**伊莱亚斯·索恩伍德**是镇上的**吟游诗人**。**公会大厅**建成后，他会在旅店出现，白天在公会大厅演奏音乐。

使用下方的**显示每周日程**查看伊莱亚斯每天的行踪。

### 任务

#### 伊莱亚斯的家

伊莱亚斯大部分时间都在公会大厅演奏。他想要一个夜晚只属于自己的安静屋顶。

1. 从伊莱亚斯那里拿走房屋地块代币。

2. 圈地并建造房屋预制件。

3. 在房屋管理栏中将伊莱亚斯指定为住户。

4. 找到伊莱亚斯，并通过对话完成任务。
