# 珠宝

珠宝偶尔会在世界各地的战利品箱中找到。新找到的珠宝未经鉴定。将其带到商人维克斯处鉴定其效果。珠宝分为 5 种稀有度（普通、罕见、稀有、神话和传说）。金饰比银饰更坚固，项链比戒指更坚固。宝石的种类决定了珠宝影响的属性。如果商人对你的好感度足够高，他会分享鉴定台和珠宝制作台的配方。鉴定台可以免费鉴定珠宝。珠宝制作台允许玩家使用金锭/银锭、宝石和生命精华制作自己的珠宝。提供的生命精华越多，珠宝的品质越高。

## 宝石属性

每种宝石类型决定了该饰品可以随机生成的三个玩家属性。具体数值取决于稀有度、材质以及戒指与项链的类型。

* **西风** — 耐力、专属能量、氧气

* **黄玉** — 耐力、专属能量、弹药

* **祖母绿** — 生命值、魔法值、氧气

* **钻石** — 生命值、耐力、魔法值

* **蓝宝石** — 魔法值、耐力、氧气

* **红宝石** — 生命值、耐力、弹药

* **虚空石** — 魔法值、专属能量、弹药

**提示**

* 多余的珠宝是赠送给村民的绝佳礼物。请参阅“机制”下的“声望”部分，了解赠送礼物如何影响友好度。
