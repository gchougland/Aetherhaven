**罗文·里奇克拉夫特**是城镇的**建造者**。他的小屋建成后，他会在工作时间前往仍在建造中的地块，一边在告示牌旁工作，一边帮助它们更快地发展。

使用下方的**显示每周日程**查看罗文每天的行程。

### 任务

#### 罗文的建造者小屋

为罗文建造一个合适的小屋，让他可以规划建筑并帮助城镇发展。

1. 在旅店与罗文对话并接受任务。

2. 从罗文那里领取建造者小屋地块代币。

3. 圈定并建造建造者小屋预制件。

4. 在小屋找到罗文，并通过对话完成任务。

#### 罗文的家

即使是像罗文这样热爱建筑的建造者，也需要一个安静的休息场所。

1. 从罗文处领取房屋地块代币。

2. 圈地并建造房屋预制件。

3. 在房屋管理模块中将罗文指定为住户。

4. 找到罗文，并通过对话完成任务。
