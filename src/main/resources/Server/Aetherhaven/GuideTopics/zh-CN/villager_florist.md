**艾薇·布鲁姆韦尔**会在她的**花店**建成后出售植物和鲜花。她会在**维克斯的市场摊位**建成后出现在旅店。

使用下方的**显示每周日程**查看艾薇每天的行程。

### 任务

#### 艾薇的花店

艾薇想要一家像样的花店，与镇上的居民分享她的植物。

1. 在旅店与艾薇对话并接受任务。

2. 从艾薇那里获得花店的**蓝图**。

3. 在你的**地块制作台**使用蓝图学习花店建造。

4. 制作一个商店地块代币并建造花店预制件。

5. 在花店找到艾薇，并通过对话完成任务。

#### 艾薇的家

即使是整天和植物说话的花艺师，也需要一个安静的休息场所。

1. 从艾薇那里拿到房屋地块代币。

2. 圈地并建造房屋预制件。

3. 在房屋管理栏中将艾薇指定为住户。

4. 找到艾薇，并通过对话结束任务。
