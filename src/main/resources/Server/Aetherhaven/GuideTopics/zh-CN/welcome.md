# 欢迎来到指南

本书位于您的城镇日志中。选择左侧主题即可阅读更多内容。

**入门指南** 将引导您创建城镇、建造首批建筑以及了解资金来源。

**机制指南** 将解释您将在城镇中使用的工具、建筑和系统。

**村民指南** 将介绍每位居民、他们的故事任务、声望礼物和每周例行活动。礼物口味剧透将在您选择显示之前保持隐藏状态。
