**格鲁布尔·斯帕克马奇**是一位出售炸药的**烟火师**。你必须**在世界中找到并解救他**，他才会光顾旅店。获救后，他就可以在镇上开一家炸弹店了。

使用下方的**显示每周日程**查看格鲁布尔每天的行踪。

### 任务

#### 格鲁布尔的逃脱

在探索过程中，你可能会发现格鲁布尔被困在蜘蛛茧里。解救他即可完成此任务。之后他就会开始出现在旅店。

#### 格鲁布尔的炸弹店

格鲁布尔想要一家像样的店铺，向镇上的人们出售他的炸药。

1. 在旅店与格鲁布尔对话并接受任务。

2. 从格鲁布尔那里获得店铺的**蓝图**。

3. 在你的**地块制作台**使用蓝图学习炸弹店的建造方法。

4. 制作一个商店地块代币，并建造炸弹商店预制件。

5. 在商店找到格鲁布尔，并通过对话完成任务。

#### 格鲁布尔的家

即使是喜欢喧闹的哥布林，有时也需要一张安静的床。

1. 从格鲁布尔那里拿走房屋地块代币。

2. 圈地并建造房屋预制件。

3. 在房屋管理模块中将格鲁布尔指定为住户。

4. 找到格鲁布尔，并通过对话完成任务。
