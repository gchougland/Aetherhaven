**艾琳·莫斯马克** 值班时通常会在**农田**。

### 任务

#### 艾琳的农田

给艾琳一块带围栏的土地和一张长凳，让她不再做梦梦见自己住在旅店的地板上。

1. 从艾琳那里拿到农田标记。

2. 圈地并建造农田预制件。

3. 在农田长凳旁找到艾琳，对话结束任务。

#### 艾琳的家

艾琳想要的是属于自己的根基，而不是借来的地板。

1. 从艾琳那里拿到房屋标记。

2. 放置并建造房屋预制件。

3. 在房屋管理栏中将艾琳指定为住户。

4. 找到艾琳，对话结束任务。

### 友谊奖励

当您的友谊等级达到相应级别时，请拜访他们并通过对话领取奖励。

- **友谊等级 25：** 教您制作 **铁制洒水器**

- **友谊等级 50：** 教您制作 **钍制洒水器**

- **友谊等级 75：** 教您制作 **钴制洒水器**

- **友谊等级 100：** 教您制作 **精金洒水器**
