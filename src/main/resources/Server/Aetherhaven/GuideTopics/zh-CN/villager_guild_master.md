**莱拉·费尔霍洛**负责管理建成后的**公会大厅**。冒险者们会聚集于此，你可以雇佣他们担任**守卫**，负责巡逻和对抗敌对生物。巡逻路线和指挥所的位置请参见“机制”下的**公会大厅和守卫**。

使用下方的**显示每周日程**查看莱拉每天的行程安排。

### 任务

#### 建造公会大厅

莱拉想要一个像样的公会大厅，冒险者们可以在这里登记，也可以雇佣守卫。

1. 先完成**城镇大厅**的建造，然后前往旅店与莱拉对话。

2. 从莱拉处领取公会大厅地块代币。

3. 圈地并建造公会大厅预制件。

4. 在公会大厅找到莱拉，并通过对话完成任务。

#### 莱拉的家

莱拉从早到晚负责公会大厅的日常运作。她渴望夜晚能拥有一个属于自己的宁静空间。

1. 从莱拉处领取房屋地块代币。

2. 圈地并建造房屋预制件。

3. 在房屋管理栏中将莱拉指定为住户。

4. 找到莱拉，并通过对话完成任务。
