# Path designer shovel

The **path designer shovel** lets you draw curved paths through town, preview them, and place blocks on the ground. A status panel with key hints appears while you hold the tool.

Craft it at the **town planning desk**.

## Modes

Press **Q** to cycle through five modes:

1. **Move** — add and reposition control nodes to shape the path.
2. **Rotate** — turn the selected node to bend the spline.
3. **Place** — cement the finished path onto the ground.
4. **Remove** — view placed paths (highlighted in orange) and delete ones you no longer want.
5. **Style designer** — create and edit path styles in a chest grid.

The HUD reminds you to switch to **Place** mode when you are ready to lay path blocks.

## Controls by mode

### Move, Rotate, and Place

* **Secondary (right click) on ground** — add a node.
* **Secondary while looking at a node** — remove that node.
* **Primary (left click) while looking at a node** — select it.
* **Primary on ground (Move mode)** — move the selected node.
* **F (Rotate mode)** — nudge the selected node's direction.
* **F (Place mode)** — place the path on the ground.
* **E** — cycle path width.
* **R** — cycle path style.
* **Middle click** — toggle whether townsfolk walk the path.
* **Q** — next mode.

### Remove

* **Primary while looking at a placed path** — select it.
* **F** — remove the selected path.
* **Q** — next mode.

### Style designer

* **F** — open the style manager (double-chest grid for weighted block columns).
* **E** — save the path style (while the chest is open).
* **Q** — next mode.

## Preview visuals

While editing, white nodes and lines show the spline. A brown preview marks where blocks will go, with green edges at the sides. **Remove** mode shows committed paths in orange instead.

## Tips

* Shape the spline in **Move** and **Rotate** first, then switch to **Place** and press **F** to cement it.
* Build custom looks in **Style designer** — each style is a weighted column of blocks rolled along the path width.
* Paths persist in the world and in your town save.
