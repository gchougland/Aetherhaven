# Path designer shovel

The **path designer shovel** lets you draw curved paths through town, preview them, and place blocks on the ground. A status panel appears while you hold the tool. It names each action, and the game shows your own key for each one at the bottom right of the screen. If the keys are missing, turn on **Display Input Bindings in HUD** in the game settings.

Craft it at the **town planning desk**.

## Modes

Use **Next mode** to cycle through modes:

1. **Move** — add and reposition control nodes to shape the path.
2. **Rotate** — turn the selected node to bend the spline.
3. **Place** — cement the finished path onto the ground.
4. **Remove** — view placed paths (highlighted in orange) and delete ones you no longer want.
5. **Restyle** — select a placed path and swap its blocks to another style.
6. **Replace filter** — choose which ground blocks the path may replace.
7. **Style designer** — create and edit path styles in a chest grid.

The HUD reminds you to switch to **Place** mode when you are ready to lay path blocks.

## Controls by mode

### Move, Rotate, and Place

* **Add or remove** on the ground: add a node.
* **Add or remove** while looking at a node: remove that node.
* **Select** while looking at a node: select it.
* **Select** on the ground (Move mode): move the selected node.
* **Mode action** (Rotate mode): nudge the selected node's direction.
* **Mode action** (Place mode): place the path on the ground.
* **Width or save**: open path width settings.
* **Crouch + Next mode**: open the style list.
* **Mode menu**: open the mode jump menu (also toggle whether townsfolk walk paths you place).
* **Next mode**: switch to the next mode.

### Remove

* **Select** while looking at a placed path: select it.
* **Mode action**: remove the selected path.
* **Mode menu**: open the mode jump menu.
* **Next mode**: switch to the next mode.

### Restyle

* **Select** while looking at a placed path: select it.
* **Mode action**: open the style list. Choosing a style swaps that path's blocks right away.
* **Mode menu**: open the mode jump menu.
* **Next mode**: switch to the next mode.

### Style designer

* **Mode action**: open the style manager (double-chest grid for weighted block columns).
* **Width or save**: save the path style (while the chest is open).
* **Mode menu**: open the mode jump menu.
* **Next mode**: switch to the next mode.

## Preview visuals

While editing, white nodes and lines show the spline. A brown preview marks where blocks will go, with green edges at the sides. **Remove** and **Restyle** modes show committed paths in orange instead.

## Tips

* Shape the spline in **Move** and **Rotate** first, then switch to **Place** and use **Mode action** to cement it.
* Build custom looks in **Style designer** — each style is a weighted column of blocks rolled along the path width.
* Use **Restyle** when you want a different look on a path you already placed, without removing it first.
* Paths persist in the world and in your town save.
