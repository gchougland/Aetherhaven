# Painted material source

`material-sheet.png` is original artwork generated with the built-in image generation tool on October 2, 2026. Native Hytale Alchemy bench, BackpackBig, Portal_Device and Leather_Light chest texture atlases were inspected and supplied as style references only. The generated source is packed into game UV atlases by the asset generators; it is not loaded at full resolution by the game.

Prompt: Create an original square game material sheet matching the references' broad hand painted value shapes, restrained warm highlights, cool creases, directional brushwork and worn edges. Four columns and four rows, no labels or gutters. Row 1: saddle leather, dark leather, honey oak, aged brass. Row 2: forged iron, patinated copper, charcoal stone, blue gray stone. Row 3: green linen, burgundy cloth, plum velvet, blue cloth. Row 4: ivory parchment, aqua glass, teal enamel, sage metal. Each tile is a flat orthographic surface with readable detail when reduced to 32 pixels. No copied artwork, perspective objects, lettering, emblems or decorative runes.

The native references are kept only under ignored build output. The ledger desk is intentionally excluded from the repaint at the user's direction.

`metal-sheet.png` is a separate original imagegen painting referenced directly against native Copper, Iron, Thorium, Cobalt and Adamantite chest textures. Layout is three columns and two rows: Copper, Iron, Thorium; Cobalt, Adamantite, brass. It supersedes the generic metal tiles in the first sheet. In particular, Thorium uses olive and pale yellow rather than teal. The requirement is to match native metals, not merely assign tier colors.

Metal prompt: Paint a flat six-panel sheet matching the exact hue, saturation and value ranges of the five attached native armor atlases. Copper is warm brown golden copper; Iron is neutral gray silver; Thorium is yellow olive with ivory highlights; Cobalt is navy with icy pale blue highlights; Adamantite is burgundy with pale warm highlights; brass is aged gold. Broad native hand-painted strokes, restrained wear, readable at 32 pixels. No copied artwork, perspective objects, noise, labels, handles, studs or runes.
